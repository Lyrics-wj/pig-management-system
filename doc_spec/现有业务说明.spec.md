# 现有系统业务说明

本文档基于当前仓库后端 Controller、Service 及前端 views/api 梳理，描述 **ai-boot（若依风格）** 已有业务模块与功能，供需求分析、迭代与代码生成参考。

---

## 一、系统概览

- **技术栈**：后端 Spring Boot + MyBatis-Plus + PageHelper + JWT；前端 Vue 3 + Vite + Element Plus。
- **认证**：登录后颁发 JWT，请求头 `Authorization: Bearer <token>`；权限按菜单与按钮标识（如 `system:user:list`）控制。
- **入口**：后端主入口 `ruoyi-admin`；前端开发代理 `/dev-api` 指向后端。

---

## 二、认证与通用

| 功能 | 后端接口 | 说明 |
|------|----------|------|
| 登录 | POST `/login` | 用户名+密码+验证码，返回 token |
| 获取用户信息 | GET `/getInfo` | 当前用户、角色、权限、是否需改密/密码过期 |
| 获取路由 | GET `/getRouters` | 按当前用户权限返回前端动态菜单/路由 |
| 注册 | POST `/register` | 需系统参数 `sys.account.registerUser` 开启 |
| 验证码 | 见 CaptchaController | 图形验证码生成与校验 |
| 通用下载 | GET `/common/download` | 按文件名下载上传文件 |
| 通用上传 | POST `/common/upload`、`/common/uploads` | 单文件/多文件上传 |
| 资源下载 | GET `/common/download/resource` | 本地资源文件下载 |

**个人信息**（`/system/user/profile`）：

- GET：当前用户资料及角色/岗位分组展示。
- PUT：修改昵称、邮箱、手机、性别。
- PUT `/updatePwd`：修改密码（旧密码校验）。
- POST `/avatar`：头像上传。

## 三、系统管理（/system）

### 3.1 用户管理（/system/user）

- **列表**：GET `/list`，分页，支持按用户名、手机号、状态、部门、创建时间筛选；数据权限（部门/本人）。
- **详情**：GET `/{userId}` 或 `/`，含用户信息、岗位 ID 列表、角色 ID 列表；同时返回角色与岗位下拉数据。
- **新增**：POST `/`，校验用户名/手机/邮箱唯一，密码加密，可关联部门、角色、岗位。
- **修改**：PUT `/`，同新增校验，数据权限校验。
- **删除**：DELETE `/{userIds}`，不能删除自己。
- **重置密码**：PUT `/resetPwd`。
- **状态切换**：PUT `/changeStatus`（启用/停用）。
- **授权角色**：GET `/authRole/{userId}` 获取弹窗数据；PUT `/authRole` 提交用户-角色关联。
- **部门树**：GET `/deptTree`，用于部门选择。
- **导出/导入**：POST `/export` 导出 Excel；POST `/importData` 导入；POST `/importTemplate` 下载导入模板。

### 3.2 角色管理（/system/role）

- **列表**：GET `/list`，分页，数据权限。
- **详情**：GET `/{roleId}`。
- **新增**：POST `/`，校验角色名、权限字符唯一。
- **修改**：PUT `/`，含菜单权限；修改后刷新当前用户权限缓存。
- **数据权限**：PUT `/dataScope`，配置角色数据范围（全部/自定义/本部门等）。
- **状态**：PUT `/changeStatus`。
- **删除**：DELETE `/{roleIds}`。
- **角色下拉**：GET `/optionselect`。
- **已分配/未分配用户**：GET `/authUser/allocatedList`、`/authUser/unallocatedList`；取消授权 PUT `/authUser/cancel`、`/authUser/cancelAll`；批量授权 PUT `/authUser/selectAll`。
- **角色部门树**：GET `/deptTree/{roleId}`，用于数据权限配置。

### 3.3 菜单管理（/system/menu）

- **列表**：GET `/list`，树形，按当前用户权限过滤。
- **详情**：GET `/{menuId}`。
- **菜单树（下拉）**：GET `/treeselect`。
- **角色菜单树**：GET `/roleMenuTreeselect/{roleId}`，用于角色配置菜单。
- **新增**：POST `/`，校验菜单名唯一、外链地址格式。
- **修改**：PUT `/`，不可选自己为父菜单。
- **删除**：DELETE `/{menuId}`，有子菜单或已分配角色则不允许删除。

### 3.4 部门管理（/system/dept）

- **列表**：GET `/list`，树形；GET `/list/exclude/{deptId}` 排除某节点及其子节点。
- **详情**：GET `/{deptId}`，数据权限校验。
- **新增**：POST `/`，部门名唯一。
- **修改**：PUT `/`，不可选自己为上级、停用时需无未停用子部门。
- **删除**：DELETE `/{deptId}`，有子部门或存在用户则不允许删除。

### 3.5 岗位管理（/system/post）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{postId}`。
- **新增**：POST `/`，岗位名称、岗位编码唯一。
- **修改**：PUT `/`。
- **删除**：DELETE `/{postIds}`。
- **岗位下拉**：GET `/optionselect`。

### 3.6 参数设置（/system/config）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{configId}`。
- **按键名查值**：GET `/configKey/{configKey}`（如 sys 开关、密码策略等）。
- **新增/修改/删除**：POST、PUT、DELETE `/{configIds}`，键名唯一。
- **刷新缓存**：DELETE `/refreshCache`。

### 3.7 字典类型（/system/dict/type）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{dictId}`。
- **新增/修改/删除**：POST、PUT、DELETE `/{dictIds}`，类型唯一。
- **刷新字典缓存**：DELETE `/refreshCache`。
- **字典类型下拉**：GET `/optionselect`。

### 3.8 字典数据（/system/dict/data）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{dictCode}`。
- **按类型查**：GET `/type/{dictType}`，供前端字典标签等使用。
- **新增/修改/删除**：POST、PUT、DELETE `/{dictCodes}`。

### 3.9 通知公告（/system/notice）

- **列表**：GET `/list`，分页。
- **详情**：GET `/{noticeId}`。
- **新增/修改/删除**：POST、PUT、DELETE `/{noticeIds}`。

## 四、系统监控（/monitor）

### 4.1 在线用户（/monitor/online）

- **列表**：GET `/list`，从 Redis Token 汇总，支持按 IP、用户名筛选。
- **强退**：DELETE `/{tokenId}`，清除对应 Token。

### 4.2 操作日志（/monitor/operlog）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **删除**：DELETE `/{operIds}`。
- **清空**：DELETE `/clean`。

### 4.3 登录日志（/monitor/logininfor）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **删除**：DELETE `/{infoIds}`。
- **清空**：DELETE `/clean`。
- **账户解锁**：GET `/unlock/{userName}`，清除密码错误次数缓存。

### 4.4 服务器信息（/monitor/server）

- **详情**：GET `/`，返回 CPU、内存、JVM、磁盘等运行信息。

### 4.5 缓存监控（/monitor/cache）

- **Redis 信息**：GET `/`，info、dbSize、commandStats。
- **缓存名列表**：GET `/getNames`（如用户信息、配置、字典、验证码等）。
- **某类 key 列表**：GET `/getKeys/{cacheName}`。
- **某 key 值**：GET `/getValue/{cacheName}/{cacheKey}`。
- **按名称清空**：DELETE `/clearCacheName/{cacheName}`。
- **按 key 清空**：DELETE `/clearCacheKey/{cacheKey}`。
- **清空全部**：DELETE `/clearCacheAll`。

### 4.6 定时任务（/monitor/job）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{jobId}`。
- **新增**：POST `/`，Cron 校验、调用目标白名单校验。
- **修改**：PUT `/`。
- **状态**：PUT `/changeStatus`（启用/停用）。
- **立即执行**：PUT `/run`。
- **删除**：DELETE `/{jobIds}`。

### 4.7 任务日志（/monitor/jobLog）

- **列表**：GET `/list`，分页；导出 POST `/export`。
- **详情**：GET `/{jobLogId}`。
- **删除**：DELETE `/{jobLogIds}`。
- **清空**：DELETE `/clean`。

## 五、系统工具（/tool）

### 5.1 代码生成（/tool/gen）

- **已配置生成表列表**：GET `/list`，分页。
- **单表配置详情**：GET `/{tableId}`，含表信息、字段列表、已配置表列表。
- **数据库表列表**：GET `/db/list`，分页，用于从库选表导入。
- **表字段列表**：GET `/column/{tableId}`。
- **导入表**：POST `/importTable`，将选中库表导入为生成配置。
- **创建表并导入**：POST `/createTable`（仅 admin），执行建表 SQL 并导入配置。
- **修改配置**：PUT `/`。
- **删除配置**：DELETE `/{tableIds}`。
- **预览代码**：GET `/preview/{tableId}`。
- **下载代码**：GET `/download/{tableName}`，单表 zip。
- **生成到本地**：GET `/genCode/{tableName}`，需配置允许覆盖。
- **同步数据库**：GET `/synchDb/{tableName}`，表结构变更后同步字段。
- **批量下载**：GET `/batchGenCode`，多表 zip。

## 七、数据权限与安全约定

- **数据权限**：角色可配置数据范围（全部/自定义/本部门/本部门及以下/仅本人等）；用户、角色、部门列表等接口按当前用户数据权限过滤。
- **权限标识**：菜单与按钮使用 `system:user:list`、`system:user:add` 等形式，与后端 `@PreAuthorize("@ss.hasPermi('...')")` 一致。
- **操作与登录日志**：关键操作通过 `@Log` 记录；登录成功/失败写入登录日志；支持按条件查询、导出、清空。
