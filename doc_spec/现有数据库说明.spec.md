# 现有数据库说明

本文档基于仓库内 SQL 脚本及后端 Mapper/实体 梳理，描述 **蓬溪县生猪数字化管理平台** 当前使用的数据库表结构、字段与关系，供建库、迁移与代码生成参考。

**同步记录约定**：每次有**新的数据库表设计**或**表结构增加/变更**，均须同步更新本文（在对应章节补充表名、主键、字段说明及与后端实体/Mapper 的对应），并在 `service/sql` 下维护或补充建表脚本，保证文档与库表一致。

---

## 一、概述

- **数据源**：由 `ruoyi-admin` 的 `application.yml`、`application-druid.yml` 配置，单库。
- **脚本位置**：
  - 业务库（系统基础 + 代码生成）：`service/sql/ry_20250522.sql`
  - 定时任务调度引擎：`service/sql/quartz.sql`（Quartz 标准表）
- **约定**：表名、字段名使用下划线命名（snake_case）；业务表统一 InnoDB；删除标记多为 `del_flag`（0 存在 2 删除）；通用审计字段：`create_by`、`create_time`、`update_by`、`update_time`。

| QRTZ_CALENDARS | 日历 | (sched_name, calendar_name) |
