## 关键代码

#### 获取列表数据
示例代码：
```typescript
/** 查询列表 */
async function getList() {
  loading.value = true
  try {
    const response:ListResponse<{Entity}> = await list{Entity}(queryParams.value)
    dataList.value = response.rows
    total.value = response.total
  } catch (error) {
    console.error('查询列表失败:', error)
  } finally {
    loading.value = false
  }
}
```

#### 初始化必须请求列表（强制约束）
**页面必须自动请求列表接口，不得仅依赖用户点击「查询」才拉取数据。** 按以下两种情形处理：

- **一般情况（无前置接口）**：在 `onMounted` 中立即调用 `getList()`。
- **有前置接口调用链**：先执行并等待前置接口（如字典、下拉选项、初始参数等）完成，在前置接口全部完成后再立即调用 `getList()`，不得在未等待前置完成时调用列表接口。

一般情况示例：
```typescript
onMounted(() => {
  getList()
})
```

有前置接口时示例：
```typescript
onMounted(async () => {
  await loadOptions()  // 或 await Promise.all([loadDict(), loadOther()])
  getList()
})
```

#### 搜索栏：日期范围通用数据设置格式
示例代码：
```typescript
// 代码生成后将此处替换为实际日期范围字段，例如：createTime、updateTime
const dateRange = computed({
  set(val: string[] | null) {
    if (!val) {
      queryParams.value.startTime = "";
      queryParams.value.endTime = "";
      return;
    }
    queryParams.value.startTime = val[0];
    queryParams.value.endTime = val[1];
  },
  get() {
    if (!queryParams.value.startTime && !queryParams.value.endTime) {
      return [];
    }
    return [queryParams.value.startTime, queryParams.value.endTime];
  },
});
```

## 文档说明：

- `list{Entity}` 是调用后端 API 查询列表的函数，根据实体名动态生成。
- `queryParams.value` 是查询参数对象，包含分页信息和搜索条件。
- `dataList.value` 是表格数据列表，用于展示查询结果。
- `total.value` 是总记录数，用于分页组件显示。
- `loading.value` 是加载状态，用于表格加载动画。
- `ListResponse<{Entity}>` 是后端返回的列表响应体，包含分页信息和数据列表。
