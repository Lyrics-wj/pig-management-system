# Element Plus 组件总览

> 基于 [Element Plus 官方文档](https://element-plus.org/zh-CN/component/overview) 整理，按分类列出组件名称与主要功能。

---

## 一、基础组件 Basic（12 个）

| 组件名 | 英文 | 功能简述 |
|--------|------|----------|
| 按钮 | Button | 触发操作的按钮，支持多种类型、尺寸、图标 |
| 边框 | Border | 为元素提供边框样式 |
| 色彩 | Color | 色彩规范与主题色使用 |
| 布局容器 | Container | 页面整体布局容器（顶栏、侧栏、主内容区） |
| 图标 | Icon | 内置图标库，配合 `@element-plus/icons-vue` 使用 |
| 布局 | Layout | 栅格布局（el-row / el-col） |
| 链接 | Link | 文字链接，可禁用、下划线、图标 |
| 文本 | Text | 文本排版与省略、复制等（2.3.0+） |
| 滚动条 | Scrollbar | 自定义滚动条样式与行为 |
| 间距 | Space | 子元素之间的间距控制 |
| 分隔面板 | Splitter | 可拖拽分割左右/上下面板（2.10.0+） |
| 排版 | Typography | 标题、段落等排版组件 |
