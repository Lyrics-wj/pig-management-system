# 生猪数字化管理平台
> 面向智慧养殖、生猪全生命周期的数字化管理与数据分析平台

## 项目简介
本项目是一套**生猪数字化管理平台**，聚焦生猪养殖、育种、防疫、饲喂、出栏、溯源、报表分析等全流程业务，
通过信息化、数字化手段提升养殖效率、降低养殖风险、实现养殖过程可追溯、数据可分析。

适用于：
- 规模化养猪场
- 养殖合作社
- 农业数字化企业
- 智慧农业/畜牧管理系统

## 核心功能
- 生猪档案管理：耳标、品种、日龄、体重、来源、批次管理
- 养殖过程管理：饲喂记录、环境监测、转栏/并栏记录
- 防疫与健康管理：免疫、用药、诊疗、疫病预警
- 繁殖管理：配种、妊娠、产仔、断奶管理
- 出栏与销售：出栏登记、销售记录、成本核算
- 数据统计与可视化：存栏报表、生长曲线、料肉比、盈亏分析
- 系统管理：用户权限、角色、日志、配置管理

## 技术栈（可根据你实际项目修改）
- 后端：SpringBoot / SpringCloud
- 前端：Vue3 + Element Plus
- 数据库：MySQL / MyBatis-Plus
- 中间件：Redis、RabbitMQ
- 部署：Docker、Nginx
- 数据可视化：ECharts
