# 制作 HTML 原型界面

## 第一步：读取最新规范

**必须**先读取项目界面制作规范，所有制作行为以该文件的最新内容为准：

```
doc_spec/界面制作规范.md
```

读取完成后，严格按照规范中的所有章节要求执行，不得依赖记忆中的旧版本内容。

## 第二步：确认 PRD 来源

按规范 **2.2 制作范围确认** 执行：

- 用户已指定**文件夹**：读取该文件夹下所有 `.prd.md` 文件，逐一生成 HTML。
- 用户已指定**具体文件**：仅生成指定文件对应的 HTML。
- 用户**未指定**任何路径：停止，提示用户指定后再继续。

## 第三步：阅读 PRD 并确认问题

按规范 **2.1 PRD 理解确认** 执行：读取所有目标 PRD 文件，发现歧义或不明确时，每次最多提 5 个问题，确认后再制作。

## 第四步：生成 HTML 文件

按规范执行以下各项（逐章对照）：

- 文件命名与存放路径：见规范**第四章**
- HTML 内部结构（注释头、MOCK_DATA、区块 id）：见规范**第五章**
- 交互功能（Tab、表格操作列、表单校验、登录、多角色）：见规范**第六章**
- 界面风格与布局：见规范**第七章**
- 各类功能页制作要点：见规范**第八章**

## 第五步：更新 index.html

每次生成或修改 HTML 文件后，同步更新 `原型图/index.html`，见规范 **4.3**。

## 第六步：质量自检

对照规范**第十章**质量自检清单逐项核查，全部通过后完成交付。
