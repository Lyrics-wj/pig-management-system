## 功能一：猪舍温湿度实时监测

### 3.1 基本信息

- **功能名称**：猪舍温湿度实时监测
- **关联现有模块/功能**：
  - 圈舍管理（基础信息-功能二）：温湿度传感器与圈舍绑定，监测数据按圈舍展示；监测页面依赖 `pig_pigsty` 中的圈舍列表
  - 企业信息管理（基础信息-功能一）：监测数据按企业隔离，仅展示当前登录用户所属企业的圈舍数据
  - 参考文档：`doc_spec/现有业务说明.spec.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（引用自全局角色权限体系 §1.1） | 使用场景 | 主要需求 |
|---------|--------------------------------------|---------|---------|
| 企业管理员 | `ent_admin` | 登录 WEB 端后，通过「企业信息管理 → 实时监测 → 猪舍温湿度」入口查看各圈舍温湿度实时数据及历史趋势，辅助养殖管理决策 | 实时掌握各圈舍的温度和湿度状态，及时发现超出正常范围的圈舍并安排处理 |
| 企业填报员 | `ent_reporter` | 同上入口查看温湿度实时数据，日常养殖巡检辅助 | 查看各圈舍温湿度数据，发现异常时及时上报 |

---

### 3.2 目标与范围

**目标**：
1. 以可视化卡片/列表形式展示各圈舍温湿度传感器的最新监测数据。
2. 支持按圈舍筛选查看温湿度数据，支持查看单个圈舍的历史监测趋势图。
3. 提供温湿度告警展示，对超出预设阈值范围的圈舍进行高亮标记和告警提示。
4. 展示传感器设备连接状态，区分「在线」「离线」「异常」三种状态。

**非目标（Non-Goals）**：
- ❌ 不做传感器设备的硬件注册与配对管理（本期由运维人员在后台完成）。
- ❌ 不做温湿度告警阈值的用户自定义配置（本期阈值由系统预设，后续迭代可开放配置）。
- ❌ 不做温湿度数据的手动填报（数据仅来源于传感器设备自动上报）。
- ❌ 不做历史数据的导出功能（本期仅展示，后续迭代补充）。
- ❌ 不做移动端（小程序）温湿度监测页面（本期仅在 WEB 端实现）。

### 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 圈舍温湿度概览展示 | P0 | 以卡片形式展示所有圈舍的最新温湿度数据及设备状态 |
| 圈舍筛选 | P1 | 支持按圈舍名称/类型筛选，只查看指定圈舍的数据 |
| 温湿度历史趋势图 | P1 | 点击某个圈舍卡片，展示该圈舍的温湿度历史趋势折线图，支持按时间范围查询 |
| 告警状态标记 | P0 | 温度或湿度超出阈值范围时，对应圈舍卡片高亮标记（红色边框+告警图标） |
| 设备状态展示 | P0 | 展示传感器设备连接状态：在线/离线/异常 |
| 数据自动刷新 | P1 | 页面展示的实时数据按设定间隔（30秒）自动刷新 |

**关键流程**：

```
进入「实时监测 → 猪舍温湿度」页面
  ↓
系统调用 GET /farm/pigsty/options 获取圈舍下拉列表（供筛选使用）
同时调用 GET /farm/monitor/temperature-humidity/realtime 获取所有圈舍最新监测数据
  ↓
展示圈舍温湿度卡片列表（含设备状态、最新温湿度值、告警状态）
  ↓
页面每隔30秒自动刷新实时数据（重新调用 realtime 接口）

查看历史趋势：
  点击某个圈舍卡片 → 展开历史趋势区域（或弹出趋势图弹窗）
    → 默认展示近24小时历史数据 → 可切换时间范围（近1小时/近24小时/近7天）
    → 调用 GET /farm/monitor/temperature-humidity/history（含 pigstyId + 时间范围参数）
    → 展示温度折线 + 湿度折线双轴图表

圈舍筛选：
  在顶部筛选区选择圈舍类型或输入圈舍名称 → 即时筛选展示区中的圈舍卡片
  → 点击「重置」恢复展示全部圈舍
```

**交互与界面要点**：
- 整体布局：顶部为筛选区（圈舍类型下拉 + 圈舍名称搜索框 + 查询/重置按钮）；主区域以网格卡片布局（每行3～4个卡片，响应式）展示各圈舍温湿度状态。
- 圈舍温湿度卡片展示内容（每张卡片）：圈舍名称、圈舍类型、设备状态（在线/离线/异常 Tag）、最新温度值（°C，保留1位小数）、最新湿度值（%RH，保留1位小数）、数据更新时间（格式：MM-DD HH:mm:ss）、告警状态（正常/温度告警/湿度告警）。
- 告警状态样式：正常状态卡片边框为灰色；温度告警时卡片左侧边框显示红色；湿度告警时卡片左侧边框显示橙色；同时存在温度和湿度告警时卡片左侧边框显示红色（优先级：温度告警 > 湿度告警）。
- 设备离线时，温度和湿度值展示「--.--」，卡片灰化处理。
- 历史趋势图使用折线图（建议使用 ECharts 组件），X 轴为时间，Y 轴左侧为温度（°C），Y 轴右侧为湿度（%RH），双折线展示温度和湿度变化趋势；图表区域顶部提供时间范围切换 Tab（近1小时/近24小时/近7天）。

#### 3.4.1 功能流程逻辑

**告警判断规则**：
- 温度告警：最新温度值 < 温度下限阈值（默认10.0°C）或最新温度值 > 温度上限阈值（默认35.0°C）时触发温度告警。
- 湿度告警：最新湿度值 < 湿度下限阈值（默认40.0%RH）或最新湿度值 > 湿度上限阈值（默认85.0%RH）时触发湿度告警。
- 阈值为系统预设值（本期不对外开放配置），后端在返回实时数据时直接标注 `is_temp_alarm`（是否温度告警）和 `is_humi_alarm`（是否湿度告警）字段，前端根据该字段展示告警样式。

**设备状态规则**：
- 在线（online）：传感器设备最近一次数据上报时间在当前时间 5 分钟以内。
- 离线（offline）：传感器设备最近一次数据上报时间超过当前时间 5 分钟且不超过 24 小时。
- 异常（error）：传感器设备最近一次数据上报时间超过当前时间 24 小时，或设备主动上报异常状态。
- 设备状态由后端在实时数据接口中统一计算并返回 `device_status` 字段，前端直接展示。

**数据自动刷新规则**：
- 页面打开后启动定时器，每 30 秒自动调用实时数据接口刷新数据。
- 用户离开该页面（路由切换）时销毁定时器，不在后台继续请求。
- 自动刷新不展示 loading 状态，静默刷新；数据更新后卡片内容自动替换。

**无数据情况处理**：
- 某圈舍绑定的传感器从未上报数据：展示「暂无数据」占位符。
- 企业无任何圈舍绑定传感器：展示空状态图标，提示「暂无监测设备，请联系平台运维人员安装传感器」。

- 图表区域在温度告警阈值处展示参考线（红色虚线标注上限35°C和下限10°C），在湿度告警阈值处展示参考线（橙色虚线标注上限85%RH和下限40%RH）。

**自动回显/只读字段说明**：

本功能为纯展示类页面（无新增/编辑表单），所有卡片展示的数据均为后端接口返回的只读数据，前端不提供编辑入口。以下字段由系统自动生成或计算，无需用户干预：
- 设备状态（device_status）：由后端根据设备最近上报时间自动计算
- 是否温度告警（is_temp_alarm）：由后端根据阈值自动计算
- 是否湿度告警（is_humi_alarm）：由后端根据阈值自动计算
- 数据更新时间（report_time）：由设备上报时自动记录

**加载与反馈状态**：
- 页面初始加载：主区域展示卡片骨架屏，加载完成后渲染实际数据。
- 自动刷新：静默刷新，不展示 loading，卡片数据直接替换。
- 历史趋势图加载：图表区域展示加载动画（ECharts 内置 loading 效果）。

### 3.2 目标与范围

**目标**：
1. 以可视化卡片形式展示各料仓的物位传感器最新监测数据（物位百分比和剩余量估算）。

#### 3.4.1 功能流程逻辑

**告警判断规则**：
- 低料位告警：最新物位百分比 ≤ 低料位告警阈值（默认 20.0%）时触发低料位告警。
- 阈值为系统预设值（本期不对外开放配置），后端在返回实时数据时直接标注 `is_low_alarm`（是否低料位告警）字段，前端根据该字段展示告警样式。

**设备状态规则**：
- 在线（online）：传感器设备最近一次数据上报时间在当前时间 5 分钟以内。
- 离线（offline）：传感器设备最近一次数据上报时间超过当前时间 5 分钟且不超过 24 小时。
- 异常（error）：传感器设备最近一次数据上报时间超过当前时间 24 小时，或设备主动上报异常状态。
- 设备状态由后端在实时数据接口中统一计算并返回 `device_status` 字段，前端直接展示。

**数据自动刷新规则**：
- 页面打开后启动定时器，每 60 秒自动调用实时数据接口刷新数据（料仓物位变化较温湿度慢，刷新频率可适当降低）。
- 用户离开该页面（路由切换）时销毁定时器，不在后台继续请求。
- 自动刷新不展示 loading 状态，静默刷新；数据更新后卡片内容自动替换。

**剩余量估算规则**：
- 剩余饲料量（kg）= 料仓设计容量（kg）× 物位百分比（%）÷ 100，计算结果取整数部分。
- 若料仓设计容量未配置，剩余饲料量展示「未配置」。

**无数据情况处理**：
- 某料仓绑定的传感器从未上报数据：展示「暂无数据」占位符。
- 企业无任何料仓绑定传感器：展示空状态图标，提示「暂无监测设备，请联系平台运维人员安装传感器」。

#### 3.4.3 界面交互逻辑

**料仓卡片信息展示规范**：

| 展示项 | 数据来源 | 展示规则 |
|-------|---------|---------|
| 料仓名称 | pig_feed_bin.bin_name | 文字展示 |
| 料仓编号 | pig_feed_bin.bin_code | 文字展示；为空时展示「-」 |
| 设备状态 | pig_iot_device.device_status | 在线：绿色 Tag「在线」；离线：灰色 Tag「离线」；异常：红色 Tag「异常」 |
| 物位百分比 | pig_bin_level.bin_level | 进度条可视化（0%～100%）+ 数值展示（保留1位小数 + %）；设备离线时展示「--.-%」 |
| 剩余饲料量 | 计算值 | 料仓设计容量（kg）× 物位百分比 ÷ 100，取整数；设备离线或容量未配置时展示「-- kg」 |
| 数据更新时间 | pig_bin_level.report_time | 格式：MM-DD HH:mm:ss |
| 告警标记 | is_low_alarm | 正常：无特殊标记；低料位告警：红色左边框 + 告警图标 + 文字「低料位告警」 |

**进度条颜色规则**：
- 物位 > 50%：进度条显示绿色（#67C23A）。
- 物位 20%（含）～ 50%（含）：进度条显示橙色（#E6A23C）。
- 物位 < 20%：进度条显示红色（#F56C6C）。

**筛选区输入校验规范**：

本功能无新增/编辑表单提交场景，筛选区涉及用户输入的字段校验规则如下：

| 筛选字段 | 控件类型 | 校验规则 | 校验时机 | 提示方式 |
|---------|---------|---------|---------|---------|
| 料仓名称 | 文本输入框 | 最大长度100字符，超出截断；仅允许中文、字母、数字、短横线；不允许纯空格 | 点击「查询」按钮时校验 | 输入框下方提示「料仓名称不超过100个字符」 |
| 重置 | 按钮 | 无需校验，点击后清空所有筛选条件并恢复展示全部料仓 | - | - |

**历史趋势图交互**：
- 时间范围 Tab 切换（近1小时/近24小时/近7天）时立即筛选并刷新图表数据，不需要额外点击「查询」按钮；切换过程中展示图表加载状态。
- 当前激活 Tab 有明显选中态样式区分。
- 近1小时：X 轴按每5分钟一个刻度展示；近24小时：X 轴按每1小时一个刻度展示；近7天：X 轴按每天一个刻度展示。
- 折线图悬浮时展示 Tooltip，显示该时刻的物位百分比（%）和剩余量估算（kg）。
- 图表区域在低料位告警阈值处展示参考线（红色虚线标注阈值 20%）。

**自动回显/只读字段说明**：

本功能为纯展示类页面（无新增/编辑表单），所有卡片展示的数据均为后端接口返回的只读数据，前端不提供编辑入口。以下字段由系统自动生成或计算，无需用户干预：
- 设备状态（device_status）：由后端根据设备最近上报时间自动计算
- 是否低料位告警（is_low_alarm）：由后端根据阈值自动计算
- 剩余饲料量：由前端根据设计容量和物位百分比自动计算展示
- 数据更新时间（report_time）：由设备上报时自动记录

**加载与反馈状态**：
- 页面初始加载：主区域展示卡片骨架屏，加载完成后渲染实际数据。
- 自动刷新：静默刷新，不展示 loading，卡片数据直接替换。
- 历史趋势图加载：图表区域展示加载动画。

### 3.5 非功能需求

- **性能**：料仓物位实时数据接口响应时间 < 2 秒（本企业料仓数量不超过30个时）；历史数据接口响应时间 < 3 秒（查询近7天数据量不超过5万条时）。
- **安全与权限**：
  - 权限标识：`farm:monitor:bin-level:list`（查看料仓物位监测）。
  - 数据权限：所有监测接口需以企业维度过滤，后端须校验数据归属于当前登录用户所属企业。数据范围规则遵循 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §2.1，企业管理员（`ent_admin`）和企业填报员（`ent_reporter`）的 data_scope 为「本部门及以下」（值为4），仅能查看本企业数据。
  - 硬件上报接口需设备鉴权（具体鉴权方式待硬件对接技术方案确定）。
- **可用性**：传感器设备离线时，前端展示离线状态和上次有效数据时间，不影响页面正常访问。
- **兼容性**：支持 Chrome 90+、Edge 90+、Firefox 88+；ECharts 图表在主流浏览器中正常渲染；适配 1280×720 及以上分辨率。
