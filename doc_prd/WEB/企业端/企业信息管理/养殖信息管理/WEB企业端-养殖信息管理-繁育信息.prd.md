## 3.2 目标与范围

**目标**：
1. 为养殖企业用户提供WEB端繁育信息填报入口，记录母猪配种、妊娠检查及分娩全过程。
2. 支持系统自动计算预产期（配种日期+114天）。
3. 实现四级审批流程：企业上报→乡镇畜牧兽医站核实→乡镇政府审核→县级审核。
4. 支持数据的新增、草稿保存、提交审核、撤回、修改、查询、导出Excel。
5. 所有角色在同一界面操作，通过操作列按钮区分职责。
6. 县级管理员可直接新增数据（直接入库不走审核）、编辑/删除企业上报数据（留痕）。

**非目标（Non-Goals）**：
- ❌ 不做繁育性能统计分析报表。
- ❌ 不做母猪耳号的全局唯一性强校验（同一企业内需唯一，不做跨企业校验）。

## 3.3 现状与复用

**现状简述**：
- 小程序端已实现繁育信息上报功能，WEB端企业端需新增对应功能，逻辑与小程序端保持一致。

- 业务特殊规则：分娩日期与预产期差异超过7天需备注说明；产仔总数 = 活仔数 + 死胎数（提交前校验）。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 新增繁育信息 | P0 | 弹窗表单填写，支持草稿保存和提交审核 |
| 查询列表 | P0 | 分页查询，支持按企业名称、行政区划、状态、日期范围、母猪耳号筛选 |
| 查看详情 | P0 | 查看完整填报内容及审核进度 |
| 编辑记录 | P0 | 草稿/退回状态可编辑 |
| 删除草稿 | P1 | 仅草稿状态可删除 |
| 撤回提交 | P1 | 待核实状态且乡镇畜牧兽医站未操作时可撤回 |
| 核实通过/退回 | P0 | 乡镇畜牧兽医站对待核实数据进行技术核实 |
| 审核通过/退回 | P0 | 乡镇政府对待审核数据进行行政审核 |
| 终审通过/退回 | P0 | 县级业务人员对待终审数据进行最终审核 |
| 导出Excel | P1 | 支持导出当前筛选结果或勾选数据 |

**关键流程**：

```
繁育信息填报主流程（含审核入库）：

企业用户点击「新增」→ 弹窗表单 → 填写内容
        ↓
  点击「保存草稿」→ 状态：草稿（不校验必填）
        或
  点击「提交审核」→ 前端全量校验
        ├── 校验失败：提示错误字段（含业务规则：产仔总数=活仔数+死胎数）
        └── 校验通过 → 弹出确认弹窗
                → 「提交后将进入审批流程：乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库，提交前请确认信息无误。」
                → 展示摘要：上报类型、配种日期、预产期
                → 确认提交 → 状态：待核实
        ↓

四级审批流程：
  企业提交 → 乡镇畜牧兽医站核实 → 乡镇政府审核 → 县级终审入库

县级管理员直接新增 → 状态直接为「已入库」，不走审批流程
```

**特殊业务规则**：
- 配种日期填写后，系统自动计算并回显预产期（配种日期+114天），预产期字段只读
- 分娩日期与预产期差异超过7天时，弹出提示「分娩日期与预产期相差超过7天，请在备注中说明原因」，并将备注字段标为必填（此时必须填写备注）
- 产仔总数、活仔数、死胎数均填写时，提交前校验：产仔总数须等于活仔数+死胎数，不满足时阻断提交并给出提示

### 3.4.1 功能流程逻辑

**数据状态规则**（与所有填报模块一致）：

| 状态值 | 状态名称 | 显示颜色 | 说明 |
|--------|----------|---------|------|
| `0` | 草稿 | 灰色(#999999) | 企业已保存未提交 |
| `1` | 待核实 | 蓝色(#1890ff) | 等待乡镇畜牧兽医站核实 |
| `2` | 待审核 | 橙色(#fa8c16) | 等待乡镇政府审核 |
| `3` | 待终审 | 紫色(#722ed1) | 等待县级终审 |
| `4` | 已入库 | 绿色(#52c41a) | 终态 |
| `5` | 核实退回 | 红色(#f5222d) | 乡镇畜牧兽医站退回 |
| `6` | 审核退回 | 红色(#f5222d) | 乡镇政府退回 |
| `7` | 终审退回 | 红色(#f5222d) | 县级退回 |

**状态流转规则**：

```
草稿(0) → 待核实(1)               【企业提交】
待核实(1) → 待审核(2)              【乡镇畜牧兽医站核实通过】
待核实(1) → 核实退回(5)            【乡镇畜牧兽医站核实退回】
待核实(1) → 草稿(0)               【企业撤回（乡镇畜牧兽医站未操作前）】
待审核(2) → 待终审(3)              【乡镇政府审核通过】
待审核(2) → 审核退回(6)            【乡镇政府审核退回】
待终审(3) → 已入库(4)              【县级终审通过】
待终审(3) → 终审退回(7)            【县级终审退回】
核实退回(5) → 待核实(1)            【企业修改后重新提交】
审核退回(6) → 待核实(1)            【企业修改后重新提交】
终审退回(7) → 待核实(1)            【企业修改后重新提交】
```

**删除规则**：仅草稿状态（`status=0`）可删除。

**导出规则**：支持导出当前筛选结果或勾选数据。

**导出文件名**：`繁育信息_YYYYMMDD_HHmmss.xlsx`

**预产期自动计算交互**：
- 用户填写配种日期后，系统立即计算并在预产期字段回显（配种日期+114天）
- 预产期字段为只读灰色禁用态，视觉上与可编辑字段有明显区分
- 配种日期清空时，预产期同步清空

**分娩日期与预产期差异校验**：
- 当分娩日期填写后，系统自动计算分娩日期与预产期的差值（天数绝对值）
- 差值 > 7天时：在分娩日期字段下方显示橙色提示文字「分娩日期与预产期相差X天，超过7天，请在备注中说明原因」；备注字段标注为必填（`*`标注变红）
- 差值 ≤ 7天时：不显示提示，备注字段保持选填

**产仔数校验**：
- 提交时，若产仔总数、活仔数、死胎数均已填写，且产仔总数 ≠ 活仔数+死胎数，阻断提交并在产仔总数字段下方提示「产仔总数须等于活仔数（X头）与死胎数（X头）之和」

**前端校验规则（强制）**：

| 字段 | 校验规则 | 校验时机 | 提示文案 |

| 配种日期 | 必填，不能大于当前日期 | 失焦+提交时 | 「请选择配种日期」/「配种日期不能晚于今天」 |

| 妊娠检查日期 | 选填，不能大于当前日期 | 失焦时 | 「妊娠检查日期不能晚于今天」 |

| 产仔总数 | 选填，整数，范围0-30 | 失焦时 | 「产仔总数须在0～30之间」 |
| 活仔数 | 选填，整数，范围0-30 | 失焦时 | 「活仔数须在0～30之间」 |
| 死胎数 | 选填，整数，范围0-30 | 失焦时 | 「死胎数须在0～30之间」 |
| 初生平均重 | 选填，数值，范围0.01-9.99 | 失焦时 | 「初生平均重须在0.01～9.99之间」 |
| 备注 | 分娩日期与预产期差异>7天时必填，最大500字符 | 失焦+提交时 | 「请在备注中说明分娩日期与预产期差异超过7天的原因」 |
| 产仔总数（业务校验） | 须等于活仔数+死胎数 | 提交时 | 「产仔总数须等于活仔数（X头）与死胎数（X头）之和」 |

**提交确认弹窗**：
- 确认文案：「提交后将进入审批流程：乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库，提交前请确认信息无误。」
- 展示摘要信息：上报类型（繁育信息）、配种日期、预产期

**查看详情弹窗**：
- 内容分区展示（字段名左对齐，字段值右对齐，空值显示「—」）：
  - 配种信息：母猪耳号、公猪耳号、配种方式、配种日期、配种次数、预产期
  - 妊娠检查：妊娠检查日期、妊娠结果
  - 分娩信息：分娩日期、产仔总数、活仔数、死胎数、初生平均重、接产员
  - 附件信息：照片附件（缩略图展示，可点击放大）
  - 其他信息：备注、填报人、创建时间
- 审批进度条（4步）：企业提交 → 乡镇畜牧兽医站核实 → 乡镇政府审核 → 县级终审入库
- 退回状态时在详情弹窗顶部显示退回原因

**导出Excel字段顺序**：企业名称、行政区划、母猪耳号、公猪耳号、配种方式、配种日期、配种次数、预产期、妊娠检查日期、妊娠结果、分娩日期、产仔总数、活仔数、死胎数、初生平均重（kg）、接产员、状态、填报人、创建时间、备注

## 3.5 非功能需求

- **性能**：列表首屏加载时间 < 2秒（P95）；表单提交响应时间 < 3秒（P95）；Excel导出响应时间 < 10秒
- **安全与权限**：
  - 企业角色（ent_admin、ent_reporter）：仅本企业数据
  - 乡镇角色（town_vet_station、town_gov_staff）：本乡镇所有企业数据
  - 县级角色（county_admin、county_staff）：全县所有数据
  - 所有接口携带有效JWT Token
- **兼容性**：支持Chrome 90+、Edge 90+、Firefox 88+；桌面端最低分辨率1280×768
