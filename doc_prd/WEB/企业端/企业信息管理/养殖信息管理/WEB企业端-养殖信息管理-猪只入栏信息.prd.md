## 3.1 基本信息

- **功能名称**：猪只入栏信息管理
- **关联现有模块/功能**：
  - 用户认证：依赖现有 JWT Token 认证（`/login`、`/getInfo`）

  - 文件上传：复用现有 `/common/upload` 接口（检疫证照片必传）
  - 数据字典：复用 `/system/dict/data/type/{dictType}` 接口（猪只类型、来源类型）
  - 参考文档：`doc_spec/现有业务说明.spec.md`
- **目标用户/场景**：

| 角色名称 | 角色编码 | 使用场景 | 主要操作 |
|---------|---------|---------|---------|
| 企业管理员 | ent_admin | 管理本企业数据上报 | 新增、编辑、删除草稿、提交审核、撤回 |
| 企业填报员 | ent_reporter | 日常数据填报 | 新增、编辑、删除草稿、提交审核、撤回 |

| 县级业务人员 | county_staff | 最终审核确认入库 | 查看、终审通过入库、终审退回 |

## 3.2 目标与范围

**目标**：
1. 为养殖企业用户提供WEB端猪只入栏信息填报入口，记录猪只来源和入栏详情。
2. 外购猪只必须上传检疫证照片，确保合规性。
3. 实现四级审批流程：企业上报→乡镇畜牧兽医站核实→乡镇政府审核→县级审核。
4. 支持数据的新增、草稿保存、提交审核、撤回、修改、查询、导出Excel。
5. 所有角色在同一界面操作，通过操作列按钮区分职责。
6. 县级管理员可直接新增数据（直接入库不走审核）、编辑/删除企业上报数据（留痕）。

**非目标（Non-Goals）**：
- ❌ 存栏量变更在记录「已入库」后才生效，本功能不直接修改圈舍存栏显示值。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 新增入栏信息 | P0 | 弹窗表单，外购猪只须上传检疫证照片 |
| 查询列表 | P0 | 分页查询，支持按企业名称、行政区划、状态、入栏日期范围、圈舍、来源类型筛选 |
| 查看详情 | P0 | 查看完整填报内容及审核进度 |
| 编辑记录 | P0 | 草稿/退回状态可编辑 |
| 删除草稿 | P1 | 仅草稿状态可删除 |
| 撤回提交 | P1 | 待核实状态且乡镇畜牧兽医站未操作时可撤回 |
| 核实通过/退回 | P0 | 乡镇畜牧兽医站对待核实数据进行技术核实 |
| 审核通过/退回 | P0 | 乡镇政府对待审核数据进行行政审核 |
| 终审通过/退回 | P0 | 县级业务人员对待终审数据进行最终审核 |
| 导出Excel | P1 | 支持导出当前筛选结果或勾选数据 |

**关键流程**：

```
入栏信息填报关键流程：

企业用户新增入栏信息 → 弹窗表单
  → 选择圈舍 → 填写入栏日期、数量等基础信息
  → 选择来源类型：
      外购 → 供应商名称、供应商地址变为必填
      自繁/调拨 → 供应商信息可不填
  → 上传检疫证照片（必传，至少1张）
  → 提交时校验：检疫有效期 ≥ 入栏日期
  → 提交确认弹窗：「提交后将进入审批流程：乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库，提交前请确认信息无误。」
  → 确认后状态变为「待核实」

四级审批流程：
  企业提交 → 乡镇畜牧兽医站核实 → 乡镇政府审核 → 县级终审入库

县级管理员直接新增 → 状态直接为「已入库」，不走审批流程
```

### 3.4.1 功能流程逻辑

**数据状态规则**（与所有填报模块一致）：

| 状态值 | 状态名称 | 显示颜色 | 说明 |
|--------|----------|---------|------|
| `0` | 草稿 | 灰色(#999999) | 企业已保存未提交 |
| `1` | 待核实 | 蓝色(#1890ff) | 等待乡镇畜牧兽医站核实 |
| `2` | 待审核 | 橙色(#fa8c16) | 等待乡镇政府审核 |
| `3` | 待终审 | 紫色(#722ed1) | 等待县级终审 |
| `4` | 已入库 | 绿色(#52c41a) | 终态 |
| `5` | 核实退回 | 红色(#f5222d) | 乡镇畜牧兽医站退回 |
| `6` | 审核退回 | 红色(#f5222d) | 乡镇政府退回 |
| `7` | 终审退回 | 红色(#f5222d) | 县级退回 |

**状态流转规则**：

```
草稿(0) → 待核实(1)               【企业提交】
待核实(1) → 待审核(2)              【乡镇畜牧兽医站核实通过】
待核实(1) → 核实退回(5)            【乡镇畜牧兽医站核实退回】
待核实(1) → 草稿(0)               【企业撤回（乡镇畜牧兽医站未操作前）】
待审核(2) → 待终审(3)              【乡镇政府审核通过】
待审核(2) → 审核退回(6)            【乡镇政府审核退回】
待终审(3) → 已入库(4)              【县级终审通过】
待终审(3) → 终审退回(7)            【县级终审退回】
核实退回(5) → 待核实(1)            【企业修改后重新提交】
审核退回(6) → 待核实(1)            【企业修改后重新提交】
终审退回(7) → 待核实(1)            【企业修改后重新提交】
```

**删除规则**：仅草稿状态（`status=0`）可删除。

**导出规则**：支持导出当前筛选结果或勾选数据。

**导出文件名**：`入栏信息_YYYYMMDD_HHmmss.xlsx`

## 3.5 非功能需求

- **性能**：列表首屏加载 < 2秒（P95）；表单提交 < 3秒（P95）；Excel导出 < 10秒
- **安全与权限**：
  - 企业角色（ent_admin、ent_reporter）：仅本企业数据
  - 乡镇角色（town_vet_station、town_gov_staff）：本乡镇所有企业数据
  - 县级角色（county_admin、county_staff）：全县所有数据
- **兼容性**：支持Chrome 90+、Edge 90+、Firefox 88+；最低分辨率1280×768
