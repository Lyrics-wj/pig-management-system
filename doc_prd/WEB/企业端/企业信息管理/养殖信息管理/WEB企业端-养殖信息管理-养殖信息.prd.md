- **关联现有模块/功能**：

## 3.2 目标与范围

**目标**：
1. 为多角色用户提供统一的WEB端养殖信息管理界面，录入每个圈舍的存栏情况。
2. 实现四级审批流程：企业上报→乡镇畜牧兽医站核实→乡镇政府审核→县级审核，确保数据质量。
3. 支持数据的新增、草稿保存、提交审核、撤回、修改、查询、导出Excel。
4. 所有角色在同一界面完成各自操作，通过操作列按钮区分不同角色的职责。
5. 县级管理员可直接新增数据（不走审核流程，直接入库），并可编辑/删除企业上报数据（留痕）。

**非目标（Non-Goals）**：
- ❌ 不做离线数据采集与同步。
- ❌ 不在本页面做跨模块汇总统计分析。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 新增养殖信息 | P0 | 弹窗表单填写，支持草稿保存和提交审核；县级管理员新增直接入库 |
| 查询列表 | P0 | 分页查询，支持按企业名称、行政区划、状态、日期范围、圈舍筛选 |
| 查看详情 | P0 | 查看完整填报内容及审核进度 |
| 编辑记录 | P0 | 草稿/退回状态可编辑（企业角色）；县级管理员可编辑所有状态数据（留痕） |
| 删除记录 | P1 | 企业角色仅草稿状态可删除；县级管理员可删除所有状态数据（逻辑删除，留痕） |
| 撤回提交 | P1 | 已提交且乡镇畜牧兽医站未操作时可撤回 |
| 核实操作 | P0 | 乡镇畜牧兽医站核实通过/核实退回 |
| 审核操作 | P0 | 乡镇政府业务人员审核通过/审核退回 |
| 终审操作 | P0 | 县级业务人员终审通过入库/终审退回 |
| 导出Excel | P1 | 支持导出当前筛选结果或勾选数据 |

**关键流程**：

```
养殖信息管理主流程（四级审批）：

─── 企业角色操作 ───

企业角色点击「新增」→ 弹窗表单 → 填写内容
        ↓
  点击「保存草稿」→ 状态：草稿（status=0，不校验必填）
        或
  点击「提交审核」→ 前端全量校验 → 校验失败：提示错误字段
                                  → 校验通过：弹出确认弹窗（展示关键信息摘要）
                                              → 确认提交 → 状态：待核实（status=1）

─── 乡镇畜牧兽医站操作 ───

  状态：待核实（等待乡镇畜牧兽医站核实）
        ↓
  乡镇畜牧兽医站操作：
        ├── 核实通过 → 状态：待审核（status=2）
        └── 核实退回（填写退回意见）→ 状态：核实退回（status=5）

─── 乡镇政府业务人员操作 ───

  状态：待审核（等待乡镇政府审核）
        ↓
  乡镇政府业务人员操作：
        ├── 审核通过 → 状态：待终审（status=3）
        └── 审核退回（填写退回意见）→ 状态：审核退回（status=6）

─── 县级业务人员操作 ───

  状态：待终审（等待县级终审）
        ↓
  县级业务人员操作：
        ├── 终审通过 → 状态：已入库（status=4，终态）
        └── 终审退回（填写退回意见）→ 状态：终审退回（status=7）

─── 退回处理 ───

企业角色针对核实退回/审核退回/终审退回状态可编辑后重新提交 → 状态：待核实（status=1）
已提交（待核实）且乡镇畜牧兽医站未操作前可撤回 → 状态：草稿（status=0）

─── 县级管理员直接操作 ───

县级管理员点击「新增」→ 弹窗表单 → 填写内容 → 直接入库（status=4, data_source=2）
县级管理员编辑企业上报数据 → 弹出编辑说明弹窗（必填编辑原因）→ 标记 county_edited=1
县级管理员删除企业上报数据 → 弹出删除说明弹窗（必填删除原因）→ 逻辑删除 county_deleted=1
```

**交互与界面要点**：

- 列表页面包含筛选区、操作栏（新增、导出）、数据列表、分页器
- 新增/编辑使用弹窗表单（Dialog），宽度 600px，内容区域垂直滚动
- 必填字段标红色星号 `*`
- 自动回显字段（企业名称、行政区划、创建时间等）只读展示
- 图片上传支持多张，缩略图右上角显示删除按钮
- 不同角色在同一界面，操作列按钮根据角色和数据状态动态显示

### 3.4.1 功能流程逻辑

**数据状态规则**（本模板定义适用于所有18个填报模块）：

| 状态值 | 状态名称 | 显示颜色 | 说明 |
|--------|----------|---------|------|
| `0` | 草稿 | 灰色(#999999) | 企业已保存未提交 |
| `1` | 待核实 | 蓝色(#1890ff) | 企业已提交，等待乡镇畜牧兽医站核实 |
| `2` | 待审核 | 橙色(#fa8c16) | 乡镇畜牧兽医站已核实，等待乡镇政府审核 |
| `3` | 待终审 | 紫色(#722ed1) | 乡镇政府已审核，等待县级终审 |
| `4` | 已入库 | 绿色(#52c41a) | 终态，县级终审通过 |
| `5` | 核实退回 | 红色(#f5222d) | 乡镇畜牧兽医站退回 |
| `6` | 审核退回 | 红色(#f5222d) | 乡镇政府退回 |
| `7` | 终审退回 | 红色(#f5222d) | 县级退回 |

**状态流转规则**：
- 草稿（`0`）→ 待核实（`1`）：企业提交
- 待核实（`1`）→ 草稿（`0`）：企业撤回（仅乡镇畜牧兽医站未操作前）
- 待核实（`1`）→ 待审核（`2`）：乡镇畜牧兽医站核实通过
- 待核实（`1`）→ 核实退回（`5`）：乡镇畜牧兽医站退回
- 待审核（`2`）→ 待终审（`3`）：乡镇政府审核通过
- 待审核（`2`）→ 审核退回（`6`）：乡镇政府退回
- 待终审（`3`）→ 已入库（`4`）：县级终审通过
- 待终审（`3`）→ 终审退回（`7`）：县级退回
- 核实退回（`5`）→ 待核实（`1`）：企业修改后重新提交
- 审核退回（`6`）→ 待核实（`1`）：企业修改后重新提交
- 终审退回（`7`）→ 待核实（`1`）：企业修改后重新提交
- 已入库（`4`）：终态，不可流转

**删除规则**：
- 企业角色：仅「草稿」状态可删除（逻辑删除，`del_flag=2`）；已提交及以后状态不可删除。
- 县级管理员：可删除所有状态数据（逻辑删除，`county_deleted=1`），删除时必须填写删除原因；企业端用户在该条数据上看到删除标记和原因。

**导出规则**：
- 列表中有勾选行时，仅导出勾选的数据行
- 列表中无勾选时，导出当前筛选条件下的全部数据（不受分页限制）
- 导出文件名：`养殖信息_YYYYMMDD_HHmmss.xlsx`

**存栏量变更规则**：存栏量变更仅在记录状态变为「已入库」时正式生效，草稿和审核中不影响统计。

## 3.5 非功能需求

- **性能**：列表首屏加载时间 < 2秒（P95）；表单提交响应时间 < 3秒（P95）；Excel导出响应时间 < 10秒（万条以内数据）
- **安全与权限**：
  - 企业角色（ent_admin/ent_reporter）：仅能查看和操作本企业的填报数据（按 enterprise_id 隔离）
  - 乡镇角色（town_vet_station/town_gov_staff）：可查看本乡镇所有企业数据（按部门树 data_scope='4' 隔离）
  - 县级角色（county_admin/county_staff）：可查看全县所有数据（data_scope='1'）
  - 所有接口携带有效JWT Token
  - 操作权限后端二次校验：核实操作仅 town_vet_station 可执行，审核操作仅 town_gov_staff 可执行，终审操作仅 county_staff 可执行，县级编辑/删除仅 county_admin 可执行
- **兼容性**：支持Chrome 90+、Edge 90+、Firefox 88+浏览器；桌面端最低分辨率1280×768

## 3.6 验收标准

- [ ] 不同角色登录后列表页正确显示对应权限范围内的养殖信息记录，按创建时间倒序排列
- [ ] 企业端角色不显示「企业名称」和「行政区划」列及筛选项；监管端角色正确显示
- [ ] 企业名称筛选（模糊搜索）、行政区划筛选（级联选择）、状态筛选、日期范围筛选、圈舍筛选均生效，筛选条件变化后自动刷新列表
- [ ] 状态筛选下拉正确显示8种状态：全部/草稿/待核实/待审核/待终审/已入库/核实退回/审核退回/终审退回
- [ ] 企业角色点击「新增」弹出表单弹窗，所有字段渲染正确，必填字段标注「*」
- [ ] 统计日期默认填充当前日期，不能选择未来日期
- [ ] 必填字段未填时提交，字段下方显示错误提示，阻断提交
- [ ] 保存草稿不触发必填校验，状态保存为草稿（`status=0`）
- [ ] 提交审核时弹出确认弹窗，展示关键信息摘要和审核流程提示（四级审批描述）
- [ ] 确认提交后状态变为「待核实」（`status=1`），操作成功Toast提示
- [ ] 草稿和退回状态（核实退回/审核退回/终审退回）记录可编辑，其他状态记录不可编辑（企业角色）
- [ ] 企业角色仅草稿状态记录可删除，点击删除弹出确认弹窗
- [ ] 待核实且乡镇畜牧兽医站未操作时显示「撤回」按钮，撤回后状态变回草稿
- [ ] 乡镇畜牧兽医站角色在待核实状态看到「核实通过」「核实退回」按钮，核实通过后状态变为待审核（`status=2`）
- [ ] 乡镇畜牧兽医站核实退回时必须填写退回意见（最少10字符），退回后状态变为核实退回（`status=5`）
- [ ] 乡镇政府业务人员角色在待审核状态看到「审核通过」「审核退回」按钮，审核通过后状态变为待终审（`status=3`）
- [ ] 乡镇政府审核退回时必须填写退回意见（最少10字符），退回后状态变为审核退回（`status=6`）
- [ ] 县级业务人员角色在待终审状态看到「终审通过」「终审退回」按钮，终审通过后状态变为已入库（`status=4`）
- [ ] 县级终审退回时必须填写退回意见（最少10字符），退回后状态变为终审退回（`status=7`）
- [ ] 退回后企业角色可编辑并重新提交，重新提交后状态回到待核实（`status=1`）
- [ ] 查看详情弹窗正确展示4步审核进度步骤条：企业提交→乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库
- [ ] 退回状态详情弹窗顶部显示红色退回原因提示，对应显示核实退回/审核退回/终审退回的意见
- [ ] 县级管理员可新增数据直接入库（`data_source='2'`，`status='4'`），不显示步骤条
- [ ] 县级管理员编辑企业上报数据时弹出编辑说明弹窗，必须填写编辑原因（最少10字符），编辑后 `county_edited='1'`
- [ ] 县级管理员删除企业上报数据时弹出删除说明弹窗，必须填写删除原因（最少10字符），删除后 `county_deleted='1'`
- [ ] 企业端用户在被县级编辑/删除的数据行看到警告图标，点击可查看编辑/删除日志
- [ ] 导出Excel：有勾选时导出勾选数据，无勾选时导出当前筛选全部数据
- [ ] 导出文件名格式正确，内容包含所有规定字段（含企业名称、行政区划、数据来源），状态列显示中文
- [ ] 列表复选框支持全选/全不选/跨页不累计
- [ ] 空数据时展示空状态
- [ ] 后端接口对操作权限进行二次校验，非对应角色调用审核接口返回403

## 3.7 附录

**确认提交弹窗信息摘要字段**：上报类型（养殖信息）、圈舍名称、统计日期

**状态标签颜色规范**：
- 草稿：`#999999`（灰色）背景浅灰
- 待核实：`#1890ff`（蓝色）背景浅蓝
- 待审核：`#fa8c16`（橙色）背景浅橙
- 待终审：`#722ed1`（紫色）背景浅紫
- 已入库：`#52c41a`（绿色）背景浅绿
- 核实退回：`#f5222d`（红色）背景浅红
- 审核退回：`#f5222d`（红色）背景浅红
- 终审退回：`#f5222d`（红色）背景浅红

**数据来源标签颜色规范**：
- 企业上报：`#1890ff`（蓝色）
- 县级直接录入：`#722ed1`（紫色）

**审核进度步骤条规范**：
- 步骤1：企业提交（对应 status 从 `0` 到 `1`）
- 步骤2：乡镇畜牧兽医站核实（对应 status 从 `1` 到 `2`）
- 步骤3：乡镇政府审核（对应 status 从 `2` 到 `3`）
- 步骤4：县级终审入库（对应 status 从 `3` 到 `4`）
