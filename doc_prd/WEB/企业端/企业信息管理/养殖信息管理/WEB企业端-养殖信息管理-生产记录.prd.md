## 3.2 目标与范围

**目标**：
1. 为养殖企业用户提供WEB端生产记录填报入口。
2. 为关键字段提供感叹号图标提示（Tooltip），引导正确填写。
3. 实现乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库的四级审批流程（企业提交→核实→审核→终审入库）。
4. 支持数据的新增、草稿保存、提交审核、撤回、修改、查询、导出Excel。
5. 为企业端、乡镇端、县级端提供统一的列表和详情查看界面，各角色按权限看到对应的操作按钮。
6. 县级管理员可直接新增记录（状态直接为「已入库」，跳过审批流程）。

**非目标（Non-Goals）**：
- ❌ 不做自动存栏统计汇总（变动数据仅作记录用途）。
- ❌ 不做离线数据采集与同步。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 新增生产记录 | P0 | 弹窗表单，关键字段提供Tooltip提示 |
| 查询列表 | P0 | 分页查询，支持按企业名称、行政区划、状态、变动日期范围筛选 |
| 查看详情 | P0 | 查看完整填报内容及审核进度（四级审批步骤条） |
| 编辑记录 | P0 | 草稿/退回状态可编辑 |
| 删除草稿 | P1 | 仅草稿状态可删除 |
| 撤回提交 | P1 | 已提交且乡镇畜牧兽医站未操作时可撤回 |
| 导出Excel | P1 | 支持导出当前筛选结果或勾选数据 |
| 核实操作 | P0 | 乡镇畜牧兽医站对待核实数据进行核实通过/退回 |
| 审核操作 | P0 | 乡镇政府业务人员对待审核数据进行审核通过/退回 |
| 终审操作 | P0 | 县级业务人员对待终审数据进行终审通过入库/退回 |

**关键流程**：

```
生产记录填报主流程（四级审批）：

企业用户点击「新增」→ 弹窗表单 → 填写内容
        ↓
  点击「保存草稿」→ 状态：草稿（不校验必填）
        或
  点击「提交审核」→ 前端全量校验 → 校验失败：提示错误字段
                                  → 校验通过：弹出确认弹窗
                                              → 确认提交 → 状态：待核实
        ↓
  状态：待核实（等待乡镇畜牧兽医站核实）
        ↓
  乡镇畜牧兽医站核实
        ├── 核实通过 → 状态：待审核（等待乡镇政府审核）
        │                     ↓
        │             乡镇政府业务人员审核
        │                     ├── 审核通过 → 状态：待终审（等待县级终审）
        │                     │                     ↓
        │                     │             县级业务人员终审
        │                     │                     ├── 终审通过 → 状态：已入库（终态）
        │                     │                     └── 终审退回 → 状态：终审退回
        │                     └── 审核退回 → 状态：审核退回
        └── 核实退回 → 状态：核实退回

企业用户针对退回状态（核实退回/审核退回/终审退回）可编辑后重新提交。
已提交（待核实）且乡镇畜牧兽医站未操作前可撤回。

县级管理员直接新增 → 状态：已入库（跳过审批流程）
```

**交互与界面要点**：

- 列表页面包含筛选区、操作栏（新增、导出）、数据列表、分页器
- 新增/编辑使用弹窗表单（Dialog），宽度 700px，内容区域垂直滚动
- 必填字段标红色星号 `*`
- 自动回显字段（企业名称、创建时间等）只读展示
- 图片上传支持多张，缩略图右上角显示删除按钮

### 3.4.1 功能流程逻辑

**数据状态规则**：

| 状态值 | 状态名称 | 显示颜色 | 说明 |
|--------|----------|---------|------|
| `0` | 草稿 | 灰色(#999999) | 企业已保存未提交 |
| `1` | 待核实 | 蓝色(#1890ff) | 等待乡镇畜牧兽医站核实 |
| `2` | 待审核 | 橙色(#fa8c16) | 等待乡镇政府审核 |
| `3` | 待终审 | 紫色(#722ed1) | 等待县级终审 |
| `4` | 已入库 | 绿色(#52c41a) | 终态 |
| `5` | 核实退回 | 红色(#f5222d) | 乡镇畜牧兽医站退回 |
| `6` | 审核退回 | 红色(#f5222d) | 乡镇政府退回 |
| `7` | 终审退回 | 红色(#f5222d) | 县级退回 |

**各角色可操作动作**：

| 状态 | 企业管理员/填报员 | 乡镇畜牧兽医站 | 乡镇政府业务人员 | 县级管理员 | 县级业务人员 |
|------|----------------|-------------|---------------|-----------|------------|
| 草稿 | 编辑、删除、提交 | - | - | 编辑、删除 | - |
| 待核实 | 查看、撤回 | 核实通过、核实退回 | - | 查看 | - |
| 待审核 | 查看 | 查看 | 审核通过、审核退回 | 查看 | - |
| 待终审 | 查看 | 查看 | 查看 | 查看 | 终审通过、终审退回 |
| 已入库 | 查看 | 查看 | 查看 | 查看、编辑、删除 | 查看 |
| 核实退回 | 编辑、重新提交 | 查看 | - | 查看 | - |
| 审核退回 | 编辑、重新提交 | 查看 | 查看 | 查看 | - |
| 终审退回 | 编辑、重新提交 | 查看 | 查看 | 查看 | 查看 |

**状态流转规则**：
- 草稿 → 待核实：企业用户点击「提交审核」
- 待核实 → 草稿：企业用户点击「撤回」（仅限乡镇畜牧兽医站未操作时）
- 待核实 → 待审核：乡镇畜牧兽医站核实通过
- 待核实 → 核实退回：乡镇畜牧兽医站核实退回
- 待审核 → 待终审：乡镇政府审核通过
- 待审核 → 审核退回：乡镇政府审核退回
- 待终审 → 已入库：县级业务人员终审通过
- 待终审 → 终审退回：县级业务人员终审退回
- 核实退回 → 待核实：企业用户修改后重新提交
- 审核退回 → 待核实：企业用户修改后重新提交
- 终审退回 → 待核实：企业用户修改后重新提交
- 已入库：终态，不可流转

**删除规则**：仅「草稿」状态可删除（逻辑删除，del_flag=2）；已提交及以后状态不可删除。县级管理员可删除任意状态。

**导出规则**：
- 列表中有勾选行时，仅导出勾选的数据行
- 列表中无勾选时，导出当前筛选条件下的全部数据（不受分页限制）
- 导出文件名：`生产记录_YYYYMMDD_HHmmss.xlsx`

- 全部字段只读，不可编辑

**撤回操作**：
- 入口：列表操作列「撤回」按钮（仅「待核实」且乡镇畜牧兽医站未操作时显示）
- 点击后弹出确认弹窗：「确认撤回该记录？撤回后状态变为草稿，可重新编辑。」，含「取消」和「确认撤回」按钮
- 确认后：状态变为草稿（`status=0`），操作结果Toast提示「撤回成功」

**删除操作**：
- 仅草稿状态可删除（县级管理员不受此限制）
- 点击「删除」后弹出确认弹窗：「确认删除该草稿记录？删除后不可恢复。」，含「取消」和「确认删除」按钮
- 支持批量删除（勾选多条草稿后，列表上方显示「批量删除」按钮）

**导出Excel**：
- 导出字段顺序：企业名称、行政区划、变动日期、圈舍类别、变动情况（数量）、存栏数、状态、填报人、创建时间、备注
- 状态字段导出为中文名称（草稿/待核实/待审核/待终审/已入库/核实退回/审核退回/终审退回）
- 导出时显示loading状态，完成后自动下载文件
- 导出文件名：`生产记录_YYYYMMDD_HHmmss.xlsx`

**核实/审核/终审退回操作**：
- 退回时弹出退回原因弹窗，退回意见为必填（最少10字符），点击确认后执行退回
- 通过操作需二次确认弹窗

**其他交互细节**：
- 列表首次加载及筛选条件变化时显示loading状态
- 筛选条件变化后自动触发查询，无需手动点击查询按钮
- 列表空数据时展示空状态插图及「暂无数据」文字
- 列表支持列宽拖拽调整（操作列固定）

## 3.5 非功能需求

- **性能**：列表首屏加载时间 < 2秒（P95）；表单提交响应时间 < 3秒（P95）；Excel导出响应时间 < 10秒（万条以内数据）
- **安全与权限**：

| 角色 | 数据范围 | 操作权限 |
|------|---------|---------|
| 企业管理员/填报员 | 仅本企业数据 | 新增、编辑（草稿/退回）、删除草稿、提交、撤回 |
| 乡镇畜牧兽医站 | 本辖区所有企业数据 | 查看、核实通过、核实退回 |
| 乡镇政府业务人员 | 本辖区所有企业数据 | 查看、审核通过、审核退回 |
| 县级管理员 | 全县所有数据 | 新增（直接入库）、编辑、删除、查看 |
| 县级业务人员 | 全县所有数据 | 查看、终审通过、终审退回 |

- **兼容性**：支持Chrome 90+、Edge 90+、Firefox 88+浏览器；桌面端最低分辨率1280×768
