## 3.2 目标与范围

**目标**：
1. 为养殖企业用户提供WEB端饲料和饲料添加剂购进记录填报入口。
2. 根据产品类型动态控制批准文号字段的必填性。
3. 为关键字段提供感叹号图标提示（Tooltip），引导正确填写。
4. 实现乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库的四级审批流程（含企业提交），确保数据质量。
5. 支持数据的新增、草稿保存、提交审核、撤回、修改、查询、导出Excel。
6. 提供统一的多角色操作界面，企业端与监管端共用同一套列表/详情组件，按角色权限动态控制可见字段与操作按钮。
7. 县级管理员可直接新增数据并以「已入库」状态入库，无需走审批流程。

**非目标（Non-Goals）**：
- ❌ 不做饲料库存管理。
- ❌ 不做离线数据采集与同步。
- ❌ 不在本页面做跨模块汇总统计分析。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 新增饲料购进记录 | P0 | 弹窗表单，关键字段提供Tooltip提示 |

| 删除草稿 | P1 | 仅草稿状态可删除 |
| 撤回提交 | P1 | 已提交且乡镇畜牧兽医站未操作时可撤回 |
| 导出Excel | P1 | 支持导出当前筛选结果或勾选数据 |

**关键流程**：

```
饲料和饲料添加剂购进记录填报主流程（含四级审批）：

企业用户点击「新增」→ 弹窗表单 → 填写内容
        ↓
  点击「保存草稿」→ 状态：草稿（不校验必填）
        或
  点击「提交审核」→ 前端全量校验 → 校验失败：提示错误字段
                                  → 校验通过：弹出确认弹窗（展示关键信息摘要）
                                              → 确认提交 → 状态：待核实
        ↓
  状态：待核实（等待乡镇畜牧兽医站核实）
        ↓
  乡镇畜牧兽医站核实
        ├── 核实通过 → 状态：待审核（等待乡镇政府审核）
        │                     ↓
        │             乡镇政府业务人员审核
        │                     ├── 审核通过 → 状态：待终审（等待县级终审）
        │                     │                     ↓
        │                     │             县级业务人员终审
        │                     │                     ├── 终审通过 → 状态：已入库（终态）
        │                     │                     └── 终审退回 → 状态：终审退回
        │                     └── 审核退回 → 状态：审核退回
        └── 核实退回 → 状态：核实退回

企业用户针对退回状态（核实退回/审核退回/终审退回）可编辑后重新提交。
已提交（待核实）且乡镇畜牧兽医站未操作前可撤回。
县级管理员新增数据直接以「已入库」状态入库。
```

**交互与界面要点**：

- 列表页面包含筛选区、操作栏（新增、导出）、数据列表、分页器
- 新增/编辑使用弹窗表单（Dialog），宽度 700px，内容区域垂直滚动
- 必填字段标红色星号 `*`
- 自动回显字段（企业名称、创建时间等）只读展示

### 3.4.1 功能流程逻辑

**数据状态规则**：

| 状态值 | 状态名称 | 显示颜色 | 说明 |
|--------|----------|---------|------|
| `0` | 草稿 | 灰色(#999999) | 企业已保存未提交 |

| `2` | 待审核 | 橙色(#fa8c16) | 等待乡镇政府审核 |
| `3` | 待终审 | 紫色(#722ed1) | 等待县级终审 |
| `4` | 已入库 | 绿色(#52c41a) | 终态 |
| `5` | 核实退回 | 红色(#f5222d) | 乡镇畜牧兽医站退回 |
| `6` | 审核退回 | 红色(#f5222d) | 乡镇政府退回 |
| `7` | 终审退回 | 红色(#f5222d) | 县级退回 |

**各角色可操作动作**：

| 状态 | 企业管理员/填报员 | 乡镇畜牧兽医站 | 乡镇政府业务人员 | 县级业务人员 | 县级管理员 |
|------|----------------|--------------|----------------|------------|-----------|
| 草稿 | 编辑、删除、提交 | — | — | — | 编辑、删除 |
| 待核实 | 查看、撤回 | 核实通过、核实退回 | — | — | 查看 |
| 待审核 | 查看 | 查看 | 审核通过、审核退回 | — | 查看 |
| 待终审 | 查看 | 查看 | 查看 | 终审通过、终审退回 | 查看 |
| 已入库 | 查看 | 查看 | 查看 | 查看 | 查看、编辑、删除 |
| 核实退回 | 编辑、重新提交 | 查看 | — | — | 查看、编辑 |
| 审核退回 | 编辑、重新提交 | 查看 | 查看 | — | 查看、编辑 |
| 终审退回 | 编辑、重新提交 | 查看 | 查看 | 查看 | 查看、编辑 |

**状态流转规则**：
- 草稿 → 待核实：企业用户点击「提交审核」
- 待核实 → 草稿：企业用户点击「撤回」（仅限乡镇畜牧兽医站未操作时）
- 待核实 → 待审核：乡镇畜牧兽医站核实通过
- 待核实 → 核实退回：乡镇畜牧兽医站核实退回
- 待审核 → 待终审：乡镇政府审核通过
- 待审核 → 审核退回：乡镇政府审核退回
- 待终审 → 已入库：县级业务人员终审通过
- 待终审 → 终审退回：县级业务人员终审退回
- 核实退回 → 待核实：企业用户修改后重新提交
- 审核退回 → 待核实：企业用户修改后重新提交
- 终审退回 → 待核实：企业用户修改后重新提交
- 已入库：终态，不可流转
- 县级管理员新增：直接 → 已入库（跳过审批流程）

**删除规则**：仅「草稿」状态可删除（逻辑删除，del_flag=2）；已提交及以后状态不可删除。县级管理员可删除任意状态数据。

**导出规则**：
- 列表中有勾选行时，仅导出勾选的数据行
- 列表中无勾选时，导出当前筛选条件下的全部数据（不受分页限制）
- 导出文件名：`饲料和饲料添加剂购进记录_YYYYMMDD_HHmmss.xlsx`

| 8 | 含药物添加剂信息 ⓘ | 选填 | 文本域，最大500字符 | 指饲料厂家在配合饲料等饲料产品中加入的药物添加剂的名称及每公斤饲料或添加剂中含药物添加剂的量。未加药物添加剂的不填此项 |
| 9 | 单位 ⓘ | 必填 | 文本输入，最大20字符 | 指袋、公斤、吨等，由养殖场根据购进不同的饲料和饲料添加剂产品实际情况填写 |
| 10 | 数量 ⓘ | 必填 | 数字输入，范围0.01-99999.99 | 指购进饲料和饲料添加剂的数量，要与前面的数量单位相对应 |
| 11 | 供货单位名称与地址 ⓘ | 必填 | 文本域，最大300字符 | 指在哪个饲料经营企业购的饲料和饲料添加剂。如从厂家购进，直接填厂家 |
| 12 | 购货人 ⓘ | 必填 | 文本输入，最大50字符 | 指亲自采购饲料和饲料添加剂的人 |
| 13 | 备注 | 选填 | 文本域，最大500字符 | - |

- 弹窗底部按钮（左对齐）：「保存草稿」（默认样式）、「提交审核」（主色按钮）、「取消」（文字按钮）
- 编辑时：草稿/核实退回/审核退回/终审退回状态可编辑，其他状态表单只读不可编辑

**批准文号动态必填规则**：
- 产品类型选择「添加剂预混合饲料」或「饲料添加剂」时：批准文号标注「*」变为必填
- 产品类型选择「配合饲料」、「浓缩饲料」、「精料补充料」时：批准文号标注「*」变为必填
- 产品类型选择「单一饲料」时：批准文号为选填

**Tooltip交互规范**：与配合饲料使用记录模块完全一致（hover触发，样式规范同）。

**前端校验规则（强制）**：

| 字段 | 校验规则 | 校验时机 | 提示文案 |
|-----|---------|---------|---------|
| 购进日期 | 必填，不能大于当前日期 | 失焦+提交时 | 「请选择购进日期」/「购进日期不能晚于今天」 |
| 产品名称 | 必填，最大200字符 | 失焦+提交时 | 「产品名称不能为空」 |
| 产品类型 | 必填，枚举值6种之一 | 提交时 | 「请选择产品类型」 |
| 生产厂家 | 必填，最大200字符 | 失焦+提交时 | 「生产厂家不能为空」 |
| 批准文号 | 产品类型非单一饲料时必填 | 失焦+提交时 | 「该产品类型须填写批准文号（审查合格证号）」 |
| 单位 | 必填，最大20字符 | 失焦+提交时 | 「单位不能为空」 |
| 数量 | 必填，数值，范围0.01-99999.99 | 失焦+提交时 | 「数量不能为空」/「数量须在0.01～99999.99之间」 |
| 供货单位名称与地址 | 必填，最大300字符 | 失焦+提交时 | 「供货单位名称与地址不能为空」 |
| 购货人 | 必填，最大50字符 | 失焦+提交时 | 「购货人不能为空」 |

- 保存草稿时不触发必填校验，仅校验填入值的格式/范围
- 提交审核时：先执行全量必填校验，通过后弹出确认弹窗；校验失败时显示错误提示，阻断提交
- 确认弹窗展示关键信息：上报类型（饲料和饲料添加剂购进记录）、购进日期、产品名称、数量、单位；底部提示文字：「提交后将进入审批流程：乡镇畜牧兽医站核实→乡镇政府审核→县级终审入库，提交前请确认信息无误。」

**查看详情弹窗**：
- 弹窗标题：「饲料和饲料添加剂购进记录详情」
- 弹窗顶部显示当前状态标签
- 若状态为核实退回/审核退回/终审退回，在顶部显示红色背景提示框展示退回原因
- 审核进度步骤条：步骤1（养殖场提交）→ 步骤2（乡镇畜牧兽医站核实）→ 步骤3（乡镇政府审核）→ 步骤4（县级终审入库）
- 分区展示（字段名左对齐，字段值右对齐，空值显示「—」）：
  - 基本信息：购进日期、产品名称、产品类型
  - 产品信息：生产厂家、生产许可证编号、批准文号、生产日期、含药物添加剂信息
  - 购进信息：数量、单位、供货单位名称与地址、购货人
  - 其他信息：备注、填报人、创建时间
- 全部字段只读，不可编辑

**撤回操作**：
- 入口：列表操作列「撤回」按钮（仅「待核实」且乡镇畜牧兽医站未操作时显示）
- 点击后弹出确认弹窗：「确认撤回该记录？撤回后状态变为草稿，可重新编辑。」，含「取消」和「确认撤回」按钮
- 确认后：状态变为草稿（`status=0`），操作结果Toast提示「撤回成功」

**删除操作**：
- 仅草稿状态可删除（县级管理员可删除任意状态）
- 点击「删除」后弹出确认弹窗：「确认删除该草稿记录？删除后不可恢复。」，含「取消」和「确认删除」按钮
- 支持批量删除（勾选多条草稿后，列表上方显示「批量删除」按钮）

**导出Excel**：
- 点击「导出Excel」按钮：
  - 若列表中有勾选行：导出勾选的数据行
  - 若无勾选：导出当前筛选条件下的全部数据
- 导出字段顺序：企业名称、行政区划、购进日期、产品名称、产品类型、生产厂家、生产许可证编号、批准文号、生产日期、含药物添加剂信息、单位、数量、供货单位名称与地址、购货人、状态、填报人、创建时间、备注
- 状态字段导出为中文名称（草稿/待核实/待审核/待终审/已入库/核实退回/审核退回/终审退回）
- 导出时显示loading状态，完成后自动下载文件
- 导出文件名：`饲料和饲料添加剂购进记录_YYYYMMDD_HHmmss.xlsx`

**其他交互细节**：
- 列表首次加载及筛选条件变化时显示loading状态
- 筛选条件变化后自动触发查询，无需手动点击查询按钮（日期选择器选择完成后触发，下拉框切换后立即触发）
- 列表空数据时展示空状态插图及「暂无数据」文字
- 列表支持列宽拖拽调整（操作列固定）

## 3.5 非功能需求

- **性能**：列表首屏加载时间 < 2秒（P95）；表单提交响应时间 < 3秒（P95）；Excel导出响应时间 < 10秒（万条以内数据）
- **安全与权限**：

| 角色 | 数据范围 | 操作权限 |
|------|---------|---------|
| 企业管理员/填报员 | 仅本企业数据 | 新增、编辑草稿/退回、删除草稿、提交、撤回 |
| 乡镇畜牧兽医站 | 所辖乡镇全部企业数据 | 查看、核实通过/退回 |
| 乡镇政府业务人员 | 所辖乡镇全部企业数据 | 查看、审核通过/退回 |
| 县级管理员 | 全县所有数据 | 新增（直接入库）、编辑、删除、查看全部 |
| 县级业务人员 | 全县所有数据 | 查看、终审通过/退回 |

- **兼容性**：支持Chrome 90+、Edge 90+、Firefox 88+浏览器；桌面端最低分辨率1280×768
