# 功能一：用户注册与登录

## 3.1 基本信息

- **功能名称**：用户注册与登录
- **关联现有模块/功能**：
  - 用户认证：平台用户依赖现有 JWT Token 认证（`/login`、`/getInfo`）
  - 用户管理：平台用户存储在 `sys_user` 表；生猪知识讲堂独立注册用户存储在新表 `kc_user`，与 `sys_user` 完全隔离
  - 参考文档：`doc_spec/现有业务说明.spec.md`、`doc_spec/现有数据库说明.spec.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（引用自全局权限体系 §1.1） | 使用场景 | 主要需求 |
|---------|--------------------------------------|---------|---------|
| 企业管理员 | ent_admin | 使用平台账号直接登录知识讲堂网站 | 无需重复注册，使用已有账号密码登录 |
| 企业填报员 | ent_reporter | 使用平台账号直接登录知识讲堂网站 | 无需重复注册，使用已有账号密码登录 |
| 企业学习用户（小程序） | mp_learner | 使用平台账号直接登录知识讲堂网站 | 无需重复注册，使用已有账号密码登录 |
| 公众用户（非平台用户） | 无（独立用户体系） | 通过知识讲堂网站自行注册账号 | 注册、登录、修改个人信息，浏览公开内容 |

---

## 3.2 目标与范围

**目标**：
1. 为平台已有用户（企业管理员、企业填报员、企业学习用户）提供使用平台账号密码直接登录知识讲堂网站的能力。
2. 为非平台公众用户提供独立注册入口，注册后可浏览公开内容、参与论坛问答。
3. 知识讲堂独立注册用户与系统用户（`sys_user`）完全隔离，独立管理。
4. 登录用户可修改个人信息（昵称、头像、手机号、密码）。

**非目标（Non-Goals）**：
- 不支持第三方社交账号登录（微信、QQ）。
- 不支持公众用户通过网站注册获得平台系统权限（企业端、监管端功能不开放给公众用户）。
- 不提供后台用户管理界面（后台管理见 `WEB-生猪知识讲堂后台管理-用户管理.prd.md`）。

## 3.3 现状与复用

**现状简述**：
- 系统已有 JWT Token 认证体系和 `sys_user` 用户表，平台用户可复用此认证。
- 知识讲堂网站面向公众开放，需新增独立用户表 `kc_user`。
- 登录时需区分平台用户（查 `sys_user`）和知识讲堂独立用户（查 `kc_user`），优先匹配 `sys_user`，未匹配再查 `kc_user`。

**复用检查结论**：

| 检查项 | 现有资源 | 复用结论 | 说明 |
|--------|---------|---------|------|
| 平台用户登录接口 | `/login` | 🔧 改造复用 | 知识讲堂登录接口需独立，但平台用户的认证逻辑复用已有 JWT 颁发机制 |
| 用户信息获取接口 | `/getInfo` | 🔧 改造复用 | 知识讲堂登录后获取用户信息，平台用户复用已有接口逻辑 |
| 系统用户表 | `sys_user` | ✅ 直接复用 | 平台用户登录时查询此表验证 |
| 字典数据接口 | `/system/dict/data/type/{dictType}` | ✅ 直接复用 | 地区下拉数据 |
| 文件上传接口 | `/common/upload` | ✅ 直接复用 | 头像上传 |
| 知识讲堂独立用户表 | 无 | 🆕 新建表 `kc_user` | 存储知识讲堂网站独立注册用户，与 sys_user 隔离 |
| 知识讲堂登录接口 | 无 | 🆕 新增 `/kc-portal/auth/login` | 知识讲堂专用登录接口 |
| 知识讲堂注册接口 | 无 | 🆕 新增 `/kc-portal/auth/register` | 公众用户注册接口 |

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 用户登录（平台用户+独立用户） | P0 | 统一登录入口，后端自动识别用户来源 |
| 公众用户注册 | P0 | 手机号+验证码注册，设置密码 |
| 个人信息查看与修改 | P1 | 登录后可修改昵称、头像、手机号 |
| 修改密码 | P1 | 登录后可修改登录密码 |
| 退出登录 | P0 | 清除登录态 |
| 忘记密码 | P1 | 通过手机号验证码重置密码 |

**关键流程**：

```
登录流程：
进入登录页 → 输入用户名/手机号 + 密码 → 前端校验 → 提交登录
  → 后端先查 sys_user 匹配
    ├── 匹配成功 → 颁发 JWT Token（标记用户来源为 platform）→ 跳转首页
    └── 未匹配 → 再查 kc_user 匹配
        ├── 匹配成功 → 颁发 JWT Token（标记用户来源为 kc_portal）→ 跳转首页
        └── 未匹配 → 返回「用户名或密码错误」

注册流程：
进入注册页 → 输入手机号 → 获取短信验证码 → 输入验证码 → 设置昵称 → 设置密码 + 确认密码
  → 前端校验 → 提交注册
    → 后端校验手机号唯一性（kc_user 表和 sys_user 表均不存在该手机号）
      ├── 通过 → 写入 kc_user → 自动登录 → 跳转首页
      └── 手机号已存在 → 返回「该手机号已注册，请直接登录」

忘记密码流程：
点击「忘记密码」→ 输入手机号 → 获取短信验证码 → 输入验证码 → 设置新密码 + 确认密码
  → 提交 → 后端查询 kc_user 表
    ├── 存在该手机号 → 更新密码 → 提示「密码重置成功，请重新登录」
    └── 不存在 → 返回「该手机号未注册」
注意：忘记密码功能仅支持知识讲堂独立用户（kc_user），平台用户密码重置须通过平台系统管理完成
```

**交互与界面要点**：
- 登录页为网站独立页面，居中卡片布局
- 登录表单包含：用户名/手机号输入框、密码输入框、「登录」按钮
- 登录页底部提供「注册账号」和「忘记密码」链接
- 注册页为独立页面，表单包含：手机号、验证码、昵称、密码、确认密码
- 登录后右上角显示用户昵称/头像，点击下拉菜单展示「个人中心」「退出登录」

### 3.4.1 功能流程逻辑

**登录认证逻辑**：
- 登录时后端按以下顺序匹配用户：
  1. 查询 `sys_user` 表，按 `user_name` 或 `phonenumber` 匹配
  2. 若 `sys_user` 未匹配，查询 `kc_user` 表，按 `user_name` 或 `phone` 匹配
  3. 匹配成功后校验密码（密码加密方式与平台一致，使用 BCrypt），通过则颁发 JWT Token
  4. Token 中携带 `user_source` 字段标识用户来源：`platform`（平台用户）或 `kc_portal`（知识讲堂独立用户）
- 账号被禁用（`status='1'`）时返回「该账号已被禁用，请联系管理员」

**验证码发送规则**：
- 同一手机号60秒内只能发送1次验证码，60秒内再次请求返回「请60秒后再试」
- 验证码有效期5分钟
- 验证码为6位纯数字
- 同一手机号每天最多发送10次验证码，超出返回「今日验证码发送次数已达上限」

**个人信息修改规则**：
- 平台用户（`user_source=platform`）：仅允许修改头像和昵称，手机号修改提示「平台用户请在系统管理中修改手机号」
- 知识讲堂独立用户（`user_source=kc_portal`）：允许修改头像、昵称、手机号（修改手机号需验证码验证新手机号）

**密码修改规则**：
- 平台用户：提示「平台用户请在系统管理中修改密码」，不提供密码修改功能
- 知识讲堂独立用户：输入旧密码 + 新密码 + 确认新密码，校验旧密码正确后更新

## 3.5 非功能需求

- **性能**：登录接口响应时间 < 1秒；短信验证码发送 < 3秒。
- **安全与权限**：密码使用 BCrypt 加密存储；JWT Token 有效期24小时；登录失败5次后锁定账号30分钟。角色定义统一以 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` 为唯一基准。
- **兼容性**：支持 Chrome 90+、Edge 90+、Safari 14+、Firefox 90+；页面响应式布局，适配1280px及以上分辨率。

- [ ] 平台已有用户（ent_admin、ent_reporter、mp_learner）可使用平台账号密码直接登录知识讲堂网站

- [ ] 忘记密码功能仅支持知识讲堂独立用户，通过手机号验证码重置密码
- [ ] 所有前端校验规则（必填、格式、一致性）在字段失焦和提交时均正确触发，错误提示紧邻字段下方

# 功能二：首页与导航

## 3.1 基本信息

- **功能名称**：首页与导航
- **关联现有模块/功能**：
  - 课程查看、政策资讯、行业动态、培训活动、在线交流各板块（本PRD其他功能）

### 3.4.1 功能流程逻辑

**分类筛选规则**：
- 课程分类Tab从 `kc_course_category` 表动态加载，首个Tab为「全部」
- 点击Tab立即筛选，列表区域显示loading骨架屏后刷新
- 当前激活Tab有明显选中态

**搜索规则**：
- 搜索框输入后防抖300ms触发，按 `course_name` 模糊匹配
- 搜索模式下分类Tab置灰不可交互
- 清空搜索关键词后恢复分类Tab功能

**视频播放规则**：
- 视频播放器支持播放/暂停、进度条、音量、全屏
- 已登录用户：每30秒自动上报一次学习进度（当前播放位置），关闭页面前上报最终进度
- 已登录用户再次观看时自动从上次播放位置恢复
- 未登录用户可正常播放但不记录进度

**学习进度计算规则**：
- 学习进度 = 已观看最远位置 / 视频总时长 × 100，取整数
- 当进度 ≥ 90% 时标记为已完成（`is_completed=1`）
- 学习时长按实际观看秒数累计，每次上报时增量累加

**评价规则**：
- 每个登录用户对每门课程只能评价1次
- 已评价的课程展示用户自己的评价，不可再次评价
- 评价审核通过后才在详情页展示（`audit_status=2`）
- 课程整体评分 = 所有已通过评价的评分算术平均值，保留1位小数

## 3.2 目标与范围

**目标**：
1. 为知识讲堂网站用户提供政策资讯浏览功能，数据来源于监管端发布的政策资讯。
2. 网站端仅展示 `visibility_type=0`（全部可见）的已发布政策，不做用户级可见范围过滤。
3. 支持按分类筛选和关键词搜索。

**非目标（Non-Goals）**：
- 不提供评论、点赞、收藏功能（与企业端WEB区分，知识讲堂网站端仅提供阅读功能）。
- 不做可见范围过滤（网站端仅展示全部可见的政策）。

**现状简述**：
- `knowledge_policy` 表已存在，政策数据由监管端管理。
- 知识讲堂网站端仅读取全部可见（`visibility_type=0`）的已发布政策进行展示。

**复用检查结论**：

| 检查项 | 现有资源 | 复用结论 | 说明 |

### 3.4.1 功能流程逻辑

**数据过滤规则（后端）**：

**排序规则**：
- 置顶资讯（`is_top=1`）优先展示，多条置顶按 `sort_order` 升序
- 非置顶按 `publish_time` 倒序

```
论坛发帖流程：
```

### 3.4.1 功能流程逻辑

**论坛帖子规则**：
- 帖子发布后立即展示（不需审核）
- 用户可删除自己发布的帖子（帖子有回复时需二次确认）
- 用户可编辑自己发布的帖子（发布30分钟内）
- 后台管理员可置顶/加精/删除帖子

**帖子排序规则**：
- 置顶帖子（`is_top=1`）优先展示
- 加精帖子（`is_featured=1`）展示「精」标签
- 非置顶帖子按最后回复时间（`last_reply_time`）倒序排列

**问答规则**：
- 用户提交问题后状态为「待回答」（`0`）
- 后台或专家用户回答后状态变为「已回答」（`1`）
- 提问者可采纳某条回答为最佳答案，状态变为「已采纳」（`2`）
- 每个问题只能有1个被采纳的最佳答案

| 帖子图片 | 否 | 最多9张，每张不超过5MB，格式jpg/jpeg/png | 「单张图片不超过5MB」/「最多上传9张图片」 |
| 回复内容 | 是 | 2~2000个字符 | 「请输入回复内容」/「回复最少2个字符」 |
| 问题标题 | 是 | 5~200个字符 | 「请输入问题标题」/「标题最少5个字符」 |

| 回答内容 | 是 | 最少10个字符 | 「请输入回答内容」/「回答最少10个字符」 |

**自动回显字段（只读）**：
- 用户ID、用户来源、用户昵称、用户头像（系统自动填充）
- 查看数、回复数、回答数（系统统计）

## 3.5 非功能需求

- **性能**：论坛帖子列表首屏加载 < 2秒；发帖和回复提交响应 < 1秒。
- **安全与权限**：浏览公开内容无需登录；发帖、回帖、提问、回答需登录；用户仅可删除/编辑自己的内容。
- **兼容性**：同本PRD其他功能。

## 3.6 验收标准

**论坛**：
- [ ] 论坛板块列表正确展示所有启用板块
- [ ] 点击板块即时筛选帖子列表
- [ ] 登录用户可发布帖子（标题+内容+图片），发布后立即展示
- [ ] 帖子详情页正确渲染内容，查看数+1
- [ ] 登录用户可回复帖子，回复后列表刷新
- [ ] 用户可删除自己的帖子和回复
- [ ] 置顶帖子排在最前，加精帖子显示「精」标签
- [ ] 未登录用户可浏览帖子但不能发帖/回复
- [ ] 发帖/回复前端校验在失焦和提交时正确触发

**问答**：
- [ ] 问答列表展示所有问题，支持分类和状态筛选（Tab切换即时筛选）
- [ ] 登录用户可提交问题（标题+描述+分类+图片），状态为待回答
- [ ] 问题详情页展示问题信息和所有回答
- [ ] 登录用户可提交回答
- [ ] 提问者可采纳某条回答为最佳答案，采纳后该回答置顶展示
- [ ] 后台/专家回答自动标记「专家」标识
- [ ] 未登录用户可浏览问答内容但不能提问/回答
