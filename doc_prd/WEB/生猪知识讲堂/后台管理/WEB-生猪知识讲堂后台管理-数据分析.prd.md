## 3.2 目标与范围

**目标**：
1. 为监管端人员提供知识讲堂运营数据的集中统计分析展示。
2. 提供概览看板，快速了解用户、内容、学习、活动等核心指标。
3. 提供用户分析、课程分析、内容分析、活动分析等多维度统计报表。
4. 支持按日/周/月维度切换趋势图时间粒度。

**非目标（Non-Goals）**：
- 不提供数据导出功能（本版本仅在线展示）。
- 不提供自定义报表配置功能。
- 不提供数据钻取下钻到明细记录功能（仅展示汇总统计）。
- 不提供实时数据刷新（数据按请求时点统计，无自动刷新）。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 概览看板 | P0 | 用户统计、内容统计、学习统计、活动统计、趋势图 |
| 用户分析 | P0 | 注册趋势图、用户来源分布、活跃用户排行 |
| 课程分析 | P0 | 学习热度排行、评分排行、学习时长趋势 |
| 内容分析 | P0 | 政策阅读排行、行业动态阅读排行、论坛帖子热度排行 |
| 活动分析 | P0 | 培训参与统计、活动类型分布 |

**关键流程**：

```
数据分析主流程：
进入数据分析页 → 顶部 Tab 切换：概览 / 用户分析 / 课程分析 / 内容分析 / 活动分析
  → 点击 Tab 立即切换下方内容区域
  → 各 Tab 内展示对应统计图表和表格
  → 趋势图支持按日/周/月维度切换（若有）
```

**交互与界面要点**：
- 页面顶部为 Tab 导航：概览、用户分析、课程分析、内容分析、活动分析
- Tab 切换即时响应，切换后内容区域重新加载对应数据
- 各 Tab 内为卡片式布局，图表与表格分区展示
- 趋势图支持维度切换（日/周/月），切换后即时刷新图表

### 3.4.1 功能流程逻辑

**概览看板数据规则**：
- 用户统计：注册用户总数（kc_user，del_flag=0）、今日新增（create_time 为今日）、近7天/30天趋势（按 create_time 统计每日新增数）
- 内容统计：课程总数（kc_course，del_flag=0，publish_status=1）、文章总数（kc_article，del_flag=0，publish_status=1）、帖子总数（kc_forum_post，del_flag=0，status=1）、问题总数（kc_qa_question，del_flag=0）
- 学习统计：今日学习人次（kc_course_learn_record，create_time 为今日的去重 user_id+user_source+chapter_id 或按记录条数）、课程总学习人次（kc_course_learn_record 总记录数或按课程去重）
- 活动统计：进行中活动数（kc_training，publish_status=1，training_status=0 或 1）、报名总人次（kc_training_enrollment，del_flag=0 的条数）

**用户分析数据规则**：
- 用户注册趋势：按 create_time 分组（日/周/月），统计每日/周/月新增用户数
- 用户来源分布：platform（平台用户，来自 sys_user 且登录过知识讲堂）vs kc_portal（独立注册用户，kc_user）；需统计 kc_user 数量，platform 用户数需从学习记录、发帖、提问等行为中统计去重 user_id
- 活跃用户排行：按学习时长（kc_course_learn_record.learn_duration 按 user_id+user_source 汇总）、发帖数（kc_forum_post 按 user_id+user_source 汇总）、提问数（kc_qa_question 按 user_id+user_source 汇总）综合排序，Top N（如 10）

**课程分析数据规则**：
- 学习热度排行：按 kc_course_learn_record 中 course_id 去重统计学习人数，Top 10 课程
- 课程评分排行：按 kc_course.score、kc_course.review_count、kc_course.learn_count 展示
- 学习时长趋势：按 kc_course_learn_record.create_time 分组（日/周/月），汇总 learn_duration

**内容分析数据规则**：
- 政策资讯阅读排行：按 knowledge_policy.read_count 倒序，Top 10
- 行业动态阅读排行：按 kc_article.read_count 倒序，Top 10
- 论坛帖子热度排行：按 kc_forum_post.reply_count 倒序，Top 10

**活动分析数据规则**：
- 培训活动参与统计：kc_training 列表，关联 kc_training_enrollment 统计报名数、通过数（approval_status=1）、参与率（通过数/报名数×100%）
- 活动类型分布：按 kc_training.training_type 分组统计，饼图展示；training_type 枚举：`1` 专题培训、`2` 技术指导、`3` 政策宣讲、`4` 经验交流

### 3.4.2 数据模型与字段定义

**本功能不新增数据表，所有数据基于已有业务表统计查询。**

**引用的表及用途**：

| 表名 | 用途 |
|------|------|
| kc_user | 用户注册总数、今日新增、注册趋势、用户来源分布（kc_portal 来源） |
| kc_course | 课程总数、课程学习热度、课程评分排行 |
| kc_course_learn_record | 今日学习人次、课程总学习人次、学习时长趋势、活跃用户学习时长、课程学习人数统计 |
| kc_course_review | 课程评价数（kc_course.review_count 已冗余） |
| kc_training | 进行中活动数、培训活动参与统计、活动类型分布 |
| kc_training_enrollment | 报名总人次、报名数、通过数、参与率 |
| kc_article | 文章总数、行业动态阅读排行 |
| knowledge_policy | 政策资讯阅读排行（注：政策总数若需统计，需确认 knowledge_policy 表在知识讲堂的展示范围） |
| kc_forum_post | 帖子总数、论坛帖子热度排行 |
| kc_qa_question | 问题总数 |
| 平台用户行为（sys_user 关联） | 用户来源分布（platform 来源）需从 kc_course_learn_record、kc_forum_post、kc_qa_question 等表中 user_source=platform 的去重 user_id 统计 |

**统计维度说明**：
- 今日：create_time 或统计时间字段的日期部分等于当前日期

- 近7天/30天：create_time 在最近 7 天或 30 天范围内

- 按日：按 create_time 的日期分组

- 按周：按 create_time 所在周（周一为起始）分组

- 按月：按 create_time 的年月分组

### 3.4.3 界面交互逻辑

**页面布局（从上到下）**：

1. **顶部 Tab 导航**：

   - Tab 项：概览、用户分析、课程分析、内容分析、活动分析
   - 点击 Tab 立即切换下方内容，切换时展示 loading 骨架屏
   - 当前激活 Tab 高亮

2. **概览 Tab 内容**：

   - 第一行：4 个统计卡片（用户总数、今日新增用户、课程总数、帖子总数）
   - 第二行：4 个统计卡片（文章总数、问题总数、今日学习人次、课程总学习人次）
   - 第三行：2 个统计卡片（进行中活动数、报名总人次）
   - 第四行：用户注册趋势折线图（近7天/30天切换，切换后即时刷新图表）

3. **用户分析 Tab 内容**：

   - 用户注册趋势图（折线图）：支持按日/周/月维度切换
   - 用户来源分布（饼图）：平台用户 vs 独立注册用户
   - 活跃用户排行（表格）：列：昵称、学习时长（秒转小时）、发帖数、提问数）

4. **课程分析 Tab 内容**：

   - 课程学习热度排行（柱状图）：Top 10 课程名称 + 学习人数
   - 课程评分排行（表格）：列：课程名称、评分、评价数、学习人数
   - 学习时长趋势（折线图）：按日/周/月维度切换

5. **内容分析 Tab 内容**：

   - 政策资讯阅读排行（表格）：列：标题、阅读数、发布时间
   - 行业动态阅读排行（表格）：列：标题、阅读数、发布时间
   - 论坛帖子热度排行（表格）：列：标题、回复数、发帖时间

6. **活动分析 Tab 内容**：

   - 培训活动参与统计（表格）：列：活动名称、报名数、通过数、参与率（%）
   - 活动类型分布（饼图）：专题培训、技术指导、政策宣讲、经验交流

**交互细节**：
- Tab 切换即时响应，切换后内容区域重新请求对应接口
- 趋势图维度切换（日/周/月）即时刷新图表数据
- 各 Tab 内图表与表格加载时展示骨架屏
- 空数据时展示「暂无数据」占位

**自动回显字段（只读）**：本功能无用户输入表单，所有数据为只读展示

## 3.5 非功能需求

- **性能**：概览看板首屏加载 < 3秒；各 Tab 切换后数据加载 < 2秒；趋势图维度切换 < 1秒。
- **安全与权限**：仅 county_admin、county_staff 可访问；需登录且具备对应菜单权限。
- **兼容性**：支持 Chrome 90+、Edge 90+、Safari 14+、Firefox 90+；图表组件需兼容主流浏览器。
