# 功能一：行业动态管理

## 3.1 基本信息

- **功能名称**：行业动态管理
- **关联现有模块/功能**：
  - 用户认证：依赖现有 JWT Token 认证（`/login`、`/getInfo`）
  - 文件上传：复用现有 `/common/upload` 接口
  - 字典数据：复用 `/system/dict/data/type/{dictType}` 接口（文章分类等）
  - 生猪知识讲堂网站：行业动态数据由本功能管理，网站端（`/kc-portal/article/*`）读取已发布数据展示
  - 政策资讯管理：`WEB管理端-政策资讯管理.prd.md`，与本功能独立，不共用表
  - 参考文档：`doc_spec/现有业务说明.spec.md`、`doc_prd/WEB/生猪知识讲堂/网站/WEB-生猪知识讲堂网站.prd.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（引用自全局权限体系 §1.1） | 使用场景 | 主要需求 |
|---------|--------------------------------------|---------|---------|
| 县级管理员 | county_admin | 管理生猪知识讲堂行业动态 | 新增、编辑、发布、下架、删除文章，置顶管理 |
| 县级业务人员 | county_staff | 日常运营行业动态 | 新增、编辑、发布、下架文章，置顶管理 |

## 3.2 目标与范围

**目标**：
1. 为监管端提供行业动态文章的全生命周期管理（新增、编辑、发布、下架、删除）。
2. 支持文章列表分页查询，按分类、发布状态、标题搜索筛选。
3. 支持置顶管理，置顶文章在网站端优先展示。
4. 支持富文本正文编辑、封面图、附件上传。

**非目标（Non-Goals）**：
- 不提供行业动态的前台浏览功能（由网站端承担）。
- 不实现评论、点赞、收藏功能（行业动态为纯阅读）。
- 不管理政策资讯（政策资讯由 `WEB管理端-政策资讯管理.prd.md` 独立管理）。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 文章列表 | P0 | 分页展示所有行业动态文章，支持按分类、发布状态、标题搜索 |
| 新增文章 | P0 | 填写文章信息（标题、摘要、分类、来源、作者、封面、正文富文本、附件、是否置顶、排序序号） |
| 编辑文章 | P0 | 修改文章信息 |
| 文章发布/下架 | P0 | 草稿→已发布、已发布→已下架 |
| 删除文章 | P1 | 逻辑删除 |
| 置顶管理 | P1 | 设置/取消置顶 |

**关键流程**：

```
新增文章流程：
点击「新增」→ 进入新增表单页 → 填写文章信息
  → 前端校验 → 提交
  → 保存成功 → 跳转列表或提示「保存成功」

发布/下架流程：
列表操作列「发布」（草稿/已下架）→ 二次确认 → publish_status=1，publish_time=当前时间
列表操作列「下架」（已发布）→ 二次确认 → publish_status=2

置顶流程：
列表操作列「置顶」/「取消置顶」→ 即时更新 is_top 字段（0/1）
```

**交互与界面要点**：
- 列表页：顶部筛选区 + 操作按钮行 + 数据表格 + 分页控件
- 新增/编辑页：独立表单页，富文本编辑器

### 3.4.1 功能流程逻辑

**发布状态流转规则**：
- `草稿（0）` → 发布 → `已发布（1）`：`publish_time` 自动填充
- `已发布（1）` → 下架 → `已下架（2）`
- `已下架（2）` → 发布 → `已发布（1）`
- 删除允许任意状态（逻辑删除）

**置顶规则**：
- 仅 `publish_status=1`（已发布）的文章可设置置顶
- 置顶数量无上限
- 置顶文章在网站端列表按 `sort_order` 升序优先展示，同置顶内按 `sort_order`，非置顶按 `publish_time` 倒序

**read_count 规则**：
- 网站端详情页打开时 +1，后台不修改

**文章列表页布局**：
- 顶部筛选区：
  - 文章分类下拉（全部 / 市场行情 / 技术前沿 / 产业分析 / 疫病防控）

| 字段 | 必填 | 格式校验 | 提示文案 |
|-----|------|---------|---------|

**自动回显字段（只读）**：

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| Banner 列表 | P0 | 展示所有 Banner，按排序序号排序，支持拖拽排序 |
| 新增 Banner | P0 | 填写 Banner 信息（标题、图片、链接地址、链接类型、排序序号） |
| 编辑 Banner | P0 | 修改 Banner 信息 |
| 删除 Banner | P0 | 逻辑删除 |
| Banner 状态切换 | P0 | 启用/停用 |

**关键流程**：

```
新增 Banner 流程：
点击「新增」→ 弹出新增弹窗或进入表单页 → 填写标题、上传图片、选择链接类型、填写链接地址（可选）、排序序号
  → 前端校验 → 提交
  → 保存成功 → 列表刷新

状态切换流程：
列表操作列「启用」/「停用」→ 即时更新 status 字段（0 启用 / 1 停用）
  → 停用后网站端首页不展示该 Banner
```

**交互与界面要点**：
- Banner 列表可考虑表格或卡片形式，展示缩略图、标题、链接类型、排序、状态
- 支持拖拽调整排序序号（可选，或通过编辑修改 sort_order）
- 链接类型为「无跳转」时，链接地址可不填

### 3.4.1 功能流程逻辑

**排序规则**：
- 列表按 `sort_order` 升序展示，数值越小越靠前
- 网站端首页轮播按 `sort_order` 升序取 `status=0` 的 Banner，最多5张

**状态规则**：
- `status=0`（启用）：网站端展示
- `status=1`（停用）：网站端不展示
- 切换为即时生效

**链接类型规则**：
- `0` 无跳转：点击 Banner 不跳转，`link_url` 可为空
- `1` 站内链接：点击跳转站内页面，`link_url` 填写站内路径（如 `/article/123`）
- `2` 外部链接：点击跳转外部 URL，`link_url` 填写完整 URL（如 `https://xxx.com`）

### 3.4.2 数据模型与字段定义

**轮播 Banner 表（kc_banner）**（✅ 复用网站端 PRD 已定义表，见 WEB-生猪知识讲堂网站.prd.md 功能二 §3.4.2）：

| 字段名（中文） | 字段名（英文） | 类型 | 长度 | 必填 | 默认值 | 取值范围/枚举值 | 说明 |
|--------------|--------------|------|------|------|--------|----------------|------|
| BannerID | banner_id | bigint | 20 | 是 | 自增 | - | 主键，只读 |
| Banner标题 | banner_title | varchar | 100 | 是 | - | 最大长度100个字符 | - |
| Banner图片 | banner_image | varchar | 500 | 是 | - | - | 图片URL |
| 链接地址 | link_url | varchar | 500 | 否 | - | 最大长度500个字符 | 链接类型为1或2时建议填写 |
| 链接类型 | link_type | char | 1 | 是 | `0` | `0` 无跳转、`1` 站内链接、`2` 外部链接 | 共3种，无其他 |
| 排序序号 | sort_order | int | 11 | 是 | `0` | 最小值0，最大值999 | 数值越小越靠前 |
| 状态 | status | char | 1 | 是 | `0` | `0` 启用、`1` 停用 | 仅2种 |
| 删除标志 | del_flag | char | 1 | 是 | `0` | `0` 存在、`2` 删除 | 仅2种 |
| 创建者 | create_by | varchar | 64 | 否 | - | - | 只读 |
| 创建时间 | create_time | datetime | - | 是 | CURRENT_TIMESTAMP | - | 只读 |
| 更新者 | update_by | varchar | 64 | 否 | - | - | 只读 |
| 更新时间 | update_time | datetime | - | 是 | CURRENT_TIMESTAMP | - | 只读 |

### 3.4.3 界面交互逻辑

**Banner 列表页布局**：
- 操作按钮行：「新增」按钮（主色）
- 数据展示：表格或卡片列表，列/项包括：缩略图（banner_image 预览）、标题、链接类型、链接地址、排序序号、状态、操作列
- 操作列：「编辑」「启用/停用」「删除」
- 支持拖拽排序（可选）：拖拽后自动更新 sort_order，或通过编辑修改
- 若无分页需求（Banner 数量通常较少），可全部展示；若超过20条可加分页

**新增/编辑表单**：
- 可为弹窗形式（Banner 字段较少）
- 表单字段：Banner 标题、Banner 图片（上传）、链接类型（下拉）、链接地址（链接类型为1或2时显示）
- 排序序号：数字输入框，默认0
- 底部：「确定」按钮 + 「取消」按钮

**前端校验规则（强制）**：

| 字段 | 必填 | 格式校验 | 提示文案 |
|-----|------|---------|---------|
| Banner 标题 | 是 | 非空，最大100字符 | 「Banner 标题不能为空」/「Banner 标题不能超过100个字符」 |
| Banner 图片 | 是 | 必须上传 | 「请上传 Banner 图片」 |
| 链接类型 | 是 | 必须选择0/1/2之一 | 「请选择链接类型」 |
| 链接地址 | 条件必填 | 链接类型为1或2时，若填写则最大500字符；站内链接建议以/开头，外部链接建议以 http:// 或 https:// 开头 | 「链接类型为站内/外部时，建议填写链接地址」 |
| 排序序号 | 是 | 整数，0~999 | 「排序序号须在0~999之间」 |

- 字段失焦时即时校验；提交时整体校验
- 错误提示紧邻对应字段下方展示（红色文字）

**自动回显字段（只读）**：
- banner_id、创建者、创建时间、更新者、更新时间

### 3.4.4 接口路径定义（强制）

| 接口名称 | HTTP 方法 | 路径 | 请求参数摘要 | 响应数据摘要 | 备注 |
|----------|-----------|------|-------------|-------------|------|
| Banner 列表 | GET | `/kc-admin/banner/list` | 无（或 pageNum、pageSize 若分页） | Banner 列表（banner_id、banner_title、banner_image、link_url、link_type、sort_order、status、create_time），按 sort_order 升序 | 🆕 新增 |
| Banner 详情 | GET | `/kc-admin/banner/{id}` | path: banner_id | Banner 完整详情 | 🆕 新增 |
| 新增 Banner | POST | `/kc-admin/banner` | 见 3.4.2 字段定义（不含只读字段） | 操作结果 + banner_id | 🆕 新增 |
| 修改 Banner | PUT | `/kc-admin/banner` | 同新增，含 banner_id | 操作结果 | 🆕 新增 |
| 删除 Banner | DELETE | `/kc-admin/banner/{ids}` | path: 多个 banner_id 逗号分隔 | 操作结果 | 🆕 新增；逻辑删除 |
| 状态切换 | PUT | `/kc-admin/banner/changeStatus` | banner_id、status（0/1） | 操作结果 + 更新后 status | 🆕 新增 |
| 排序更新 | PUT | `/kc-admin/banner/sort` | bannerIds（按新顺序的 id 数组） | 操作结果 | 🆕 新增；可选，用于拖拽排序后批量更新 sort_order |

## 3.5 非功能需求

- **性能**：Banner 列表加载响应时间 < 500ms。
- **安全与权限**：所有接口携带有效 JWT Token；需校验用户具备「生猪知识讲堂-Banner 管理」权限。
- **兼容性**：同功能一。

## 3.6 验收标准

- [ ] Banner 列表按排序序号升序展示，展示缩略图、标题、链接类型、状态
- [ ] 新增 Banner 时所有必填字段校验生效，图片必须上传
- [ ] 链接类型为「无跳转」时，链接地址可不填
- [ ] 链接类型为「站内链接」或「外部链接」时，可填写链接地址
- [ ] 编辑 Banner 正确回显已保存数据
- [ ] 启用/停用切换即时生效，停用后网站端首页不展示
- [ ] 删除为逻辑删除，删除后列表不展示
- [ ] 支持拖拽排序时，排序更新后列表顺序正确
