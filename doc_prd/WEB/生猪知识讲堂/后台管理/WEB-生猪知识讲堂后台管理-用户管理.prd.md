## 3.2 目标与范围

**目标**：
1. 为监管端人员提供知识讲堂网站注册用户（kc_user）的集中管理入口。
2. 支持按昵称、手机号、状态筛选用户，分页查看用户列表。
3. 支持查看用户详细信息。
4. 支持启用/停用用户账号，控制用户登录权限。
5. 支持管理员为用户重置密码（默认重置为 123456）。
6. 支持逻辑删除用户，支持批量删除。

**非目标（Non-Goals）**：
- 不提供新增用户功能（用户自行在网站注册）。
- 不提供编辑用户个人信息功能（昵称、头像、性别、地区、个人简介等由用户自行在网站个人中心修改）。
- 不提供用户注册审核功能（网站注册即生效）。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 用户列表查看 | P0 | 分页查看 kc_user 表中所有注册用户，支持按昵称、手机号、状态搜索筛选 |
| 用户详情查看 | P0 | 查看用户完整信息 |
| 用户状态管理 | P0 | 启用/停用用户账号 |
| 重置用户密码 | P0 | 管理员为用户重置密码，默认重置为 123456 |
| 删除用户 | P0 | 逻辑删除，支持批量删除 |

**关键流程**：

```
用户列表流程：
进入用户管理页 → 输入筛选条件（昵称、手机号、状态）→ 点击「查询」或直接加载
  → 后端分页查询 kc_user（del_flag=0）→ 展示用户列表
  → 可执行：查看详情、启用/停用、重置密码、删除

用户详情流程：
列表页点击「详情」→ 弹窗或跳转详情页 → 展示用户完整信息（只读）

状态管理流程：
列表页点击「启用」或「停用」→ 二次确认 → 提交 → 更新 kc_user.status
  → status=0 正常，status=1 停用；停用后该用户无法登录网站

重置密码流程：
列表页点击「重置密码」→ 二次确认（提示「将重置为 123456」）→ 提交
  → 后端将密码加密后更新 kc_user.password → 提示「密码已重置」

删除用户流程：
列表页勾选用户 → 点击「删除」→ 二次确认 → 提交
  → 后端将 kc_user.del_flag 置为 2（逻辑删除）→ 提示「删除成功」
```

**交互与界面要点**：
- 列表页顶部为筛选区域：昵称（模糊）、手机号（模糊）、状态（下拉：全部/正常/停用）
- 列表表格列：用户ID、用户名、昵称、手机号、性别、账号状态、最后登录时间、创建时间、操作（详情、启用/停用、重置密码、删除）
- 支持批量删除：勾选多行后点击「批量删除」
- 详情弹窗/页展示所有字段，均为只读

### 3.4.1 功能流程逻辑

**列表筛选规则**：
- 昵称：按 `nick_name` 模糊匹配，支持空（不筛选）
- 手机号：按 `phone` 模糊匹配，支持空（不筛选）
- 状态：`0` 正常、`1` 停用，空表示全部
- 仅查询 `del_flag=0`（未删除）的用户

**状态切换逻辑**：
- 当前 `status=0`（正常）时，按钮展示「停用」，点击后 `status` 置为 `1`
- 当前 `status=1`（停用）时，按钮展示「启用」，点击后 `status` 置为 `0`
- 停用后用户无法登录知识讲堂网站

**重置密码规则**：
- 重置后密码明文为 `123456`，存储时使用 BCrypt 加密
- 重置成功后用户可使用新密码登录

**删除规则**：
- 逻辑删除：将 `del_flag` 置为 `2`
- 支持单条删除和批量删除（多个 user_id 逗号分隔）
- 删除后用户数据仍保留，但不再在列表中展示，且无法登录

**按钮展示逻辑**：
- 详情：所有有权限用户可见
- 启用/停用：根据当前 status 展示对应按钮，仅展示一个
- 重置密码：所有有权限用户可见
- 删除：所有有权限用户可见

### 3.4.2 数据模型与字段定义

**知识讲堂用户表（kc_user）**（✅ 复用网站端 PRD 已定义的表，见 `WEB-生猪知识讲堂网站.prd.md` §3.4.2）：

| 字段名（中文） | 字段名（英文） | 类型 | 长度 | 必填 | 默认值 | 取值范围/枚举值 | 说明 |
|--------------|--------------|------|------|------|--------|----------------|------|
| 用户ID | user_id | bigint | 20 | 是 | 自增 | - | 主键 |
| 用户名 | user_name | varchar | 30 | 是 | - | 长度5~30个字符 | 登录账号 |
| 用户昵称 | nick_name | varchar | 30 | 是 | - | 长度2~30个字符 | 展示名称 |
| 手机号 | phone | varchar | 11 | 是 | - | 11位中国大陆手机号 | 唯一 |
| 密码 | password | varchar | 100 | 是 | - | BCrypt 哈希存储 | 后台不展示明文 |
| 头像地址 | avatar | varchar | 200 | 否 | - | 图片URL | - |
| 用户性别 | sex | char | 1 | 否 | `2` | `0` 男、`1` 女、`2` 未知 | 共3种，无其他 |
| 所在地区 | region | varchar | 100 | 否 | - | - | - |
| 个人简介 | profile | varchar | 200 | 否 | - | 最大长度200个字符 | - |
| 账号状态 | status | char | 1 | 是 | `0` | `0` 正常、`1` 停用 | 仅2种 |
| 最后登录IP | login_ip | varchar | 128 | 否 | - | - | 只读 |
| 最后登录时间 | login_date | datetime | - | 否 | - | - | 只读 |
| 删除标志 | del_flag | char | 1 | 是 | `0` | `0` 存在、`2` 删除 | 仅2种 |
| 创建者 | create_by | varchar | 64 | 否 | - | - | 只读 |
| 创建时间 | create_time | datetime | - | 是 | CURRENT_TIMESTAMP | - | 只读 |
| 更新者 | update_by | varchar | 64 | 否 | - | - | 只读 |
| 更新时间 | update_time | datetime | - | 是 | CURRENT_TIMESTAMP | - | 只读 |
| 备注 | remark | varchar | 500 | 否 | - | - | - |

> 本功能不新增表，不修改表结构，仅对 `kc_user` 进行查询、更新操作。

### 3.4.3 界面交互逻辑

**用户列表页布局**：
- 顶部筛选区域（横向排列）：
  - 昵称输入框（placeholder：「请输入昵称」）
  - 手机号输入框（placeholder：「请输入手机号」）
  - 状态下拉框：全部、正常、停用
  - 「查询」按钮、「重置」按钮
- 操作按钮区域：「批量删除」按钮（选中至少一条时可用）
- 表格区域：
  - 列：勾选框、用户ID、用户名、昵称、手机号、性别、账号状态、最后登录时间、创建时间、操作
  - 操作列：详情、启用/停用、重置密码、删除（下拉或按钮组）
- 底部分页器：每页条数选择（10/20/50）、页码

**用户详情弹窗/页布局**：
- 展示所有字段，均为只读
- 字段分组：基本信息（用户名、昵称、手机号、性别、地区、头像、个人简介）、账号信息（状态、最后登录IP、最后登录时间）、审计信息（创建时间、创建者、更新时间、更新者）
- 底部「关闭」按钮

**二次确认规则**：
- 停用：弹窗「确定停用该用户？停用后用户将无法登录知识讲堂网站。」
- 启用：弹窗「确定启用该用户？」
- 重置密码：弹窗「确定将该用户密码重置为 123456？用户需使用新密码登录。」
- 删除：弹窗「确定删除所选用户？删除后用户将无法登录，数据可恢复。」
- 批量删除：弹窗「确定删除选中的 X 个用户？删除后用户将无法登录，数据可恢复。」

**加载与错误提示**：
- 列表加载时展示表格 loading 骨架
- 操作提交时按钮 loading 状态
- 接口失败时全局消息提示错误信息

**自动回显字段（只读）**：
- 用户详情中所有字段均为只读，后台不提供编辑功能

### 3.4.4 接口路径定义（强制）

| 接口名称 | HTTP 方法 | 路径 | 请求参数摘要 | 响应数据摘要 | 备注 |
|----------|-----------|------|-------------|-------------|------|
| 用户分页列表 | GET | `/kc-admin/users/list` | pageNum、pageSize、nickName（可选，模糊）、phone（可选，模糊）、status（可选，0/1） | 分页列表（user_id、user_name、nick_name、phone、sex、avatar、status、login_ip、login_date、create_time）+ 总数 | 🆕 新增；仅返回 del_flag=0 |
| 用户详情 | GET | `/kc-admin/users/{id}` | path: user_id | 用户完整信息（不含 password 明文） | 🆕 新增 |
| 用户状态切换 | PUT | `/kc-admin/users/changeStatus` | userId、status（0/1） | 操作结果 | 🆕 新增 |
| 重置用户密码 | PUT | `/kc-admin/users/resetPwd` | userId | 操作结果；密码重置为 123456 | 🆕 新增 |
| 删除用户 | DELETE | `/kc-admin/users/{ids}` | path: user_id，多个逗号分隔 | 操作结果 | 🆕 新增；逻辑删除，del_flag=2 |

## 3.5 非功能需求

- **性能**：用户列表首屏加载时间 < 2秒；分页切换响应时间 < 1秒。
- **安全与权限**：仅 county_admin、county_staff、town_vet_station 角色可访问；数据范围：全县数据（county_admin、county_staff）或本乡镇数据（town_vet_station，若按乡镇过滤则需关联用户 region 或扩展字段）；角色定义以 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` 为唯一基准。
- **兼容性**：支持 Chrome 90+、Edge 90+、Safari 14+、Firefox 90+；适配 1280px 及以上分辨率。
