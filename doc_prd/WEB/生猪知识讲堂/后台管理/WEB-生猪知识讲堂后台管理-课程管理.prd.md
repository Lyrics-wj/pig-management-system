## 3.2 目标与范围

1. 为监管端人员提供课程分类的增删改查能力。

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 分类列表 | P0 | 展示所有课程分类，支持排序 |
| 新增分类 | P0 | 输入分类名称、排序序号 |
| 编辑分类 | P0 | 修改分类名称、排序序号 |
| 删除分类 | P0 | 有课程关联的分类不可删除 |
| 分类状态切换 | P0 | 启用/停用 |

**关键流程**：

```
分类列表流程：
进入课程分类管理页 → 加载全部分类（不分页或分页）→ 展示列表
  → 可执行：新增、编辑、删除、启用/停用

新增分类流程：
点击「新增」→ 弹出表单 → 输入分类名称、排序序号 → 前端校验 → 提交
  → 后端写入 kc_course_category → 提示「新增成功」→ 刷新列表

编辑分类流程：
点击「编辑」→ 弹出表单（回显当前数据）→ 修改分类名称、排序序号 → 前端校验 → 提交
  → 后端更新 kc_course_category → 提示「修改成功」→ 刷新列表

删除分类流程：
点击「删除」→ 二次确认 → 提交
  → 后端检查 kc_course 表中是否存在 category_id 关联
    ├── 存在关联 → 返回「该分类下存在课程，无法删除」
    └── 无关联 → 逻辑删除（del_flag=2）→ 提示「删除成功」→ 刷新列表

状态切换流程：
点击「启用」或「停用」→ 二次确认 → 提交 → 更新 status
  → status=0 正常，status=1 停用；停用后网站端不展示该分类
```

### 3.4.1 功能流程逻辑

**删除校验规则**：
- 删除前检查 `kc_course` 表中是否存在 `category_id` 等于当前分类 ID 且 `del_flag=0` 的课程
- 若存在，返回错误「该分类下存在课程，无法删除」，不执行删除
- 若不存在，执行逻辑删除

**状态切换逻辑**：
- `status=0` 正常：网站端课程分类 Tab 展示该分类
- `status=1` 停用：网站端不展示该分类，已有课程仍可访问但分类 Tab 中不显示

**排序规则**：
- 列表按 `sort_order` 升序排列，`sort_order` 数值越小越靠前

**课程分类表（kc_course_category）**（✅ 复用网站端 PRD 已定义的表，见 `WEB-生猪知识讲堂网站.prd.md` §3.4.2）：

| 字段名（中文） | 字段名（英文） | 类型 | 长度 | 必填 | 默认值 | 取值范围/枚举值 | 说明 |

| 排序序号 | sort_order | int | 11 | 是 | `0` | 最小值0，最大值999 | 数值越小越靠前 |
| 状态 | status | char | 1 | 是 | `0` | `0` 正常、`1` 停用 | 仅2种 |

## 3.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 课程列表 | P0 | 分页展示所有课程，支持按分类、发布状态、课程名称搜索 |
| 新增课程 | P0 | 填写课程信息，添加章节（标题、视频、时长） |

**关键流程**：

```
课程列表流程：
进入课程管理页 → 选择筛选条件（分类、发布状态、课程名称）→ 点击「查询」或直接加载
  → 分页展示课程列表 → 可执行：新增、编辑、发布/下架、删除、评价审核

新增课程流程：
点击「新增课程」→ 进入新增页/弹窗
  → 第一步：填写课程基本信息（名称、简介、分类、封面、讲师信息）
  → 第二步：添加章节（章节标题、视频上传、视频时长）
  → 前端校验 → 提交 → 写入 kc_course + kc_course_chapter → 提示「新增成功」

编辑课程流程：
点击「编辑」→ 进入编辑页/弹窗（回显课程信息和章节列表）
  → 修改课程信息、增删改章节 → 前端校验 → 提交 → 更新数据 → 提示「修改成功」

发布/下架流程：
点击「发布」或「下架」→ 二次确认 → 提交
  → 发布：publish_status=1，publish_time=当前时间
  → 下架：publish_status=2
  → 草稿：publish_status=0（新增时默认）

删除课程流程：
点击「删除」→ 二次确认 → 提交 → del_flag=2（逻辑删除）→ 提示「删除成功」

评价审核流程：
课程详情/列表进入「评价管理」→ 展示待审核评价列表
  → 点击「通过」或「拒绝」→ 二次确认（拒绝时需填写拒绝原因，可选）
  → 提交 → 更新 audit_status（2 已通过、3 已拒绝）→ 提示成功
```

### 3.4.1 功能流程逻辑

**发布状态流转**：
- `0` 草稿：仅后台可见，网站端不展示
- `1` 已发布：网站端展示，发布时自动填充 `publish_time`
- `2` 已下架：网站端不展示，已学习用户可查看历史记录（若业务支持）

**课程统计字段自动计算**：
- `total_duration`：各章节 `video_duration` 之和，新增/编辑章节时自动更新
- `chapter_count`：章节数量，新增/编辑章节时自动更新
- `learn_count`、`score`、`review_count`：由业务逻辑累计，只读

**评价审核规则**：
- `audit_status=1` 待审核：用户提交后默认状态
- `audit_status=2` 已通过：审核通过后展示在网站课程详情页
- `audit_status=3` 已拒绝：不展示，可填写拒绝原因（存入 remark 或扩展字段）
- 课程 `score` 仅统计 `audit_status=2` 的评价平均值
- 课程 `review_count` 仅统计 `audit_status=2` 的评价数量

**删除规则**：
- 逻辑删除：`kc_course.del_flag=2`
- 同时逻辑删除关联章节：`kc_course_chapter.del_flag=2`（或通过 course_id 关联过滤）
- 评价保留，通过 course_id 关联可查历史

**课程表（kc_course）**（✅ 复用网站端 PRD 已定义的表，见 `WEB-生猪知识讲堂网站.prd.md` §3.4.2）：

| 字段名（中文） | 字段名（英文） | 类型 | 长度 | 必填 | 默认值 | 取值范围/枚举值 | 说明 |

### 3.4.3 界面交互逻辑

**课程列表页布局**：
- 顶部筛选区域：分类下拉（调用 options 接口）、发布状态下拉（全部/草稿/已发布/已下架）、课程名称输入框、「查询」「重置」按钮
- 操作区：「新增课程」按钮
- 表格列：课程ID、封面缩略图、课程名称、分类名称、讲师、发布状态、章节数、学习人数、评分、创建时间、操作（编辑、发布/下架、删除、评价管理）
- 底部分页器

**新增/编辑课程表单（与 3.4.2 数据模型字段全量对应）**：

**课程基本信息区块**：
- 课程名称（必填，varchar 200）
- 课程简介（必填，富文本）
- 课程分类（必填，下拉选择，调用 `/kc-admin/course-categories/options`）
- 封面图片（必填，图片上传）
- 讲师名称（必填，varchar 50）
- 讲师简介（选填，varchar 500）
- 讲师头像（选填，图片上传）
- 排序序号（必填，int 0~999，默认 0）

**章节管理区块**：
- 章节列表（可增删改）
- 每章节包含：章节标题（必填，varchar 200）、章节序号（必填，int 1~999）、视频地址（必填，视频上传）、视频时长（必填，int 0~86400，单位秒）
- 支持拖拽排序调整章节顺序
- 「添加章节」按钮

**自动回显/只读字段**：
- 课程ID、创建者、创建时间、更新者、更新时间（编辑时展示，不可编辑）
- 课程总时长、章节数量、学习人数、评分、评价数量（系统自动计算，不可编辑）
- 发布时间（发布时自动填充，只读）

**评价审核页/弹窗布局**：
- 可进入方式：课程列表操作「评价管理」或课程详情页「评价管理」
- 评价列表：用户昵称、头像、评分、评价内容、提交时间、审核状态、操作（通过、拒绝）
- 筛选：全部/待审核/已通过/已拒绝
- 拒绝时可弹出输入框填写拒绝原因（可选，可扩展 remark 字段存储）

**前端校验规则（强制）**：

| 字段 | 必填 | 格式校验 | 提示文案 |
|-----|------|---------|---------|
| 课程名称 | 是 | 最大200个字符 | 「请输入课程名称」/「课程名称不能超过200个字符」 |
| 课程简介 | 是 | 不能为空 | 「请输入课程简介」 |
| 课程分类 | 是 | 必须选择 | 「请选择课程分类」 |
| 封面图片 | 是 | 必须上传 | 「请上传封面图片」 |
| 讲师名称 | 是 | 最大50个字符 | 「请输入讲师名称」/「讲师名称不能超过50个字符」 |
| 讲师简介 | 否 | 最大500个字符 | 「讲师简介不能超过500个字符」 |
| 排序序号 | 是 | 0~999 整数 | 「请输入排序序号」/「排序序号必须为0~999的整数」 |
| 章节标题 | 是 | 最大200个字符 | 「请输入章节标题」/「章节标题不能超过200个字符」 |
| 章节序号 | 是 | 1~999 整数 | 「请输入章节序号」/「章节序号必须为1~999的整数」 |
| 视频地址 | 是 | 必须上传 | 「请上传章节视频」 |

- 字段失焦时即时校验，提交时整体校验
- 错误提示紧邻对应字段下方

**二次确认**：
- 发布：弹窗「确定发布该课程？发布后将在网站端展示。」
- 下架：弹窗「确定下架该课程？下架后网站端将不再展示。」
- 删除：弹窗「确定删除该课程？删除后不可恢复（逻辑删除）。」
- 评价通过：弹窗「确定通过该评价？」
- 评价拒绝：弹窗「确定拒绝该评价？」（可选填写拒绝原因）

## 3.5 非功能需求

- **性能**：课程列表首屏加载 < 2秒；课程详情加载 < 1秒；视频上传支持大文件（建议分片上传或异步处理）。
- **安全与权限**：仅 county_admin、county_staff、town_vet_station 可访问；角色定义以 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` 为唯一基准。
- **兼容性**：支持 Chrome 90+、Edge 90+、Safari 14+、Firefox 90+；视频格式支持 MP4（H.264）；适配 1280px 及以上分辨率。
