## 1.2 目标与范围

**目标**：
1. 以企业为维度，展示每家养殖企业各类档案的已入库记录数汇总，形成档案台账总览列表。
2. 支持按企业名称、所属乡镇、企业类型、时间范围进行筛选和搜索。
3. 点击某企业可进入该企业的完整档案详情页，按 Tab 页签浏览各类别已入库档案记录。
4. 支持导出台账总览列表和单企业单类别已入库数据列表（Excel）。
5. 数据范围按角色自动过滤：县级看全县，乡镇看本乡镇。

**非目标（Non-Goals）**：
- ❌ 不展示草稿、审批中、退回等非"已入库"状态的数据。
- ❌ 不提供审批操作功能（审批在"养殖档案监管"模块完成）。
- ❌ 不提供新增/编辑/删除档案记录的功能。
- ❌ 不新建汇总数据表，台账数据实时从各业务表聚合查询。

## 1.3 现状与复用

**现状简述**：
- 18 类养殖档案数据全部存储在企业端已定义的各业务表中（`pig_*` 系列表），每条记录有 `status` 字段标识审批状态，`status = '4'` 表示已入库。
- 养殖档案监管模块（`WEB监管端-养殖档案监管.prd.md`）已实现按 Tab 页签逐条查看各类别档案记录和审批操作，覆盖所有状态的数据。
- 本功能侧重已入库数据的全局视角统计和台账管理，与养殖档案监管互补不重叠。
- 企业基础信息存储在 `pig_enterprise` 表中，养殖企业信息管理模块已定义相关列表接口。

### 1.4.1 功能流程逻辑

**台账总览列表数据来源**：
- 后端按 `enterprise_id` 分组，对 18 张业务表分别统计 `status = '4'`（已入库）且 `del_flag = '0'`（未删除）的记录数。
- 同一 `enterprise_id` 的统计结果合并为一行，与 `pig_enterprise` 表 JOIN 获取企业名称、企业类型、所属乡镇、养殖规模。
- 最近更新时间取该企业在所有 18 张业务表中 `status = '4'` 的记录里 `create_time` 最大值。
- 不新建汇总表，每次查询实时聚合（企业数量有限，性能可接受）。

**台账数字点击跳转逻辑**：
- 台账列表中各档案类别列展示的数字（已入库记录数），点击后跳转到企业档案详情页并自动定位到对应类别的 Tab。
- 数字为 0 时显示红色字体，提示该企业该类别无归档数据，点击 0 同样可跳转（跳转后展示空列表）。

**企业档案详情页 Tab 结构**：
- Tab 页签按以下 5 个分组横向排列展示，与养殖档案监管页面 Tab 结构一致：

| 分组 | Tab 名称（按顺序） |
|------|----------------|
| 养殖管理 | 养殖信息、繁育信息、断奶信息、入栏信息、转栏信息、出栏信息 |
| 防疫免疫 | 畜禽免疫记录、消毒记录、防疫监测记录 |
| 投入品管理 | 兽药购进记录、兽药使用记录、饲料添加剂购进记录、配合饲料使用记录 |
| 疾病与处理 | 畜禽疾病诊疗记录、病死畜禽无害化处理记录、粪便及污物无害化处理记录 |
| 生产与销售 | 生产记录、畜禽及其产品销售记录 |

**企业档案详情页与养殖档案监管的区别**：

| 差异项 | 养殖档案监管 | 企业档案详情页（本功能） |
|-------|-----------|-------------------|
| 数据范围 | 所有状态（草稿/审批中/已入库/退回） | 仅已入库（`status = '4'`） |
| 筛选条件 | 企业名称、所属乡镇、状态、各类别自有条件 | 仅时间范围（已锁定具体企业和已入库状态） |
| 操作列 | 查看、审批操作按钮 | 仅「查看详情」，所有数据只读 |
| 页面入口 | 独立菜单入口 | 从台账总览列表中的「查看档案」进入 |

**导出文件名规则**：
- 台账总览导出：`档案台账总览_YYYYMMDD_HHmmss.xlsx`
- 企业档案导出：`{企业名称}_{档案类别}_YYYYMMDD_HHmmss.xlsx`

### 1.4.3 界面交互逻辑

**档案台账总览页面**：
- 页面标题：档案台账总览。
- 筛选栏（页面顶部）：
  - 企业名称（输入框，模糊搜索）
  - 所属乡镇（下拉选择，单选；乡镇角色不展示此筛选项，自动按本乡镇过滤）
  - 企业类型（下拉选择，单选；含"全部"选项，枚举值：`1` 规模养殖场、`2` 家庭农场、`3` 散养户、`4` 合作社）
  - 时间范围（日期区间选择器，按最近更新时间筛选）
  - 「查询」按钮 + 「重置」按钮
- 操作按钮区（筛选栏下方右侧）：「导出」按钮（默认色）。
- 台账列表表格：序号 + 企业基本信息列（企业名称、所属乡镇、企业类型、养殖规模）+ 18 个档案类别数字列 + 最近更新列 + 操作列。
- 各档案类别数字列：
  - 数字大于 0 时显示蓝色文字，鼠标悬浮变为手型光标，可点击跳转。
  - 数字等于 0 时显示红色字体（#f5222d），鼠标悬浮变为手型光标，可点击跳转（跳转后为空列表）。
- 操作列：「查看档案」蓝色文字按钮。
- 分页组件：每页 10 条，展示总条数、页码切换。
- 列表默认按最近更新时间倒序排列。
- 空数据时展示空状态占位图，提示"暂无数据"。

**企业档案详情页**：
- 页面顶部展示面包屑导航：档案台账总览 > {企业名称}。
- 面包屑下方为企业基本信息摘要区：以卡片形式展示企业名称、企业类型、法人代表、联系电话、养殖规模（头），所有信息只读。
- 摘要区下方为 Tab 页签栏 + 列表区域：
  - Tab 结构与养殖档案监管一致（18 个 Tab，按 5 个分组排列，分组间以竖线分隔）。
  - **Tab 切换为即时响应**：点击 Tab 标签后立即加载对应类别的已入库档案列表，无需额外点击「查询」按钮。切换过程中展示骨架屏加载效果。当前激活标签以主色底色 + 白色文字标识选中态，非激活标签为浅灰底色。
  - Tab 栏可横向滚动（当 Tab 总宽度超出页面宽度时，右侧出现「>」滚动箭头，左侧出现「<」滚动箭头）。
- 每个 Tab 下的列表：
  - 筛选栏：时间范围（日期区间选择器，按创建时间筛选）+ 「查询」按钮 + 「重置」按钮。
  - 操作按钮区（筛选栏下方右侧）：「导出」按钮（默认色）。
  - 列表字段：各类别业务字段列 + 操作列（仅「查看详情」文字按钮）。
  - 点击「查看详情」弹出对应档案类别的只读详情弹窗（弹窗内容复用养殖档案监管功能二的详情弹窗，但不展示审批进度和操作按钮）。
  - 分页组件：每页 10 条。
  - 列表默认按创建时间倒序排列。
  - 空数据时展示空状态占位图，提示"暂无数据"。

## 1.5 非功能需求

- **安全与权限**：
  - 需具备 `admin:archive:overview:list` 权限标识方可访问台账总览列表页面。
  - 需具备 `admin:archive:overview:query` 权限标识方可查看企业档案详情页。
  - 需具备 `admin:archive:overview:export` 权限标识方可执行导出操作。
  - 以上 3 个权限标识分配给：`county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`。
  - 数据权限按 `data_scope` + 部门树自动过滤：县级角色（`county_admin`、`county_staff`）看全县数据（`data_scope=1`），乡镇角色（`town_gov_staff`、`town_vet_station`）看本乡镇数据（`data_scope=4`）。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：台账总览列表查询响应时间不超过 5 秒（需对 18 张表做分组统计聚合，企业数量预估不超过 500 家）。企业档案详情页单个 Tab 列表查询响应时间不超过 3 秒。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示，Tab 栏支持横向滚动。
