## 2.2 目标与范围

**目标**：
1. 提供统一的全局检索入口，支持跨档案类别、跨企业的已入库档案数据检索。
2. 支持高级检索条件组合：档案类别（多选）、企业名称、所属乡镇、时间范围、填报人。
3. 检索结果以统一列表形式分页展示，每条记录标识所属档案类别，展示关键摘要信息。
4. 点击检索结果可查看对应档案的详情弹窗。
5. 支持导出当前检索结果（Excel）。
6. 数据范围按角色自动过滤：县级看全县，乡镇看本乡镇。

**非目标（Non-Goals）**：
- ❌ 不检索草稿、审批中、退回等非"已入库"状态的数据。
- ❌ 不提供审批操作功能。
- ❌ 不提供编辑/删除档案记录的功能。
- ❌ 初期不引入 Elasticsearch，使用数据库查询实现检索；如后续数据量增长可考虑引入。

## 2.3 现状与复用

**现状简述**：
- 18 类养殖档案数据分布在各自独立的业务表中，每张表的字段结构不同。
- 养殖档案监管模块已实现按 Tab 页签在单个类别内筛选查看，但不支持跨类别的统一检索。
- 本功能提供一个全局视角的检索能力，可一次搜索跨越多个档案类别和多家企业的数据。

**复用检查结论**：

**1. 接口复用检查（对照 `doc_spec/现有业务说明.spec.md`）**

| 检查项 | 现有资源 | 复用结论 | 说明 |

**关键流程**：

```
进入档案分类检索页面
    ↓
用户可在搜索框输入关键字 → 点击"搜索"或按回车触发检索
    ↓
```

### 2.4.1 功能流程逻辑

- 数据范围按当前用户角色的 `data_scope` + 部门树自动过滤。

### 2.4.3 界面交互逻辑

**档案分类检索页面**：
- 页面标题：档案分类检索。
- 页面顶部为搜索区域：
  - 主搜索框：宽度占页面 60%，左侧展示搜索图标，占位文字为"输入关键字搜索档案记录（企业名称、疫苗名称、药品名称、处理方法...）"，最大输入长度 200 字符。按回车或点击搜索按钮触发检索。
  - 搜索按钮：主搜索框右侧，主色按钮，文字"搜索"。
  - 高级检索展开/收起按钮：搜索框下方，文字"高级检索"，点击展开/收起高级筛选条件区域。默认收起状态。展开时显示向上箭头，收起时显示向下箭头。
- 高级检索条件区域（默认收起）：
  - 档案类别：下拉多选，默认全部选中，每个选项前有勾选框。
  - 企业名称：输入框（文本），模糊搜索。
  - 所属乡镇：下拉选择（单选），含"全部"选项；乡镇角色不展示此筛选项。
  - 时间范围：日期区间选择器。
  - 填报人：输入框（文本），模糊搜索。
  - 「查询」按钮 + 「重置」按钮。
- 检索结果统计区域（搜索区域下方）：
  - 以统计文字形式展示："共 **X** 条记录，涉及 **X** 个档案类别、**X** 家企业"。
  - X 为加粗蓝色数字。
  - 右侧展示「导出」按钮（默认色）。
- 检索结果列表：

- **搜索触发方式**：主搜索框按回车、点击「搜索」按钮、高级检索区域点击「查询」按钮，三种方式均可触发检索。
- **搜索加载状态**：检索请求发起后，列表区域展示骨架屏/loading 遮罩，搜索按钮变为禁用态并展示加载图标，防止重复提交。
- **搜索结果刷新**：每次触发检索后，分页重置为第 1 页，列表和统计信息同步刷新。
- **高级检索与主搜索框的关系**：主搜索框的关键字与高级检索条件为"且"（AND）关系，同时生效。主搜索框关键字在 18 张表的关键字段中做 LIKE 模糊匹配，高级检索条件进一步缩小范围。

### 2.4.4 接口路径定义

| 接口名称 | HTTP 方法 | 路径 | 请求参数摘要 | 响应数据摘要 | 备注 |
|----------|-----------|------|-------------|-------------|------|
| 档案全局检索 | GET | `/admin/archive/search` | pageNum、pageSize、keyword（全局关键字）、categories（档案类别标识数组）、enterpriseName（模糊）、areaCode（乡镇编码）、startTime、endTime、createBy（填报人，模糊） | 分页列表（统一结构：category、enterpriseName、areaName、summary、createBy、createTime、sourceId、sourceTable）+ 总条数 + categoryCount + enterpriseCount | 🆕 新增接口 |
| 各类别单条详情 | GET | `/farm/{category}/{id}` | — | 单条档案记录全部字段 | ✅ 复用企业端各模块详情接口；`category` 为该记录对应的基础 API 路径段 |
| 导出检索结果 | POST | `/admin/archive/search/export` | keyword、categories、enterpriseName、areaCode、startTime、endTime、createBy | Excel 文件流 | 🆕 新增接口 |
| 部门树下拉（乡镇筛选） | GET | `/system/dept/treeselect` | — | 部门树结构 | ✅ 复用现有接口，见现有业务说明.spec.md §三 |

**接口响应中额外字段说明**：

| 字段 | 说明 |
|------|------|
| `sourceId` | 该条记录在原业务表中的主键 ID，用于调用详情接口 |
| `sourceTable` | 该条记录所属的业务表名（如 `pig_breeding_info`），用于前端判断调用哪个详情接口路径 |

## 2.5 非功能需求

- **安全与权限**：
  - 需具备 `admin:archive:search` 权限标识方可访问档案分类检索页面。
  - 需具备 `admin:archive:search:export` 权限标识方可执行导出操作。
  - `admin:archive:search` 权限分配给：`county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`。
  - `admin:archive:search:export` 权限分配给：`county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`。
  - 数据权限按 `data_scope` + 部门树自动过滤：县级角色（`county_admin`、`county_staff`）看全县数据（`data_scope=1`），乡镇角色（`town_gov_staff`、`town_vet_station`）看本乡镇数据（`data_scope=4`）。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：
  - 检索接口响应时间不超过 5 秒（初期使用数据库 LIKE 查询，18 张表依次查询后 UNION 合并）。
  - 单张业务表数据量预估不超过 50000 条，18 张表总量预估不超过 500000 条。
  - 如后续数据量增长导致性能不佳，可引入 Elasticsearch 优化搜索性能。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示。
