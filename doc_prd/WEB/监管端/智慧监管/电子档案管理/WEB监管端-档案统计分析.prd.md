## 3.1 基本信息

- **功能名称**：档案统计分析
- **关联现有模块/功能**：
  - 用户认证：复用现有 `/login`、`/getInfo`、`/getRouters` 接口与 JWT 机制
  - 权限管理：复用现有角色权限体系，新增"档案统计分析"权限标识 `admin:archive:stats`

## 3.2 目标与范围

**目标**：
1. 对已入库档案数据进行 7 个维度的统计分析，以图表和数据表格形式展示。
2. 支持全局筛选条件：时间范围、所属乡镇、企业名称，动态刷新所有统计面板。
3. 每个统计卡片包含图表区域和可折叠的数据表格区域，图表支持 hover 查看具体数值。
4. 支持整页统计报告导出（Excel）和单个统计项导出（Excel 或 PNG 图片）。
5. 数据范围按角色自动过滤：县级看全县，乡镇看本乡镇。

**非目标（Non-Goals）**：
- ❌ 不提供"产业发展视角"的深度分析（如 PSY 排行、养殖成本、预警趋势），这些属于第4阶段"决策分析"的范畴。
- ❌ 不引入定时任务生成统计快照表（初期），统计数据实时从业务表聚合查询。
- ❌ 不提供自定义统计维度或拖拽式报表功能。

## 3.3 现状与复用

**现状简述**：
- 18 类养殖档案数据存储在各自独立的业务表中，每条记录有 `status` 字段标识状态。
- 目前系统无档案层面的统计分析功能，需全部新建。

### 3.4.1 功能流程逻辑

**全局筛选条件**：

| 序号 | 筛选条件 | 控件类型 | 是否必填 | 默认值 | 说明 |
|------|---------|---------|---------|-------|------|
| 1 | 时间范围 | 日期区间选择器 | 选填 | 近一年（当前日期往前推 12 个月） | 筛选各业务表中 `create_time` 在此范围内的记录 |
| 2 | 所属乡镇 | 下拉选择（单选） | 选填 | 全部 | 含"全部"选项；乡镇角色不展示此筛选项（自动按本乡镇过滤）；数据来自 `GET /system/dept/treeselect` |
| 3 | 企业名称 | 输入框（文本） | 选填 | 空 | 模糊搜索，选定某一家企业或留空查看全部；最大长度 100 字符 |

修改任一筛选条件后，需点击「查询」按钮触发所有统计面板刷新。点击「重置」按钮恢复默认值并刷新。

**7 个统计项详细规则**：

---

**统计项一：存出栏统计**

- **数据来源**：
  - 存栏数据：`pig_breeding_info` 表的 `stock_quantity`（存栏数量）字段，按 `statistics_date`（统计日期）聚合
  - 出栏数据：`pig_outbound_record` 表的 `outbound_quantity`（出栏数量）字段，按 `outbound_date`（出栏日期）聚合
- **统计逻辑**：按时间粒度（月/季/年）分组，SUM 汇总存栏数量和出栏数量
- **图表类型**：折线图，X 轴为时间，Y 轴为数量（头），两条折线分别代表存栏量和出栏量
- **时间粒度切换**：支持按月、按季、按年三种粒度切换，切换方式为图表区域右上角的单选按钮组，枚举值：`month` 按月、`quarter` 按季、`year` 按年，仅此 3 种取值
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 时间周期 | 按时间粒度展示（如 2025-01、2025-Q1、2025） |
| 存栏量（头） | 该时间周期内的存栏数量总和 |
| 出栏量（头） | 该时间周期内的出栏数量总和 |
| 环比增长率 | 与上一周期对比的增长率，百分比格式，保留 2 位小数 |

---

**统计项二：免疫防疫统计**

- **数据来源**：`pig_immune_vaccination_record` 表
- **统计逻辑**：按 `vaccine_name`（疫苗名称）分组，SUM `actual_immune_number`（实免数），同时统计各企业的免疫记录数与企业总数得出免疫覆盖率
- **图表类型**：柱状图，X 轴为疫苗名称（前 10 名，其余归为"其他"），Y 轴为免疫数量（头/只）
- **免疫覆盖率计算**：（有免疫记录的企业数 / 筛选范围内的企业总数）× 100%，在图表区域右上角以数字指标卡形式展示
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 疫苗名称 | 疫苗通用名称 |
| 免疫数量（头/只） | 该疫苗的实免数总和 |
| 免疫记录数（条） | 使用该疫苗的记录总条数 |
| 占比 | 该疫苗免疫数量占全部免疫数量的比例，百分比格式，保留 2 位小数 |

---

**统计项三：无害化处理统计**

- **数据来源**：
  - 病死畜禽：`pig_dead_animal_record` 表
  - 粪便污物：`pig_manure_harmless_record` 表
- **统计逻辑**：
  - 饼图：按 `disposal_method`（处理方法/处理方式）分组，COUNT 记录数
  - 折线图：按月份分组，SUM `dead_quantity`（病死数量）
- **图表类型**：左侧饼图展示处理方式分布，右侧折线图展示病死数量月度趋势
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 处理方式 | 处理方法名称 |
| 病死畜禽处理数量（头/只） | 该处理方式对应的病死数量总和 |
| 粪便产生量（吨） | 该处理方式对应的粪便产生量总和 |
| 污水产生量（吨） | 该处理方式对应的污水产生量总和 |
| 记录数（条） | 使用该处理方式的记录总条数 |
| 占比 | 该处理方式记录数占全部记录数的比例，百分比格式，保留 2 位小数 |

---

**统计项四：投入品使用统计**

- **数据来源**：
  - 兽药使用：`pig_vet_drug_record` 表
  - 兽药采购：`pig_vet_drug_purchase_record` 表
  - 饲料使用：`pig_feed_record` 表
  - 饲料采购：`pig_feed_purchase_record` 表
- **统计逻辑**：按投入品大类（兽药使用、兽药采购、饲料使用、饲料采购）分组统计记录数和数量
- **图表类型**：柱状图，X 轴为投入品大类（固定 4 类：兽药使用、兽药采购、饲料使用、饲料采购），Y 轴为记录条数
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 投入品类别 | 兽药使用、兽药采购、饲料使用、饲料采购，仅此 4 种取值 |
| 记录数（条） | 该类别的已入库记录总条数 |
| 涉及企业数 | 有该类别记录的不重复企业数 |
| 产品种类数 | 不重复的产品名称/兽药名称数量 |

---

**统计项五：疾病诊疗统计**

- **数据来源**：`pig_disease_treatment_record` 表
- **统计逻辑**：
  - 饼图：按 `diagnosis_result`（诊疗结果）分组，COUNT 记录数
  - 折线图：按月份分组，COUNT 记录数，展示发病趋势
- **图表类型**：左侧饼图展示诊疗结果分布，右侧折线图展示月度发病趋势
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 月份 | 格式 YYYY-MM |
| 诊疗记录数（条） | 该月的诊疗记录总条数 |
| 涉及企业数 | 该月有诊疗记录的不重复企业数 |
| 环比增长率 | 与上月对比的增长率，百分比格式，保留 2 位小数 |

---

**统计项六：销售统计**

- **数据来源**：`pig_sales_record` 表
- **统计逻辑**：
  - 柱状图：按月份分组，SUM `quantity`（数量），展示销售数量时间趋势
  - 饼图：按 `sales_destination`（销往去向）分组，SUM `quantity`（数量），展示去向分布
- **图表类型**：左侧柱状图展示月度销售数量，右侧饼图展示销售去向分布
- **数据表格字段**：

| 列名 | 说明 |
|------|------|
| 月份 | 格式 YYYY-MM |
| 销售数量 | 该月销售数量总和，单位与原始数据一致 |
| 涉及企业数 | 该月有销售记录的不重复企业数 |
| 主要去向 | 该月销售数量最多的去向名称 |

---

**统计项七：档案填报情况统计**

- **数据来源**：18 张业务表
- **统计逻辑**：按 `enterprise_id`（行）× 18 个档案类别（列）交叉统计 `status = '4'` 的记录数，形成矩阵
- **图表类型**：热力表格（Table 形式，单元格背景色深浅代表填报数量多少）
- **热力表格配色规则**：

| 填报数量范围 | 单元格背景色 | 说明 |
|-----------|-----------|------|
| 0 条 | 红色 #fff1f0 + 红色文字 #f5222d | 无归档数据，醒目提示 |
| 1-5 条 | 浅绿 #f6ffed | 有少量数据 |
| 6-20 条 | 中绿 #d9f7be | 数据量中等 |
| 21-50 条 | 深绿 #b7eb8f | 数据量较多 |
| 51 条及以上 | 浓绿 #73d13d + 白色文字 | 数据量充足 |

- **热力表格行列定义**：

| 维度 | 内容 |
|------|------|
| 行 | 各养殖企业（enterprise_name），按企业名称排序 |
| 列 | 18 个档案类别（按养殖管理→防疫免疫→投入品管理→疾病与处理→生产与销售分组排列），另加"合计"列 |
| 单元格值 | 该企业该类别的已入库记录数 |
| 合计列 | 该企业所有类别的已入库记录数总和 |
| 合计行（末行） | 各类别所有企业的已入库记录数总和 |

- **数据表格**：热力表格本身即为数据表格，无需额外展示，但支持导出为 Excel。

### 3.4.2 数据模型与字段定义

本功能无新建表，所有统计数据从已有业务表实时聚合。

**各统计接口通用请求参数**：

| 参数名（英文） | 类型 | 必填 | 说明 |
|-------------|------|------|------|
| `startTime` | string | 选填 | 时间范围开始，格式 YYYY-MM-DD |
| `endTime` | string | 选填 | 时间范围结束，格式 YYYY-MM-DD |
| `areaCode` | string | 选填 | 乡镇编码，为空时按角色数据范围自动过滤 |
| `enterpriseName` | string | 选填 | 企业名称模糊搜索，最大长度 100 字符 |

**存出栏统计接口额外请求参数**：

| 参数名（英文） | 类型 | 必填 | 说明 |
|-------------|------|------|------|
| `granularity` | string | 选填 | 时间粒度，枚举值：`month` 按月、`quarter` 按季、`year` 按年，默认 `month`，仅此 3 种取值 |

**存出栏统计响应数据结构**：

| 字段名（英文） | 类型 | 说明 |

**无害化处理统计响应数据结构**：

### 3.4.3 界面交互逻辑

**档案统计分析页面**：
- 页面标题：档案统计分析。
- 全局筛选栏（页面顶部固定区域）：
  - 时间范围（日期区间选择器，默认近一年）
  - 所属乡镇（下拉选择，单选，含"全部"选项；乡镇角色不展示此筛选项）
  - 企业名称（输入框，模糊搜索）
  - 「查询」按钮 + 「重置」按钮
  - 「导出统计报告」按钮（默认色，仅 `county_admin` 和 `county_staff` 角色展示）
- 统计面板区域（筛选栏下方，可滚动）：
  - 7 个统计卡片以两列网格布局排列（大屏两列，小屏单列自适应）。
  - 每个统计卡片的结构：
    - 卡片标题栏：标题文字（左）+ 导出操作按钮组（右，含「导出数据」和「导出图表」两个小按钮）。
    - 图表区域：占卡片主体，使用 ECharts 渲染，最小高度 300px。
    - 数据表格区域：默认收起，标题栏右侧有「展开数据表格」/「收起数据表格」切换按钮。展开后在图表下方展示数据表格。
  - 卡片排列顺序：存出栏统计、免疫防疫统计、无害化处理统计、投入品使用统计、疾病诊疗统计、销售统计、档案填报情况统计。
  - 档案填报情况统计卡片（热力表格）占满两列宽度。

**各图表交互细节**：

- 所有图表支持 hover 交互：鼠标悬浮在数据点/柱子/扇形上时，展示 Tooltip 浮窗显示具体数值。
- 折线图 Tooltip 格式："时间: XXX \n 存栏量: XXX 头 \n 出栏量: XXX 头"。
- 柱状图 Tooltip 格式："名称: XXX \n 数量: XXX"。
- 饼图 Tooltip 格式："名称: XXX \n 数量: XXX \n 占比: XX.XX%"。
- 折线图和柱状图支持图例（Legend）点击隐藏/显示数据系列。
- 存出栏统计卡片图表区域右上角展示时间粒度切换按钮组（按月 / 按季 / 按年），点击切换后图表自动重新加载。
- 免疫防疫统计卡片图表区域右上角展示免疫覆盖率指标卡："免疫覆盖率 XX.XX%"，绿色加粗数字。
- 无害化处理统计和疾病诊疗统计：左侧饼图占 40% 宽度，右侧折线图占 60% 宽度。
- 销售统计：左侧柱状图占 60% 宽度，右侧饼图占 40% 宽度。
- 热力表格（档案填报情况统计）：行列标题固定（首行和首列冻结），可横向和纵向滚动查看全部数据。

**导出交互**：
- 每个卡片标题栏右侧的「导出数据」按钮：点击后导出该统计项的数据表格为 Excel，文件名格式：`{统计项名称}_YYYYMMDD_HHmmss.xlsx`。
- 每个卡片标题栏右侧的「导出图表」按钮：点击后导出该统计项的图表为 PNG 图片，文件名格式：`{统计项名称}_YYYYMMDD_HHmmss.png`。利用 ECharts 内置的 `getDataURL()` 方法导出。

**加载状态**：
- 页面进入和筛选条件变更后，各统计卡片独立展示 loading 状态（旋转加载图标 + "加载中..."文字）。
- 某个统计接口加载失败时，对应卡片展示错误提示"数据加载失败，请重试"和「重试」按钮，不影响其他卡片正常展示。

## 3.5 非功能需求

- **安全与权限**：
  - 需具备 `admin:archive:stats` 权限标识方可访问档案统计分析页面。
  - 需具备 `admin:archive:stats:export` 权限标识方可执行导出操作。
  - `admin:archive:stats` 权限分配给：`county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`。
  - `admin:archive:stats:export` 权限仅分配给：`county_admin`、`county_staff`。乡镇角色可查看统计但不可导出全局统计报告。
  - 数据权限按 `data_scope` + 部门树自动过滤：县级角色（`county_admin`、`county_staff`）看全县数据（`data_scope=1`），乡镇角色（`town_gov_staff`、`town_vet_station`）看本乡镇数据（`data_scope=4`）。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：
  - 各统计接口独立返回，单个统计接口响应时间不超过 5 秒。
  - 页面采用异步并行加载策略：7 个统计接口并行请求，各卡片独立渲染，不因某一个慢的接口阻塞整个页面。
  - 如后续数据量增大导致统计查询性能不佳，可引入定时任务生成统计快照表进行优化，初期不做。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示。图表组件使用 ECharts，与后续产业大屏保持技术栈统一。
