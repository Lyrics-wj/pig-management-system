## 3.1 基本信息

- **功能名称**：大屏配置
- **关联现有模块/功能**：
  - 用户认证：复用现有 `/login`、`/getInfo`、`/getRouters` 接口与 JWT 机制
  - 权限管理：复用现有角色权限体系，新增"大屏配置"相关权限标识
  - 产业总览大屏：`doc_prd/WEB/监管端/产业驾驶舱/产业总览/WEB监管端-产业总览大屏.prd.md`，大屏配置模块产出的看板可替代或扩展固定布局的产业总览大屏
  - 字典管理：复用 `/system/dict/data/type/{dictType}` 接口获取组件分类、数据源类型枚举
  - 通用文件上传：复用 `/common/upload`、`/common/uploads` 接口上传背景图、图标等资源文件
  - 参考文档：`doc_spec/现有业务说明.spec.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（role_key） | 使用场景 | 主要操作 |
|---------|---------------------|---------|---------|
| 超级管理员 | `super_admin` | 系统级大屏配置管理 | 全部操作：创建/编辑/发布/删除项目、管理资源库、管理数据源、分配看板权限 |
| 县级管理员 | `county_admin` | 定制产业大屏看板 | 创建/编辑/发布/删除项目、管理资源库、管理数据源、分配看板权限 |
| 县级业务人员 | `county_staff` | 查看已发布的大屏看板 | 查看已授权的看板链接 |

> 角色编码引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1 角色总览。
>
> 大屏配置模块面向具备管理权限的县级角色，乡镇角色不配置大屏配置权限。配置完成后发布的看板链接可分配给不同角色查看。

## 3.2 目标与范围

**目标**：

1. 提供可视化拖拽式大屏编辑器，支持组件的自由拖拽定位、尺寸调整、图层管理，使县级管理人员无需编码即可搭建数据可视化看板。
2. 提供数据源管理能力，支持配置关系型数据库查询语句作为数据源，数据内容来源于系统内养殖分析、市场贸易分析、检验检疫无害化分析、视频监管等功能板块。
3. 支持项目看板的角色权限分配，将不同看板分配给不同角色查看，保证数据安全。
4. 提供资源管理功能，支持 2D 图标、修饰条、背景图等素材的上传、分类、预览和删除。
5. 提供丰富的组件库，包含数据图表（柱状图、折线图、饼图、仪表盘等）、数据表格、视频播放、文本、大屏装饰素材（边框、标题栏、分隔线等）组件。
6. 提供项目管理功能，支持看板项目的快速创建、编辑、删除、克隆、封面设置，以及项目预览、发布和看板链接有效期控制。

**非目标（Non-Goals）**：

- ❌ 不做移动端适配（大屏配置器为桌面端操作工具）。
- ❌ 不支持多人同时协作编辑同一看板（同一时间仅一人编辑）。
- ❌ 不做实时数据流对接（数据源为定时轮询查询，不接入 WebSocket 实时推送）。
- ❌ 不支持自定义 JavaScript 脚本组件（仅提供预置组件库中的组件类型）。
- ❌ 不做 3D 场景渲染（仅支持 2D 可视化图表和装饰素材）。
- ❌ 不提供数据源直连外部第三方数据库（仅支持查询本系统内数据库）。

## 3.3 现状与复用

**现状简述**：

- 产业总览大屏已实现固定布局的全屏展示页面，但布局和组件不可由用户自行调整。
- 现有系统的养殖分析、市场贸易分析、检验检疫无害化分析等模块已建立完善的数据接口，可作为大屏配置的数据来源。
- 现有通用文件上传接口（`/common/upload`）可用于素材资源上传。
- 角色权限体系（RBAC）已完善，可在此基础上实现看板的角色分配。
- 目前系统无大屏配置功能，需新建项目管理、画布编辑、数据源管理、资源管理、组件库等全套功能。

### 3.4.1 功能流程逻辑

#### 一、项目管理

##### 1.1 项目列表页

**页面布局**：
- 顶部操作栏：搜索框（按项目名称搜索）+ 「新建项目」按钮
- 主区域：卡片网格布局，每行最多 4 张项目卡片
- 每张项目卡片展示：封面图、项目名称、发布状态标签、最后更新时间、操作菜单（编辑、预览、发布/取消发布、克隆、设置、删除）

**项目卡片信息**：

| 展示项 | 数据来源 | 说明 |
|-------|---------|------|
| 封面图 | `screen_project.cover_url` | 项目封面缩略图；无封面时显示默认占位图（深色渐变背景 + 项目名称首字） |
| 项目名称 | `screen_project.project_name` | 最多显示 20 个字符，超出截断加省略号 |
| 发布状态 | `screen_project.status` | Tag 标签：`0` 草稿-灰色、`1` 已发布-绿色、`2` 已过期-橙色 |
| 最后更新时间 | `screen_project.update_time` | 格式 YYYY-MM-DD HH:mm |
| 操作菜单 | — | 更多操作下拉菜单 |

**操作菜单项**：

| 菜单项 | 触发条件 | 操作说明 |
|-------|---------|---------|
| 编辑 | 任何状态 | 进入画布编辑器 |
| 预览 | 任何状态 | 新窗口全屏预览 |
| 发布 | 状态为草稿（`0`）或已过期（`2`） | 将项目发布为已发布状态 |
| 取消发布 | 状态为已发布（`1`） | 将项目切回草稿状态 |
| 克隆 | 任何状态 | 复制项目生成新项目 |
| 设置 | 任何状态 | 打开项目设置弹窗 |
| 删除 | 任何状态 | 二次确认后删除项目 |

##### 1.2 新建项目

**弹窗表单字段**：

| 字段名称 | 对应字段 | 控件类型 | 必填 | 校验规则 | 说明 |
|---------|---------|---------|------|---------|------|
| 项目名称 | `project_name` | 文本输入框 | 是 | 不为空，最大长度 50 字符，项目名称唯一 | — |
| 画布宽度 | `canvas_width` | 数值输入框 | 是 | 正整数，最小值 800，最大值 7680 | 单位：像素（px），默认值 1920 |
| 画布高度 | `canvas_height` | 数值输入框 | 是 | 正整数，最小值 600，最大值 4320 | 单位：像素（px），默认值 1080 |
| 背景颜色 | `bg_color` | 颜色选择器 | 否 | 合法 HEX 颜色值 | 默认值 `#0d1b2a`（深蓝色） |
| 背景图片 | `bg_image_url` | 图片上传 | 否 | 支持 jpg、png、webp 格式，最大 5MB | 上传后覆盖背景颜色 |
| 分辨率预设 | — | 下拉选择 | 否 | — | 快捷选择：1920×1080（Full HD）、2560×1440（2K）、3840×2160（4K），选择后自动填充宽高 |

**提交流程**：
1. 前端校验全部必填项和格式。
2. 调用新建项目接口，后端创建项目记录并自动创建关联的空白画布记录。
3. 创建成功后自动跳转进入画布编辑器。

##### 1.3 项目克隆

- 点击「克隆」后弹出确认弹窗，显示"确认克隆项目「{项目名称}」？"
- 确认后后端复制以下数据：项目基本信息（名称追加"_副本"后缀）、画布配置、所有组件实例及其属性、数据源绑定关系
- 不复制的内容：发布状态（克隆项目默认为草稿）、看板链接与有效期、角色权限分配
- 克隆完成后项目列表刷新，新项目显示在列表首位

##### 1.4 项目发布与链接管理

**发布操作**：
- 点击「发布」按钮，弹出发布确认弹窗
- 弹窗内容：
  - 看板访问链接：系统自动生成（格式 `/screen/view/{projectToken}`，`projectToken` 为系统生成的 32 位随机字符串）
  - 链接有效期：日期时间选择器，选择过期时间；可选"永不过期"
  - 确认发布按钮
- 发布后项目状态变为「已发布」（`status = '1'`），生成的链接在有效期内可访问

**链接有效期控制**：
- 有效期字段 `expire_time`：datetime 类型，NULL 表示永不过期
- 访问看板链接时，后端校验：
  1. 项目状态为已发布（`status = '1'`）
  2. 当前时间未超过 `expire_time`（若 `expire_time` 为 NULL 则不校验过期）
  3. 当前登录用户的角色在该项目的授权角色列表中
- 校验不通过时返回对应提示："看板未发布"、"看板链接已过期"、"无权限访问该看板"
- 已过期的项目状态自动更新为「已过期」（`status = '2'`），由后端定时任务每分钟扫描处理

**取消发布操作**：
- 点击「取消发布」，弹出确认弹窗："取消发布后，已分发的看板链接将立即失效，确认操作？"
- 确认后项目状态变为「草稿」（`status = '0'`），看板链接不可访问

##### 1.5 项目设置

**弹窗包含以下设置项**：

**Tab 1：基本信息**
- 修改项目名称、画布宽高、背景颜色、背景图片（字段与新建项目一致）

**Tab 2：权限分配**
- 角色列表：以复选框列表形式展示系统中所有角色（来自 `GET /system/role/optionselect`）

#### 三、数据源管理

##### 3.1 数据源类型

| 数据源类型 | 类型编码 | 说明 |
|----------|---------|------|
| SQL查询 | `sql` | 配置 SELECT 语句，直接查询系统数据库中的数据 |
| 系统接口 | `api` | 配置系统内现有 API 接口地址，通过 HTTP 请求获取数据 |

##### 3.2 新建/编辑数据源

**弹窗表单字段**：

| 字段名称 | 对应字段 | 控件类型 | 必填 | 校验规则 | 说明 |
|---------|---------|---------|------|---------|------|
| 数据源名称 | `ds_name` | 文本输入框 | 是 | 不为空，最大长度 50 字符，同一项目内名称唯一 | — |
| 数据源类型 | `ds_type` | 下拉选择 | 是 | 必选 | 选项：SQL查询（`sql`）、系统接口（`api`），共 2 种取值 |
| SQL查询语句 | `sql_content` | 代码编辑器（SQL语法高亮） | 类型为 `sql` 时必填 | 不为空，最大长度 5000 字符，必须以 SELECT 开头（不区分大小写），禁止包含 INSERT、UPDATE、DELETE、DROP、ALTER、CREATE、TRUNCATE 关键字 | 仅 `ds_type = 'sql'` 时显示 |
| 接口地址 | `api_url` | 文本输入框 | 类型为 `api` 时必填 | 不为空，最大长度 500 字符，必须以 `/` 开头 | 仅 `ds_type = 'api'` 时显示；相对路径，系统自动补充域名和认证头 |
| 请求方式 | `api_method` | 下拉选择 | 类型为 `api` 时必填 | 必选 | 仅 `ds_type = 'api'` 时显示；选项：GET、POST，共 2 种取值 |
| 请求参数 | `api_params` | JSON编辑器 | 否 | 合法 JSON 格式 | 仅 `ds_type = 'api'` 时显示；GET 请求追加为 URL 参数，POST 请求作为请求体 |
| 刷新频率（秒） | `refresh_interval` | 数值输入框 | 是 | 正整数，最小值 5，最大值 86400 | 默认值 300（5分钟），单位秒 |

**SQL查询安全约束**：
- 后端对 `sql_content` 进行二次校验：
  1. 正则匹配确保语句以 `SELECT` 开头
  2. 正则匹配确保不包含 `INSERT`、`UPDATE`、`DELETE`、`DROP`、`ALTER`、`CREATE`、`TRUNCATE`、`EXEC`、`EXECUTE`、`GRANT`、`REVOKE` 关键字（全文不区分大小写匹配）
  3. 禁止包含分号 `;`（防止多语句注入）
  4. 查询超时限制：SQL 执行超时时间为 10 秒，超时自动终止并返回错误
  5. 查询结果行数限制：最多返回 1000 行数据，超出部分截断
- 数据库连接使用只读账号，该账号仅具有 SELECT 权限

##### 3.3 数据源测试

- 点击「测试」按钮，后端执行数据源查询并返回结果

##### 5.2 权限校验规则

| 校验环节 | 校验内容 | 不通过处理 |
|---------|---------|----------|
| 进入大屏配置管理页 | 用户是否拥有 `admin:screen:config` 权限 | 菜单不可见，直接访问 URL 返回 403 |
| 查看已发布看板 | 用户是否拥有 `admin:screen:view` 权限 + 看板是否已分配给用户角色 | 菜单中不显示未授权的看板 |

| 编辑/删除/发布操作 | 用户是否拥有 `admin:screen:config` 权限 | 对应按钮不可见或禁用 |

### 3.4.3 界面交互逻辑

**项目列表页**：

- 页面加载后自动请求项目列表数据，展示项目卡片网格。
- 搜索框输入后按回车或点击搜索图标触发搜索，按项目名称模糊匹配筛选。
- 项目卡片 hover 时整体上移 4px 并加阴影效果（CSS `transform: translateY(-4px)` + `box-shadow`）。
- 操作菜单为卡片右上角「...」按钮点击展开的下拉菜单，菜单项根据项目状态动态显示（如已发布项目显示"取消发布"而非"发布"）。
- 删除操作二次确认弹窗文案："确认删除项目「{项目名称}」？删除后不可恢复。"
- 项目列表为空时显示空状态图标和文案"暂无大屏项目，点击「新建项目」开始创建"。

**画布编辑器**：

- 编辑器采用全屏布局（隐藏系统顶栏和侧栏），独立路由 `/screen/editor/{projectId}`。
- 左侧面板和右侧面板可通过拖拽边缘调整宽度，也可通过点击面板边缘的折叠按钮收起/展开。
- 从组件库拖拽组件到画布的过程中，画布上显示组件的虚线轮廓（drop preview），松手后组件以默认尺寸实例化。
- 组件拖拽移动过程中，画布上实时显示对齐辅助线（红色虚线）和距离标注（px 数值），松手后辅助线消失。
- 选中组件后，右侧属性面板立即切换显示该组件的配置项（Tab 自动切换到"基础属性"）。
- 右侧属性面板中修改数值后：
  - 数值输入框：失焦时立即应用修改到画布上。
  - 颜色选择器：实时预览颜色变化。
  - 下拉选择：选中后立即应用。
  - 开关：切换后立即应用。
- 画布上所有修改都是即时预览的，但需点击「保存」按钮才持久化到后端。
- 保存操作：将当前画布中所有组件的坐标、尺寸、属性、数据源绑定等信息打包为 JSON，调用保存接口一次性提交。
- 保存成功提示 "保存成功" 绿色 Toast，2 秒自动消失。保存失败显示红色 Toast "保存失败，请重试"。
- 自动保存：每 120 秒自动保存一次（如有修改），底部状态栏显示"自动保存于 HH:mm:ss"。
- 撤销/重做操作记录的是组件级变更（增删改），最多保留 50 步。页面刷新后操作历史清空。

**数据源管理**：

- 新建/编辑数据源弹窗中，切换数据源类型时，表单字段区域平滑切换（CSS transition），不相关的字段隐藏。
- SQL查询语句代码编辑器提供基础的 SQL 语法高亮和行号，编辑区域高度 200px，可拖拽调整高度。
- 测试按钮点击后显示 loading 状态，最长等待 15 秒（10 秒超时 + 5 秒网络延迟缓冲），超时后显示"测试超时"。
- 删除数据源前检查是否有组件绑定了该数据源，如有则弹窗提示"该数据源正在被 X 个组件使用，删除后对应组件将失去数据绑定，确认删除？"。

**资源管理**：

- 资源管理页面为独立页面，通过大屏配置页面的顶部导航进入（项目列表页顶部有"项目管理"、"资源管理"两个导航 Tab）。
- 左侧分类树点击分类名称后，右侧列表立即刷新为对应分类的资源。
- 资源卡片缩略图等比缩放裁切展示，宽度固定 160px，高度 120px。
- 上传弹窗中文件上传进度条实时更新，上传完成后进度条变为绿色，失败变为红色并显示失败原因。
- 拖拽文件到上传区域时，上传区域边框变为蓝色虚线高亮。

**看板展示页**：

- 看板展示页为独立路由 `/screen/view/{projectToken}`，不嵌套在管理系统 Layout 中。
- 页面打开后以全屏深色背景展示，画布内容等比缩放适配浏览器窗口。
- 数据源绑定的组件按各自刷新频率自动刷新数据，刷新时组件无闪烁（增量更新）。
- 页面异常处理：
  - 项目未发布：显示居中提示"该看板未发布"。
  - 链接已过期：显示居中提示"看板链接已过期，请联系管理员"。
  - 无权限：显示居中提示"无权限访问该看板"。
  - 项目不存在：显示居中提示"看板不存在"。

**加载状态与降级处理**：

- 项目列表页加载时显示骨架屏（4 张卡片骨架）。
- 画布编辑器加载时显示全屏 loading 动画。
- 组件数据源加载失败时，组件内显示灰色提示"数据加载失败，请检查数据源配置"，组件边框变为红色虚线。
- 图片资源加载失败时显示缺失图片占位符（灰色背景 + 断裂图片图标）。

**空状态处理**：

- 项目列表无项目时：空状态插图 + "暂无大屏项目，点击「新建项目」开始创建"。
- 画布无组件时：画布中央显示灰色虚线框 + "从左侧组件库拖拽组件到此处"。
- 数据源列表为空时：显示"暂无数据源，点击下方按钮创建"。
- 资源列表为空时：显示"暂无资源，点击「上传资源」添加"。

## 3.5 非功能需求

- **安全与权限**：
  - 权限标识：

  | 权限标识 | 说明 | 拥有角色 |
  |---------|------|---------|
  | `admin:screen:config` | 大屏配置管理（创建/编辑/发布/删除项目、管理数据源、管理资源） | `super_admin`、`county_admin` |
  | `admin:screen:view` | 查看已发布大屏看板 | `super_admin`、`county_admin`、`county_staff` |

  - 大屏配置管理仅向超级管理员和县级管理员开放。县级业务人员仅可查看已授权的已发布看板。
  - 乡镇角色不配置大屏配置相关权限。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
  - **SQL查询安全**：
    - 数据源 SQL 查询仅允许 `SELECT` 语句，后端白名单校验。
    - SQL 执行使用只读数据库账号，仅具有 SELECT 权限。
    - SQL 执行超时限制 10 秒。
    - SQL 查询结果最多返回 1000 行。
    - 禁止 SQL 注入风险关键字（`INSERT`、`UPDATE`、`DELETE`、`DROP`、`ALTER`、`CREATE`、`TRUNCATE`、`EXEC`、`EXECUTE`、`GRANT`、`REVOKE`）和分号 `;`。

- **性能**：
  - 项目列表页加载时间控制在 2 秒以内。
  - 画布编辑器加载时间（含画布配置和全部组件）控制在 3 秒以内。
  - 画布上同时放置不超过 100 个组件时，拖拽操作帧率不低于 30fps。
  - 数据源 SQL 查询超时时间为 10 秒。
  - 数据源查询结果最多返回 1000 行。
  - 画布保存操作将全部组件配置打包为 JSON 一次性提交，单次保存请求体大小不超过 2MB。
  - 资源图片上传单文件大小按分类限制（图标 500KB、修饰条 2MB、背景图 10MB）。
  - 看板展示页面长时间运行需防止内存泄漏：定时器在页面离开时统一清理、ECharts 实例在页面销毁时调用 `dispose()`。

- **兼容性**：
  - 画布编辑器适配 1366×768 及以上分辨率。
  - 看板展示页面适配 1920×1080 至 3840×2160 分辨率范围。
  - 图表组件使用 ECharts 渲染。
  - 支持 Chrome 80+、Edge 80+、Firefox 80+ 浏览器。

- [ ] 可新建项目，设置项目名称、画布宽高、背景颜色/图片，创建后自动进入画布编辑器。

### F. 与产业总览大屏的关系

- 产业总览大屏（`WEB监管端-产业总览大屏.prd.md`）为固定布局的预置大屏，布局和组件由前端代码硬编码。
- 大屏配置模块提供可视化拖拽搭建能力，管理员可利用大屏配置模块创建自定义看板来替代或补充固定布局大屏。
- 两者独立运行，互不影响。管理员可同时使用产业总览大屏（快速查看）和自定义看板（灵活展示）。
- 大屏配置模块的组件库中包含了与产业总览大屏相同类型的图表和装饰组件（ECharts 图表、科技感装饰元素），可复现产业总览大屏的展示效果。
