## 3.1 基本信息

- **功能名称**：产业总览大屏
- **关联现有模块/功能**：
  - 用户认证：复用现有 `/login`、`/getInfo`、`/getRouters` 接口与 JWT 机制
  - 权限管理：复用现有角色权限体系，新增"产业总览大屏"权限标识 `admin:analysis:screen`
  - 养殖企业信息管理：`pig_enterprise` 表提供企业名称、类型、经纬度坐标、状态、所属部门等基础信息，`pig_enterprise_detail` 表提供经营状况等扩展信息
  - 养殖分析模块：提供核心指标卡片（企业总数、存栏、母猪存栏、出栏）、养殖结构分布、存栏出栏趋势、养殖规模排行、预警事件列表等数据
  - 市场贸易分析模块：提供今日市场行情速览、猪粮比等数据
  - 检验检疫无害化分析模块：提供检疫总量、合格率、免疫覆盖率等数据
  - 视频监管模块：`pig_video_device` 表提供视频设备状态数据，用于判断企业是否对接摄像头
  - 部门树：`sys_dept` 表提供行政区划数据，用于乡镇区域展示
  - 图表组件：ECharts（深色主题，与其他分析模块保持技术栈统一）
  - 乡镇地图：蓬溪县行政区划 GeoJSON 数据（与检验检疫分析的乡镇热力图共用同一份 GeoJSON）
  - 参考文档：`doc_spec/现有业务说明.spec.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（role_key） | 使用场景 | 主要操作 |
|---------|---------------------|---------|---------|
| 县级管理员 | `county_admin` | 领导汇报、大屏投放、日常指挥 | 查看大屏、全屏切换、点击企业图标查看详情、跳转视频监控 |
| 县级业务人员 | `county_staff` | 日常态势感知 | 查看大屏、点击企业图标查看详情 |

> 角色编码引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1 角色总览。
>
> 产业总览大屏展示全县级别数据，不做乡镇级数据过滤。乡镇角色不配置大屏菜单权限（乡镇用户通过各分析子模块查看本辖区数据）。

## 3.2 目标与范围

**目标**：

1. 以驾驶舱全屏可视化大屏形式，将养殖分析、市场贸易分析、检验检疫无害化分析三个模块的核心指标集中呈现在一张屏幕上，面向县级领导和监管决策者提供蓬溪县生猪产业全貌的一站式总览。
2. 中央区域以蓬溪县行政区划地图为底图，鼠标移入乡镇区域高亮对应行政区划，直观展示全县地理空间分布。
3. 在地图上展示养殖企业信息管理功能中维护了经纬度坐标的企业图标，根据企业状态（正常/停用）和经营状况（正常/停养/转产）使用不同颜色标识，快速识别企业当前运营状态。
4. 点击地图上的企业图标弹窗查看企业基础信息摘要，对接了摄像头的企业可一键跳转查看视频监控画面。
5. 适用于日常监管指挥、领导汇报展示、大屏投放（7×24 小时持续展示）场景。

**非目标（Non-Goals）**：

- ❌ 不做乡镇级数据过滤（大屏始终展示全县数据）。
- ❌ 地图不支持乡镇点击下钻到详细分析页（大屏定位为总览，深度分析到各子模块）。
- ❌ 不做移动端适配（大屏专为大屏幕显示器和投影仪设计）。
- ❌ 不做实时疫病预警推送弹窗（预警事件以滚动列表形式展示）。
- ❌ 不提供数据筛选、导出等交互功能（纯展示大屏）。
- ❌ 不在大屏页面内嵌视频流播放器（点击跳转到视频监管模块进行视频查看）。

## 3.3 现状与复用

**现状简述**：

- 养殖企业信息管理已建立 `pig_enterprise` 表，包含企业名称、类型、状态、经纬度坐标（`longitude`、`latitude`）等字段；`pig_enterprise_detail` 扩展表包含经营状况（`operation_status`）等字段。
- 养殖分析模块已定义核心指标、养殖结构分布、存栏出栏趋势、规模排行、预警事件列表等接口。
- 市场贸易分析模块已定义今日市场行情、猪粮比等接口。
- 检验检疫无害化分析模块已定义年度核心指标、免疫覆盖等接口。
- 视频监管模块已建立 `pig_video_device` 表，包含设备编码、企业关联、在线状态等字段。
- 蓬溪县行政区划 GeoJSON 数据需单独制作或获取（与检验检疫分析热力图共用）。
- 目前系统无产业总览大屏功能，需新建大屏页面和少量聚合接口。

```

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
```

### 3.4.1 功能流程逻辑

#### 页面整体布局

**屏幕规格与适配**：
- **设计基准分辨率**：1920×1080（16:9），同时兼容 2K（2560×1440）和 4K（3840×2160）
- **显示模式**：支持浏览器 F11 全屏模式，菜单栏和侧边栏自动隐藏

#### 区域二：左侧栏（养殖产业）

##### 板块 L1：核心指标卡片

**展示形式**：2×2 排列的指标卡片

| 指标 | 数值来源接口 | 展示方式 |
|------|-----------|---------|

| 本年出栏总量（头） | `/admin/analysis/breeding/overview` → `exitTotal` | 整数数字 + 单位"头" + 同比变化 |

**视觉效果**：
- 数字使用科技感数字字体（Digital-7 或 Orbitron 风格），带从 0 到目标值的数字滚动递增动画（countUp 效果），持续约 1.5 秒
- 同比变化：正增长显示绿色 `#52c41a` + ↑ 箭头，负增长显示红色 `#f5222d` + ↓ 箭头，无变化显示灰色 `#8c8c8c` + "—"
- 卡片边框带微光呼吸动效（亮度周期性变化，CSS animation，周期 3 秒）
- 卡片背景色 `#1b2838`，边框色 `#2a4a6b`，数字颜色 `#00d4ff`

- 各扇区 hover Tooltip："类型名称: XXX \n 数量: XXX 家 \n 占比: X.X%"
- 数据来源接口：`GET /admin/analysis/breeding/structure`

### 3.4.3 界面交互逻辑

**大屏进入与退出**：
- 用户在 WEB 端左侧菜单点击"产业驾驶舱 → 产业总览"进入大屏。
- 进入后自动切换为深色全屏布局，使用独立的深色主题 CSS，不显示系统顶栏和侧栏。大屏作为独立前端路由（如 `/screen`），不嵌套在管理系统 Layout 组件中。
- 退出方式：点击右上角「退出大屏」按钮 或 按键盘 ESC 键，退出后返回管理系统正常浅色界面。
- 按 F11 可切换浏览器全屏模式。

**乡镇区域高亮交互**：
- hover 进入乡镇区域时：该乡镇行政区划边界线颜色从 `#2a4a6b` 变为 `#00d4ff`，线宽从 1px 变为 2px，区域填充色在当前热力色基础上提亮 20%。高亮过渡动画 200ms。
- hover 进入后 200ms 延迟弹出气泡窗口，避免快速划过时频繁弹窗。
- hover 离开乡镇区域时：高亮恢复为默认状态，气泡消失，恢复过渡动画 200ms。
- 乡镇区域不支持点击下钻（大屏定位为总览，不做深度交互）。

**企业图标交互**：
- hover 企业图标：图标放大（`symbolSize` 12 → 18，过渡动画 200ms），弹出 Tooltip 显示企业名称、类型、状态。
- 点击企业图标：弹出企业基础信息弹窗（模态弹窗，深色半透明背景）。
- 弹窗中如该企业 `hasVideoDevice = true`：底部显示蓝色「查看视频监控」按钮（`#1890ff`）和在线设备数"X台在线/共X台"。
- 弹窗中如该企业 `hasVideoDevice = false`：底部显示灰色文字"未接入视频监控"，无可点击按钮。
- 点击「查看视频监控」按钮：页面跳转至 `/video/monitor?enterpriseId={enterpriseId}`，退出大屏模式。
- 弹窗关闭方式：点击弹窗底部「关闭」按钮 或 点击弹窗外遮罩区域 或 按 ESC 键（优先关闭弹窗而非退出大屏）。

**地图图例交互**：
- 图例面板位于地图右下角，半透明深色背景（`rgba(27,40,56,0.8)`）。
- 点击企业状态图例项可切换对应状态企业图标的显示/隐藏。例如点击"停用"图例项，地图上所有灰色停用企业图标隐藏。
- 图例项被隐藏时文字变为灰色 `#595959` 并加删除线。

**预警列表交互**：
- 列表自动向上滚动，每 3 秒滚动一条（CSS transition，过渡 500ms）。
- 当预警条数不足以填满显示区域（不足 5 条）时，不做滚动，静态展示。
- 滚动到底部后从头循环播放。
- 鼠标 hover 进入预警列表区域时暂停滚动，鼠标移出后恢复滚动。
- 预警列表不支持点击跳转（大屏纯展示）。

**加载状态与降级处理**：
- 页面首次加载时显示全屏深色背景 + 中央 loading 动画（科技感旋转光效），各区域数据加载完毕后依次渐入。
- 某个数据接口异常时，对应区域显示"数据加载中..."或上次成功获取的数据（缓存最近一次成功响应），不影响其他区域正常展示。
- 接口连续 3 次调用失败后，对应区域显示"数据暂时不可用"灰色提示，下一轮定时刷新时自动重试。
- GeoJSON 地图数据加载失败时，中央地图区域显示"地图加载失败"提示，其他区域不受影响。

**空状态处理**：
- 地图无企业点位数据时（所有企业均未维护经纬度），地图仅展示乡镇热力底图，不展示散点图层，不显示图例中的企业状态部分。
- 预警列表无数据时，显示绿色安全提示"当前无待处理预警"。
- 市场行情接口无数据时，对应品种行显示"暂无报价"灰色文字。

## 3.5 非功能需求

- **安全与权限**：
  - 需具备 `admin:analysis:screen` 权限标识方可访问产业总览大屏页面。
  - 权限分配：

  | 权限标识 | 说明 | 拥有角色 |
  |---------|------|---------|
  | `admin:analysis:screen` | 产业总览大屏查看 | `county_admin`、`county_staff` |

  - 大屏仅向县级角色开放，乡镇角色不配置大屏权限。乡镇角色通过各分析子模块的页面查看本辖区数据。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
  - 大屏展示全县级别数据，不做数据权限过滤。

- **性能**：
  - 大屏首次加载时间（含地图渲染）控制在 3 秒以内。
  - 蓬溪县 GeoJSON 地图数据前端缓存（localStorage 或 sessionStorage），避免重复网络请求。
  - 各数据接口并行请求，各区域独立渲染，不因某一个慢的接口阻塞整个页面。
  - 地图渲染使用 ECharts 的 SVG 模式（降低 GPU 负载，适合长时间运行场景）。
  - 动效使用 CSS animation 优先，减少 JS 动画对主线程的占用。
  - 定时刷新采用增量更新，仅更新变化的数据区域。
  - 长时间运行需防止内存泄漏：`setInterval` 定时器在页面离开时统一清理、ECharts 实例在页面销毁时调用 `dispose()`、DOM 引用及时回收。
  - 企业点位数据量上限：预计全县有经纬度的企业不超过 500 家，scatter 散点图层性能无瓶颈。如后续超过 1000 家，考虑聚合显示优化。
  - 无交互超时：大屏页面不设自动退出超时，支持 7×24 小时持续展示。

- **兼容性**：
  - 适配 1920×1080 至 3840×2160 分辨率范围，使用 `rem` + `vw/vh` 做响应式布局。
  - 图表组件使用 ECharts（深色主题），乡镇地图使用自定义蓬溪县行政区划 GeoJSON 数据，与检验检疫分析模块共用。
  - 支持 Chrome 80+、Edge 80+、Firefox 80+ 浏览器。
  - 大屏使用独立的深色主题 CSS，不影响管理系统的正常浅色主题。

- **离线/演示支持**：
  - 如需离线演示（无后端数据），大屏应支持加载本地 Mock 数据文件进行静态展示。

### C. 蓬溪县行政区划 GeoJSON 备注

- 蓬溪县 GeoJSON 地图数据需单独制作或获取，与检验检疫分析模块中的乡镇热力图共用同一份 GeoJSON 文件。

- GeoJSON 文件建议放置在前端静态资源目录（如 `public/geo/pengxi.json`），通过 HTTP 请求加载并缓存。

| 企业弹窗详情 | 养殖企业信息管理 + 视频监管 | 企业基础信息 + 摄像头对接状态 |

### E. 大屏路由与主题切换备注

- 大屏建议作为独立前端路由页面（如 `/screen` 或 `/screen/industry-overview`），不嵌套在管理系统的 Layout 组件中，避免系统布局对全屏展示的干扰。
- 进入大屏时切换至独立深色主题 CSS（`dark-screen.css`），退出时恢复管理系统浅色主题。
- 天气信息为可选增强功能，需对接第三方天气 API（如和风天气、心知天气等）。如不实现，该区域替换为蓬溪县地标或装饰图标。
