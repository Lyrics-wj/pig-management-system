## 3.1 基本信息

- **功能名称**：视频监控实时查看
- **关联现有模块/功能**：
  - 用户认证：复用现有 `POST /login`、`GET /getInfo`、`GET /getRouters` 接口与 JWT 机制
  - 权限管理：复用现有角色权限体系，新增实时监控查看权限标识
  - 视频设备信息管理：`pig_video_device` 表提供设备信息和接入通道号
  - 养殖企业信息：`pig_enterprise` 表提供企业信息，用于设备树的企业层级
  - 部门树：`sys_dept` 表提供行政区划层级，用于设备树的乡镇层级
  - 参考文档：`doc_spec/现有业务说明.spec.md`
- **目标用户/场景**：

| 用户角色 | 角色编码（role_key） | 可查看范围 |
|---------|---------------------|----------|
| 县级管理员 | `county_admin` | 全县所有摄像头 |
| 县级业务人员 | `county_staff` | 全县所有摄像头 |
| 乡镇政府业务人员 | `town_gov_staff` | 本乡镇下所有企业的摄像头 |
| 乡镇畜牧兽医站 | `town_vet_station` | 本乡镇下所有企业的摄像头 |
| 企业管理员 | `ent_admin` | 本企业的摄像头 |

> 角色编码引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1 角色总览。

## 3.2 目标与范围

**目标**：
1. 提供多画面分屏视频监控实时查看能力，支持同时观看多路摄像头实时画面。
2. 页面左侧设备树按"乡镇→企业→摄像头"层级组织，支持搜索和状态展示。
3. 支持 1×1、2×2、3×3、4×4 四种分屏模式，满足不同监控场景需求。
4. 提供截图、录制、全屏等画面操作功能。
5. 数据范围按角色权限自动过滤。

**非目标（Non-Goals）**：
- ❌ 不在本页面管理设备信息（设备管理在"视频设备信息管理"完成）。
- ❌ 不在本页面查看历史录像（历史回放在"视频监控历史回放"完成）。
- ❌ 不在本页面处理告警（告警处理在"视频监控告警管理"完成）。
- ❌ 不负责视频流的编解码和分发（由第三方视频平台提供）。

## 3.3 现状与复用

**现状简述**：
- 系统当前无视频监控查看功能，需全新开发。
- 视频设备信息将存储在 `pig_video_device` 表中（见视频设备信息管理PRD）。
- 视频流地址由后端从第三方视频平台获取后返回给前端。

**复用检查结论**：

**1. 接口复用检查（对照 `doc_spec/现有业务说明.spec.md`）**

| 检查项 | 现有资源 | 复用结论 | 说明 |
|--------|---------|---------|------|
| 用户认证 | `POST /login`、`GET /getInfo`、`GET /getRouters` | ✅ 直接复用 | 见现有业务说明.spec.md §二 |
| 设备树接口 | 无 | 🆕 新增 `/video/monitor/device-tree` | 按权限返回乡镇→企业→摄像头树形结构 |

| 截图接口 | 无 | 🆕 新增 `/video/monitor/snapshot/{deviceId}` | 截取当前帧并返回图片URL |

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 设备树展示 | P0 | 左侧设备树按乡镇→企业→摄像头层级展示 |
| 设备树搜索 | P0 | 关键字搜索过滤设备树节点 |
| 多画面分屏播放 | P0 | 支持 1×1、2×2、3×3、4×4 分屏 |
| 拖拽/双击选择摄像头 | P0 | 从设备树拖拽或双击到画面窗口播放 |
| 画面全屏 | P0 | 单个画面全屏查看 |
| 画面截图 | P1 | 截取当前帧保存为图片 |
| 画面录制 | P1 | 录制视频片段下载 |
| 画面关闭 | P0 | 关闭某个窗口画面 |
| 离线/异常提示 | P0 | 设备离线或加载失败的友好提示 |

**关键流程**：

```
用户进入"视频监控实时查看"页面
    ↓
系统加载设备树（按当前用户数据权限过滤）
页面右侧显示默认分屏模式（2×2 四画面）的空白窗口
    ↓
用户在设备树中找到目标摄像头（可搜索过滤）
    ↓
用户将摄像头拖拽到某个画面窗口 或 双击摄像头
    ↓
系统调用接口获取该设备的实时视频流地址
    ↓
前端播放器加载视频流，画面窗口开始播放实时画面
    ↓
用户可执行画面操作：
  - 点击画面窗口 → 全屏查看
  - 点击截图按钮 → 保存当前帧图片
  - 点击录制按钮 → 录制片段 → 点击停止 → 下载
  - 点击关闭按钮 → 关闭该窗口画面
  - 右键菜单 → 全屏/截图/录制/关闭
    ↓
用户可切换分屏模式（1×1 / 2×2 / 3×3 / 4×4）
```

### 3.4.1 功能流程逻辑

**设备树结构**：

- 监管端用户（县级/乡镇角色）看到的设备树层级：
  ```
  ├── XX镇
  │   ├── XX养殖场
  │   │   ├── 大门入口（在线 ●）
  │   │   ├── 猪舍A（在线 ●）
  │   │   └── 猪舍B（离线 ○）
  │   └── YY牧业
  │       └── ...
  ├── YY镇
  │   └── ...
  ```
- 企业端用户（`ent_admin`）看到的设备树层级（无乡镇/企业层级，直接展示摄像头列表）：
  ```
  ├── 大门入口（在线 ●）
  ├── 猪舍A（在线 ●）
  └── 猪舍B（离线 ○）
  ```
- 设备树节点前的状态图标：在线显示绿色实心圆点（`#52c41a`），离线显示灰色空心圆点（`#bfbfbf`），故障显示红色实心圆点（`#f5222d`）。
- 乡镇和企业节点后方显示该节点下的在线设备数/总设备数（如 `(3/5)`）。

**设备树搜索逻辑**：
- 设备树顶部有搜索输入框，支持关键字搜索。
- 搜索范围：设备名称、企业名称。
- 搜索为前端过滤（设备树数据一次性加载），输入关键字后即时过滤，高亮匹配文字。
- 搜索结果自动展开匹配节点的父级路径。

**分屏模式**：

| 模式 | 布局 | 最大画面数 | 说明 |
|------|------|----------|------|
| 单画面 | 1×1 | 1 | 全区域单画面 |
| 四画面 | 2×2 | 4 | 默认模式 |
| 九画面 | 3×3 | 9 | — |
| 十六画面 | 4×4 | 16 | — |

- 切换分屏模式时，已播放的画面保留在对应窗口（窗口编号不变），超出新模式窗口数的画面自动关闭。
- 例：从 3×3 切换到 2×2 时，窗口 1~4 保留，窗口 5~9 关闭。

**画面窗口操作**：

| 操作 | 触发方式 | 行为描述 |
|------|---------|---------|
| 播放 | 拖拽摄像头到窗口 / 双击摄像头 | 拖拽到指定窗口播放；双击自动填入第一个空闲窗口（无空闲窗口时替换当前选中窗口） |
| 全屏 | 双击画面 / 右键菜单"全屏" | 画面全屏展示，按 ESC 或再次双击退出全屏 |
| 截图 | 画面右上角截图按钮 / 右键菜单"截图" | 调用后端截图接口，返回图片URL后自动触发浏览器下载 |
| 录制 | 画面右上角录制按钮 / 右键菜单"录制" | 点击开始录制（按钮变红色），再次点击停止录制并自动下载视频文件 |
| 关闭 | 画面右上角关闭按钮 / 右键菜单"关闭" | 关闭该窗口画面，窗口恢复为空白占位状态 |

**视频流技术要求**：
- 实时画面延迟不超过 3 秒。
- 支持 H.264 和 H.265 视频编码。
- 前端播放推荐使用 WebRTC 或 HTTP-FLV 方式（具体在技术方案中确定）。
- 视频流地址由后端根据设备的 `channel_no`（接入通道号）从视频平台获取后返回给前端。

**异常处理**：

| 异常场景 | 展示方式 |
|---------|---------|
| 摄像头离线 | 画面区域显示灰色占位图 + 居中文案"设备离线" + 离线图标 |
| 视频流加载超时（10秒） | 画面区域显示"视频加载失败，请检查设备状态" + 重试按钮 |
| 网络断开 | 页面顶部显示红色通知条"网络连接异常，请检查网络" |
| 视频平台不可用 | 画面区域显示"视频服务不可用，请稍后重试" |

### 3.4.2 数据模型与字段定义

本功能无新建表，复用已有数据表。

**设备树接口响应结构**：

| 字段名（中文） | 字段名（英文） | 类型 | 说明 |
|--------------|--------------|------|------|
| 节点ID | id | varchar(50) | 唯一标识（乡镇用 dept_id、企业用 enterprise_id、设备用 device_id） |
| 节点名称 | label | varchar(200) | 显示名称 |
| 节点类型 | type | varchar(20) | `town` 乡镇、`enterprise` 企业、`device` 设备，仅此 3 种取值 |
| 设备状态 | deviceStatus | char(1) | 仅 `type=device` 时有值：`0` 在线、`1` 离线、`2` 故障 |
| 在线数 | onlineCount | int | 仅 `type=town` 或 `type=enterprise` 时有值 |
| 总数 | totalCount | int | 仅 `type=town` 或 `type=enterprise` 时有值 |
| 子节点 | children | array | 子节点数组 |

**实时视频流地址接口响应**：

| 字段名（中文） | 字段名（英文） | 类型 | 说明 |
|--------------|--------------|------|------|
| 设备ID | deviceId | bigint(20) | — |
| 设备名称 | deviceName | varchar(100) | — |
| 视频流地址 | streamUrl | varchar(500) | 实时视频流播放地址 |
| 协议类型 | protocol | varchar(20) | `webrtc`、`httpflv`、`hls`，仅此 3 种取值 |
| 设备状态 | deviceStatus | char(1) | `0` 在线、`1` 离线、`2` 故障 |

### 3.4.3 界面交互逻辑

**整体页面布局**：

```
┌──────────────────────────────────────────────────────────┐
│  页面标题：视频监控实时查看                                   │
├───────────┬──────────────────────────────────────────────┤
│  设备树     │  分屏模式切换按钮组: [1×1] [2×2] [3×3] [4×4]   │
│  ┌───────┐ │  ┌──────────┬──────────┐                    │
│  │🔍搜索  │ │  │  画面1    │  画面2    │                    │
│  ├───────┤ │  │          │          │                    │
│  │ XX镇   │ │  ├──────────┼──────────┤                    │
│  │ ├ A企业 │ │  │  画面3    │  画面4    │                    │
│  │ │ ├ 📹1 │ │  │          │          │                    │
│  │ │ └ 📹2 │ │  └──────────┴──────────┘                    │
│  │ └ B企业 │ │                                            │
│  │   └ 📹3 │ │                                            │
│  │ YY镇   │ │                                            │
│  │ └ ...  │ │                                            │
│  └───────┘ │                                            │
└───────────┴──────────────────────────────────────────────┘
```

- 左侧设备树区域固定宽度 280px，可通过拖拽分割线调整（最小 200px，最大 400px）。
- 右侧监控画面区域自适应填充剩余宽度。
- 设备树区域高度与页面内容区等高，内容溢出时独立滚动。

**设备树交互**：

- 搜索输入框在设备树顶部，placeholder 为"搜索设备/企业"。
- 输入关键字后 300ms 防抖触发前端过滤。
- 匹配的文字以黄色背景高亮。
- 搜索结果自动展开匹配节点的所有祖先节点。
- 清空搜索框时恢复设备树原始折叠状态。
- 设备树默认展开第一个乡镇节点。
- 乡镇和企业节点可折叠/展开。
- 设备节点支持拖拽（拖拽时显示半透明设备名称随鼠标移动）。
- 设备节点双击时：找到画面区域第一个空闲窗口播放；所有窗口均已占用时替换当前选中窗口（默认选中窗口1）。

**分屏模式切换**：

- 页面右上方（画面区域顶部）水平排列 4 个分屏模式按钮。
- 按钮样式：图标 + 文字，如 ⊞ 四画面。
- 当前选中模式按钮高亮（主色底色 + 白色文字），其余为默认样式。
- 切换模式有 300ms 过渡动画（画面网格平滑重排）。

**画面窗口交互**：

- 空闲窗口：浅灰色背景 + 居中"请选择摄像头"文字 + 虚线边框。
- 播放中窗口：
  - 画面内容充满窗口（保持 16:9 宽高比，多余区域黑色填充）。
  - 左上角叠加设备名称标签（白色文字 12px，半透明黑底圆角矩形）。
  - 右上角叠加操作按钮组（半透明黑底圆角矩形）：截图、录制、关闭按钮（白色图标 16px）。操作按钮默认隐藏，鼠标悬浮画面时以 200ms 淡入显示。
- 当前选中窗口（鼠标点击某窗口选中）：边框变为主色 2px 实线，与未选中窗口区分。
- 窗口间距 4px。

**右键菜单**：

- 在播放中的画面窗口上右键弹出自定义菜单：
  - 全屏（图标 + 文字）
  - 截图（图标 + 文字）
  - 录制/停止录制（图标 + 文字，录制中显示红色文字"停止录制"）
  - 关闭（图标 + 文字）
- 菜单样式：白色背景、圆角 4px、阴影。

**截图操作**：
- 点击截图按钮 → 画面闪烁白色遮罩 200ms（模拟快门效果）→ 浏览器自动下载截图文件。
- 截图文件名：`{设备名称}_{YYYYMMDD_HHmmss}.jpg`。

**录制操作**：
- 点击录制按钮 → 按钮图标变为红色实心圆 + 闪烁动效 → 画面左上角出现红色"REC"标识 + 录制时长计时器。
- 再次点击停止录制 → 浏览器自动下载录制的视频文件。
- 录制文件名：`{设备名称}_{YYYYMMDD_HHmmss}.mp4`。
- 单次录制最长 30 分钟，超过后自动停止并下载。

**校验规则**：

本页面无用户输入表单，无需前端校验。

### 3.4.4 接口路径定义

| 接口名称 | HTTP 方法 | 路径 | 请求参数摘要 | 响应数据摘要 | 备注 |

## 3.5 非功能需求

- **安全与权限**：

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `video:monitor:realtime` | 实时监控查看 | `county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`、`ent_admin` |
| `video:monitor:snapshot` | 截图 | `county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`、`ent_admin` |

  - 数据权限按 `data_scope` + 部门树自动过滤设备树内容：县级看全县摄像头，乡镇看本乡镇，企业看本企业。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：
  - 实时画面延迟不超过 3 秒。
  - 设备树接口响应时间不超过 2 秒。
  - 获取视频流地址接口响应时间不超过 3 秒。
  - 支持同时播放 16 路视频流（4×4 分屏）。
  - 设备规模上限 140 台。
