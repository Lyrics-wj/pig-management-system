## 5.2 目标与范围

**目标**：
1. 提供历史监控视频的按时间段回放查看能力，支持最近 30 天内的录像回放。
2. 提供可视化 24 小时时间轴控件，直观展示有录像和无录像的时段，以及告警时刻标记。
3. 支持播放/暂停、快进（2x/4x/8x/16x）、慢放（0.5x）、逐帧等播放控制。
4. 提供截图和视频片段下载功能（下载仅限县级角色）。
5. 从告警管理页面跳转时自动定位到告警时间点开始回放。

**非目标（Non-Goals）**：
- ❌ 不支持超过 30 天的录像回放（受云存储保留策略限制）。
- ❌ 不在本页面多画面同时回放（历史回放为单画面模式）。
- ❌ 不在本页面管理告警和设备。

## 5.4 功能需求

**功能列表**：

| 功能点 | 优先级 | 说明 |
|-------|-------|------|
| 设备树（共用） | P0 | 与实时监控共用设备树组件 |
| 日期选择 | P0 | 选择回放日期 |
| 可视化时间轴 | P0 | 24小时时间轴，展示有录像/无录像时段和告警时刻 |
| 回放播放器 | P0 | 播放历史录像 |
| 播放控制 | P0 | 播放/暂停、快进、慢放、逐帧 |
| 截图 | P1 | 保存回放当前帧 |
| 片段下载 | P1 | 下载指定时段视频文件（仅县级角色） |
| 告警时间点定位 | P1 | 从告警管理跳转时自动定位 |

**关键流程**：

```
用户进入"视频监控历史回放"页面
    ↓
系统加载设备树（共用实时监控的设备树接口）
    ↓
用户在设备树中选择一个摄像头
    ↓
页面右侧回放区域激活，默认选中今天日期
    ↓
系统查询该设备当天的录像时段信息
    ↓
时间轴显示有录像的时段（蓝色条）、无录像时段（灰色）、告警时刻（红色三角标记）
    ↓
用户可更换日期（日期选择器）
    ↓
用户点击时间轴上某个有录像的位置 或 拖拽时间轴定位
    ↓
系统获取回放视频流地址 → 播放器从该时间点开始播放
    ↓
用户可执行播放控制操作：
  - 播放/暂停
  - 快进（2x/4x/8x/16x）
  - 慢放（0.5x）
  - 逐帧前进/后退
  - 截图
  - 片段下载（仅县级角色可见）
```

### 5.4.1 功能流程逻辑

**回放日期限制**：
- 可选日期范围：今天起往前 30 天（含今天）。
- 超过 30 天的日期在日期选择器中禁用（灰色不可选），hover 提示"超出存储保留期，录像不可用"。
- 未来日期禁用。

**时间轴控件逻辑**：

- 时间轴为水平条形，默认展示 24 小时全览（0:00 ~ 23:59）。
- 有录像的时段以蓝色条（`#1890ff`）标识。
- 无录像的时段为灰色底色（`#f0f0f0`）。
- 告警时刻以红色倒三角标记（`#f5222d`）定位在时间轴上方，鼠标悬浮显示告警时间和类型。
- 时间轴支持缩放：
  - 鼠标滚轮缩放（放大到分钟级精度，缩小到小时级精度）。
  - 缩放级别：24小时全览 → 6小时 → 1小时 → 15分钟 → 5分钟，共 5 个级别。
- 时间轴支持拖拽平移（缩放后左右拖拽查看不同时段）。
- 当前播放位置以红色竖线（播放指针）标示在时间轴上，随播放实时移动。
- 点击时间轴上有录像的位置，播放器跳转到该时间点继续播放。
- 点击无录像的灰色区域，提示"该时段无录像"。

**播放控制逻辑**：

| 控制 | 图标 | 行为 |
|------|------|------|
| 播放/暂停 | ▶ / ‖ | 切换播放和暂停状态 |
| 快进 2x | 2× | 2 倍速播放 |
| 快进 4x | 4× | 4 倍速播放 |
| 快进 8x | 8× | 8 倍速播放 |
| 快进 16x | 16× | 16 倍速播放 |
| 慢放 0.5x | 0.5× | 0.5 倍速播放 |
| 逐帧前进 | ▶\| | 前进一帧 |
| 逐帧后退 | \|◀ | 后退一帧 |
| 截图 | 📷 | 截取当前帧并下载 |
| 片段下载 | ⬇ | 弹出时间段选择弹窗 |

- 当前倍速以高亮标识，默认为 1x（正常速度）。
- 点击不同倍速按钮即时切换。

**片段下载逻辑**（仅县级角色可见）：
- 点击片段下载按钮 → 弹出选择时段弹窗。
- 弹窗字段：
  - 开始时间（时间选择器，HH:mm:ss 格式，必填）
  - 结束时间（时间选择器，HH:mm:ss 格式，必填）
- 校验：结束时间须晚于开始时间；时间段不超过 2 小时（7200 秒）；时间段须在有录像的范围内。
- 提交后后端生成视频文件并返回下载链接，浏览器自动开始下载。
- 下载文件名：`{设备名称}_{日期}_{开始时间}_{结束时间}.mp4`

**从告警管理跳转逻辑**：
- URL 参数：`?deviceId={deviceId}&date={YYYY-MM-DD}&time={HH:mm:ss}`
- 页面加载时检测 URL 参数，若有则自动选中设备树中对应设备、设置日期、加载时间轴、定位到告警时间点并自动开始播放。


- 左侧设备树区域：与实时监控共用设备树组件（同样的搜索、状态展示、层级结构），但操作方式为单击选中（非拖拽）。
- 右侧回放区域：上部为播放画面（16:9），中部为播放控制条，下部为时间轴。
- 未选择摄像头时，回放区域显示灰色占位图 + "请在左侧设备树中选择摄像头"文案。

**日期选择器交互**：

- 位于回放区域顶部右侧。
- 日期选择器旁有「前一天」「后一天」快捷箭头按钮（← →）。
- 当前日期为今天时「后一天」按钮禁用。
- 当前日期为30天前时「前一天」按钮禁用。
- 切换日期后自动重新加载该日的录像时段信息和告警标记。

**时间轴交互**：

- 时间轴高度 40px，背景灰色，有录像区域覆盖蓝色条。
- 时间轴上方每小时刻度处显示时间数字（0、2、4、...、22）。
- 告警标记：红色倒三角（`▼`）固定在时间轴上方对应时间位置。鼠标悬浮显示 tooltip："告警时间: HH:mm:ss | 类型: 人员入侵"。点击告警标记弹出告警详情弹窗。
- 播放指针：红色竖线从顶到底贯穿时间轴，上方显示当前播放时间（HH:mm:ss）。
- 鼠标悬浮时间轴时，鼠标位置处显示细竖线和时间提示。
- 点击蓝色区域（有录像）跳转播放到该时间点。
- 点击灰色区域（无录像）弹出轻提示"该时段无录像"。
- 鼠标滚轮缩放时间轴（以鼠标位置为中心缩放）。

**播放控制条交互**：

- 控制条位于画面和时间轴之间，水平排列。
- 左侧：播放/暂停按钮（大图标 24px）。
- 中间：倍速按钮组（0.5x、1x、2x、4x、8x、16x），当前倍速高亮（主色底色+白色文字），其余为默认样式。
- 右侧：逐帧后退、逐帧前进、截图、片段下载（仅县级角色可见）按钮。
- 控制条背景半透明黑色（`rgba(0,0,0,0.7)`），文字白色。

**片段下载弹窗**（仅 `county_admin`、`county_staff` 可见下载按钮）：

- 弹窗标题："下载视频片段"。
- 弹窗宽度 450px。
- 表单字段：

| 序号 | 字段名 | 控件类型 | 必填 | 校验规则 |
|------|-------|---------|------|---------|
| 1 | 开始时间 | 时间选择器（HH:mm:ss） | 是 | 不可为空；须在有录像时段内 |
| 2 | 结束时间 | 时间选择器（HH:mm:ss） | 是 | 不可为空；须晚于开始时间；须在有录像时段内 |

- 时间段限制：单次下载时间段不超过 2 小时（7200 秒）。
- 弹窗底部按钮：「下载」（主色）+ 「取消」（默认色）。
- 点击下载后显示进度提示，完成后自动开始浏览器下载。

**截图操作**：
- 点击截图按钮 → 画面闪烁白色遮罩 200ms → 浏览器自动下载截图文件。
- 截图文件名：`{设备名称}_回放_{YYYYMMDD_HHmmss}.jpg`

**异常状态**：

| 异常场景 | 展示方式 |

| 超过30天的录像 | 日期选择器中禁用，hover 提示"超出存储保留期" |

  - 视频片段下载仅限县级角色，乡镇和企业角色不可见下载按钮。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：
  - 录像时段查询接口响应时间不超过 2 秒。
  - 回放视频流加载时间不超过 5 秒。
  - 片段下载文件生成时间：60 分钟以内的片段不超过 30 秒。
  - 最长可回放最近 30 天内的录像。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示。推荐使用 Chrome 80+、Edge 80+。
