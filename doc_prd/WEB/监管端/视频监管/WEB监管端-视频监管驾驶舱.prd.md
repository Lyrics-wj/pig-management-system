## 1.2 目标与范围

**目标**：
1. 以驾驶舱大屏风格集中展示视频监管的全局态势：设备在线状况、告警动态、存储使用情况、实时监控快捷入口。
2. 作为视频监管模块的首页入口，提供一站式总览与快速跳转能力，方便监管人员快速感知全局并深入具体功能。
3. 驾驶舱内容根据当前用户角色的数据权限自动过滤（县级看全县，乡镇看本乡镇）。
4. 关键指标实时刷新（设备在线状态、未处理告警数、存储使用率），保障监管值班场景下信息时效性。

**非目标（Non-Goals）**：
- ❌ 不在驾驶舱页面执行设备管理操作（新增/编辑/删除设备），设备管理在独立功能页面完成。
- ❌ 不在驾驶舱页面处理告警（告警处理在告警管理功能页面完成），驾驶舱仅展示和跳转。
- ❌ 不在驾驶舱页面配置存储策略，存储策略配置在云存储管理功能页面完成。
- ❌ 不提供大屏投屏/全屏展示模式（当前为标准后台页面布局，非独立大屏系统）。

## 1.3 现状与复用

**现状简述**：
- 系统当前无视频监管相关功能，视频监管为全新模块。
- 系统已有的"系统监控"模块（`/monitor/*`）为服务器运行状态监控，与视频监控无关。
- `pig_enterprise` 表（企业端PRD定义）提供企业基本信息，用于设备关联企业。
- `sys_dept` 表提供部门树结构，用于行政区划数据权限过滤。

```

    ↓

    ↓
用户浏览驾驶舱各区域信息：
  - 核心指标卡片（设备总数/在线数/今日告警/未处理告警）
  - 设备状态分布图
  - 乡镇设备分布图
  - 实时告警动态滚动列表
  - 告警趋势折线图
  - 实时监控4宫格轮播
  - 存储状态仪表盘
    ↓
用户可点击各区域跳转到对应详细功能页面：
  - 点击设备相关区域 → 跳转"视频设备信息管理"
  - 点击告警相关区域 → 跳转"视频监控告警管理"
  - 点击监控画面区域 → 跳转"视频监控实时查看"
  - 点击存储区域 → 跳转"云存储管理"
    ↓
页面每 60 秒自动刷新核心指标、设备状态、告警动态数据
```

### 1.4.1 功能流程逻辑

**驾驶舱页面区域划分（从上到下、从左到右）**：

│  设备总数  │  在线设备   │  今日告警   │  未处理告警  │    ← 核心指标卡片区
│   140    │   128     │    5     │    3     │
│          │  在线率91% │          │          │
├──────────────┬──────────────────────────────┤
│  设备状态分布   │       乡镇设备分布              │    ← 第二行

│              │                              │
├──────────────┬──────────────────────────────┤
│  实时告警动态   │       告警趋势                 │    ← 第三行

├──────────────┬──────────────────────────────┤

**核心指标卡片区（4个卡片）**：

| 卡片 | 指标名称 | 数值来源 | 图标 | 辅助信息 |
|------|---------|---------|------|---------|
| 卡片1 | 设备总数 | `pig_video_device` 表中 `del_flag='0'` 的记录总数 | 摄像头图标 | 点击跳转"视频设备信息管理" |
| 卡片2 | 在线设备 | `pig_video_device` 表中 `device_status='0'`（在线）的记录数 | 信号图标（绿色） | 辅助文字显示在线率百分比（在线数/总数×100%，保留1位小数） |
| 卡片3 | 今日告警 | `pig_video_alarm` 表中 `alarm_time` 在今日范围内的记录数 | 警铃图标（橙色） | 点击跳转"视频监控告警管理" |
| 卡片4 | 未处理告警 | `pig_video_alarm` 表中 `handle_status='0'`（未处理）的记录数 | 警告图标（红色） | 数值 > 0 时卡片边框以红色脉冲动效提醒；点击跳转"视频监控告警管理"并筛选未处理 |

**设备状态分布图（左侧）**：

- 图表类型：环形图（Donut Chart）
- 数据维度：在线（绿色 `#52c41a`）、离线（灰色 `#bfbfbf`）、故障（红色 `#f5222d`）
- 中心显示设备总数
- 鼠标悬浮各扇区显示具体数量和占比百分比
- 图例在图表下方水平排列
- 点击环形图任一扇区跳转到"视频设备信息管理"并自动填入该状态筛选条件

**乡镇设备分布图（右侧）**：

- 图表类型：横向堆叠柱状图
- 纵轴：各乡镇名称
- 横轴：设备数量
- 每个乡镇的柱状条分三色堆叠：在线（绿色）、离线（灰色）、故障（红色）
- 乡镇按设备总数从高到低排列
- 鼠标悬浮显示该乡镇的设备总数、在线数、离线数、故障数、在线率
- 乡镇角色进入时仅显示本乡镇数据（单条柱状图退化为简单柱状图）

**实时告警动态（左侧）**：

- 展示形式：垂直滚动列表，自动滚动，鼠标悬浮时暂停滚动
- 展示最近 20 条未处理告警记录
- 每条告警项展示：告警时间（HH:mm:ss）、设备名称、使用单位、告警类型标签（红色底）
- 告警项前方有红色圆点脉冲动效（表示未处理）
- 点击单条告警跳转到"视频监控告警管理"的告警详情
- 无告警时展示绿色安全图标 + "暂无未处理告警"文案
- 每 30 秒自动请求刷新最新告警数据

**告警趋势图（右侧）**：

- 图表类型：面积折线图
- 横轴：日期
- 纵轴：告警数量
- 默认展示近 7 天数据，右上角提供切换按钮组：「近7天」「近30天」
- 切换即时生效，无需额外点击
- 折线下方填充半透明橙色区域
- 鼠标悬浮显示当日告警数量、较前一日环比变化
- 数据来源：按天统计 `pig_video_alarm` 表中各天的告警记录数

**实时监控轮播窗口（左侧）**：

- 展示形式：2×2 四宫格画面
- 默认随机选取 4 个在线摄像头播放实时画面
- 每 30 秒自动轮换一组摄像头（4个同时切换到下一组）
- 每个画面窗口左下角显示设备名称（白色文字+半透明黑底）
- 画面右上角显示在线状态绿色圆点
- 设备离线时画面显示灰色占位图 + "设备离线"文案
- 视频流加载失败时显示"视频加载失败"提示
- 点击任意画面窗口跳转到"视频监控实时查看"页面并自动选中该摄像头
- 轮播窗口右上角提供「暂停轮播」/「继续轮播」切换按钮

**存储状态面板（右侧）**：

- 顶部：存储使用率仪表盘（半环形 Gauge Chart）
  - 使用率 0%~70% 显示绿色，70%~85% 显示橙色，85%~100% 显示红色
  - 中心显示当前使用率百分比数值（保留1位小数）
- 中部：文字展示总容量、已用容量、剩余容量（单位 TB，保留2位小数）
- 底部：存储使用率超过告警阈值（默认85%）时显示红色警告文案："存储空间不足，请及时清理或扩容"
- 整个面板点击跳转到"云存储管理"页面

**快捷入口区（底部）**：

| 入口 | 图标 | 文字 | 跳转目标 |
|------|------|------|---------|
| 设备管理 | 摄像头图标 | 设备管理 | 视频设备信息管理页面 |
| 实时监控 | 监控屏幕图标 | 实时监控 | 视频监控实时查看页面 |
| 告警管理 | 警铃图标 | 告警管理 | 视频监控告警管理页面 |
| 历史回放 | 时钟回退图标 | 历史回放 | 视频监控历史回放页面 |
| 云存储 | 云存储图标 | 云存储 | 云存储管理页面 |

**自动刷新机制**：

| 设备状态分布图 | 60 秒 | 与核心指标同步刷新 |

### 1.4.3 界面交互逻辑

**整体页面布局**：

- 页面标题：视频监管驾驶舱。
- 页面背景色采用深色调（`#1b2a4a`），各数据面板以卡片形式浮于深色背景之上（卡片背景 `#ffffff`，圆角 8px，阴影 `0 2px 8px rgba(0,0,0,0.1)`），营造驾驶舱沉浸感。
- 各区域布局采用 CSS Grid 或 Flex 响应式排列，最小支持宽度 1280px。
- 页面无滚动条（所有区域在一屏内展示，各区域高度自适应但有最大高度限制）。

**核心指标卡片交互**：

- 4 个卡片水平等分排列。
- 数值使用大字号（32px）加粗展示。
- 数值加载时以数字滚动动效从 0 增至目标值（动画时长 800ms）。
- 鼠标悬浮卡片时背景色加深为 `#f0f5ff`，光标变为手型。
- "未处理告警"卡片当数值 > 0 时，卡片左边框显示 3px 红色边条，且数字以红色字体展示（`#f5222d`）；数值为 0 时显示绿色字体（`#52c41a`）。

**设备状态分布环形图交互**：

- 环形图中心显示设备总数（大字号 + "台"字后缀）。
- 鼠标悬浮扇区：扇区略微外扩 6px，tooltip 显示"在线：128台（91.4%）"。
- 图例样式：圆形色块 + 名称 + 数量，点击图例可切换该状态的显示/隐藏。
- 点击扇区跳转到设备管理页面，URL 参数携带 `deviceStatus=0/1/2`。

**乡镇设备分布图交互**：

- 柱状图最多展示 20 个乡镇，超过时仅展示设备数量最多的 20 个。
- 鼠标悬浮柱状条显示 tooltip：乡镇名称、设备总数、在线/离线/故障各数量、在线率。
- 柱状条高度按比例自适应，最长的柱状条占满可用宽度。

**实时告警动态交互**：

- 列表区域固定高度（不超过 280px），内容超出高度时自动向上滚动。
- 滚动速度：每 3 秒向上滚动一行。
- 鼠标悬浮列表区域时滚动暂停，鼠标离开后继续滚动。
- 点击某条告警记录，跳转到告警管理页面并打开该条告警的详情。
- 每条告警左侧有红色圆点呼吸灯效果（CSS animation，1.5 秒循环）。
- 告警为 0 条时，区域内居中展示绿色盾牌图标 + "暂无未处理告警，系统运行正常"文案。

**告警趋势图交互**：

- 右上角切换按钮组（「近7天」「近30天」），当前选中项高亮。
- 切换即时响应，折线图以 300ms 过渡动画切换数据。
- 鼠标悬浮折线节点，tooltip 显示：日期、告警数量、环比变化（如"+3"或"-2"或"持平"）。
- 折线颜色：橙色（`#fa8c16`），填充区域半透明橙色（`rgba(250,140,22,0.15)`）。

**实时监控轮播交互**：

- 4 个画面窗口以 2×2 网格排列，每个窗口 16:9 宽高比。
- 画面左下角叠加设备名称标签（白色文字，底部渐变半透明黑色遮罩）。
- 画面右上角叠加在线状态圆点（绿色圆点 8px，带白色描边）。
- 轮播切换时以 500ms 淡入淡出动效过渡。
- 右上角「暂停轮播」按钮，图标为暂停图标（‖），点击后变为播放图标（▶）和"继续轮播"文字。
- 鼠标悬浮某画面窗口时叠加半透明蒙层 + "点击查看大画面"文案 + 放大图标。
- 点击画面跳转到实时监控页面并自动选中该摄像头。
- 在线设备不足 4 台时，空闲窗口显示灰色占位图 + "暂无更多在线设备"。

**存储状态面板交互**：

- 仪表盘为半环形（180度弧），指针指向当前使用率位置。
- 弧形颜色渐变：绿色（0%-70%）→ 橙色（70%-85%）→ 红色（85%-100%）。
- 中心数字显示当前使用率（大字号，保留1位小数）。
- 下方以三行文字展示：总容量 XX.XX TB / 已用 XX.XX TB / 剩余 XX.XX TB。
- 使用率超过 85% 时，面板底部出现红色警告横幅（脉冲闪烁效果）："存储空间不足，请及时清理或扩容"。
- 整个面板鼠标悬浮出现浅色覆盖层，点击跳转到云存储管理页面。

**快捷入口区交互**：

- 5 个入口按钮水平等分排列。
- 每个按钮为圆角矩形卡片（白色底，圆角 8px），内含图标（32×32）和文字标签。
- 鼠标悬浮时卡片上移 4px 并增强阴影效果（微浮动感）。
- 点击跳转到对应功能页面。

**异常状态展示**：

| 异常场景 | 展示方式 |
|---------|---------|
| 接口请求失败 | 对应区域显示灰色占位 + "数据加载失败，请刷新重试"文案 + 重试按钮 |
| 无设备数据 | 设备相关区域显示"暂无设备数据"；核心指标卡片数值均显示 0 |
| 无告警数据 | 告警动态区域显示绿色安全图标 + "系统运行正常"；趋势图折线为 0 水平线 |
| 实时视频加载失败 | 对应画面窗口显示"视频加载失败"灰色占位图 |
| 存储接口不可用 | 存储面板显示"存储服务不可用，请联系管理员" |

**校验规则**：

本页面无用户输入表单，无需前端校验。

## 1.5 非功能需求

- **安全与权限**：
  - 需具备 `video:cockpit:view` 权限标识方可访问视频监管驾驶舱页面。
  - 权限标识分配给：`county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`。
  - 数据权限按 `data_scope` + 部门树自动过滤：县级角色（`county_admin`、`county_staff`）看全县数据（`data_scope=1`），乡镇角色（`town_gov_staff`、`town_vet_station`）看本乡镇数据（`data_scope=4`）。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：
  - 驾驶舱页面首屏加载时间不超过 3 秒（各区域数据接口并行请求）。
  - 单个接口响应时间不超过 2 秒。
  - 视频轮播画面延迟不超过 3 秒。
  - 设备规模上限 140 台，告警数据量级：日均不超过 100 条。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示，1920px 最佳体验。
