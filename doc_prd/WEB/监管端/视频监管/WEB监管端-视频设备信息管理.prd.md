## 2.2 目标与范围

**目标**：
1. 对全县生猪养殖场视频监控摄像头设备信息进行统一登记和维护管理。
2. 支持按设备名称、使用单位、所属乡镇、设备状态、是否告警区域等条件筛选查询。
3. 仅县级管理员可执行新增、编辑、删除、批量导入操作，其他角色仅查看。
4. 设备状态（在线/离线/故障）与视频平台实时同步，便于监管人员随时掌握设备运行状况。
5. 支持 Excel 批量导入和导出设备信息，便于初始化和日常管理。

**非目标（Non-Goals）**：
- ❌ 不在本页面播放视频画面（视频播放在"视频监控实时查看"功能完成）。
- ❌ 不在本页面配置告警规则（告警规则在"视频监控告警管理"功能完成）。
- ❌ 不负责视频平台的摄像头接入和通道配置（由第三方视频平台完成，本功能仅记录接入后的设备信息）。

### 2.4.1 功能流程逻辑

**设备编号生成规则**：
- 手动填写，格式为 `CAM-XXXX`（`CAM-` 前缀 + 4位数字编号，如 `CAM-0001`）。
- 新增时前端自动生成建议编号（基于当前最大编号+1），允许手动修改。
- 编号唯一性校验：提交前后端校验 `device_code` 是否重复，重复时返回"设备编号已存在"。

**设备状态同步机制**：
- 设备状态（在线/离线/故障）由后端通过以下方式之一与视频平台同步（具体方式在技术方案中确定）：
  - 方式一：定时轮询视频平台设备状态接口（建议间隔 60 秒）
  - 方式二：视频平台通过回调接口主动推送状态变更
- 前端列表中设备状态字段实时反映后端同步结果，前端不主动轮询设备状态。

**批量导入逻辑**：
- 导入文件格式：`.xlsx`，文件大小不超过 10MB。
- 导入模板列：设备编号、设备名称、使用单位名称、安装位置、IP地址、设备品牌、设备型号、接入通道号、是否告警区域（是/否）、备注。
- 导入校验规则：
  - 设备编号不可为空，格式须为 `CAM-` + 4位数字，编号不可重复（文件内不重复 + 与数据库不重复）。
  - 设备名称不可为空。
  - 使用单位名称不可为空，须能匹配到 `pig_enterprise` 表中的企业（模糊匹配取唯一结果，多结果时报错提示"使用单位匹配到多条记录，请使用精确名称"）。
  - IP地址不可为空，须为合法 IPv4 格式。
  - 接入通道号不可为空。
  - 是否告警区域仅允许填"是"或"否"。
- 导入结果反馈：弹窗展示导入总条数、成功条数、失败条数；失败记录列出失败原因（逐行展示，最多显示前 50 条失败记录）。

**导出文件名规则**：
- `视频设备信息_YYYYMMDD_HHmmss.xlsx`

## 2.5 非功能需求

- **安全与权限**：

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `video:device:list` | 设备列表查看 | `county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`、`ent_admin` |
| `video:device:query` | 设备详情查看 | `county_admin`、`county_staff`、`town_gov_staff`、`town_vet_station`、`ent_admin` |
| `video:device:add` | 新增设备 | `county_admin` |
| `video:device:edit` | 编辑设备 | `county_admin` |
| `video:device:remove` | 删除设备 | `county_admin` |
| `video:device:import` | 批量导入 | `county_admin` |
| `video:device:export` | 导出 | `county_admin`、`county_staff` |

  - 数据权限按 `data_scope` + 部门树自动过滤：县级角色看全县数据（`data_scope=1`），乡镇角色看本乡镇数据（`data_scope=4`），企业角色看本企业数据（`data_scope=4`）。
  - 角色定义引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1。
- **性能**：设备列表查询响应时间不超过 2 秒。设备规模上限 140 台。批量导入单次最大支持 200 条记录。
- **兼容性**：桌面端主流分辨率（1280px 及以上）正常显示。
