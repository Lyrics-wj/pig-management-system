# WEB监管端-市场贸易分析

## 需求描述

市场贸易分析模块为监管端决策分析板块的组成部分，通过接入外部市场行情数据，展示生猪及相关产品（饲料原料、猪肉）的市场价格走势和交易趋势，帮助监管部门了解市场动态、研判价格波动风险，为产业政策制定和养殖指导提供数据支撑。

与养殖分析模块的区别：养殖分析侧重本县内部的养殖生产数据分析，市场贸易分析侧重外部市场行情数据的展示与对比分析。

技术参数 #3 定义：
数据汇总展示：平台获取展示生猪（外三元）交易趋势、玉米（14%水分）交易趋势、豆粕（43%蛋白）交易趋势、白条猪肉交易趋势信息。全国猪肉批发价格、全国生猪市场价格走势等相关信息。

### 三、分析卡片详细定义

#### 卡片一：今日市场行情速览

**展示形式**：4个横向排列的行情卡片

| 品种 | 展示内容 | 说明 |
|------|---------|------|
| 生猪（外三元） | 今日价格（元/公斤）、日涨跌（元 + 涨跌箭头）、周涨跌幅（%） | 外三元为我国生猪市场主流品种报价基准 |
| 玉米（14%水分） | 今日价格（元/吨）、日涨跌、周涨跌幅 | 主要饲料原料 |
| 豆粕（43%蛋白） | 今日价格（元/吨）、日涨跌、周涨跌幅 | 主要蛋白饲料原料 |
| 白条猪肉 | 今日价格（元/公斤）、日涨跌、周涨跌幅 | 终端消费市场价格 |

**视觉规范**：
- 上涨时数字和箭头为红色（↑），下跌时为绿色（↓），持平为灰色（-）
- 每个卡片内附一条迷你折线图（sparkline），展示近7天价格走势
- 数据更新时间标注在行情区域右上角（如"数据更新：2026-03-10 09:00"）

#### 卡片二：生猪（外三元）交易趋势

**展示形式**：折线图 + 数据表格

**折线图**：
- X轴：时间（按日/周/月，与全局筛选联动）
- Y轴：价格（元/公斤）
- 展示曲线：
  - 全国均价（主线，蓝色实线）
  - 四川省均价（辅线，橙色虚线）
  - 本县收购价（辅线，绿色虚线，来源为本县企业出栏记录中的销售均价，如无数据则不展示）
- 关键价格节点标注（如年度最高点/最低点）
- 数据点 hover 展示：日期、全国均价、四川省均价、本县价格

**数据表格**（可折叠）：

| 日期 | 全国均价（元/kg） | 四川省均价（元/kg） | 本县价格（元/kg） | 日涨跌 | 周涨跌幅 |
|------|-----------------|-----------------|----------------|--------|---------|
| 2026-03-10 | XX.XX | XX.XX | XX.XX | +0.XX | +X.XX% |

**辅助分析线**：
- 养殖成本线：基于本县投入品成本数据估算的头均成本折算单价（红色水平参考线），当生猪价格低于成本线时触发视觉警示（区域填充红色半透明）
- 猪粮比参考线：标注猪粮比（生猪价格/玉米价格）6:1 的预警线

#### 卡片六：猪粮比价分析

**展示形式**：面积折线图

**猪粮比计算**：生猪价格（元/公斤）÷ 玉米价格（元/公斤）

> 注意：玉米价格原始数据为元/吨，需转换为元/公斤（÷1000）后计算

**折线图**：
- X轴：时间
- Y轴：猪粮比（无单位）
- 展示曲线：全国猪粮比
- 预警区间标注：
  - 绿色区域（6:1 ~ 9:1）：正常盈利区间
  - 黄色区域（5:1 ~ 6:1）：盈亏平衡区间
  - 红色区域（< 5:1）：亏损预警区间
  - 浅红区域（> 12:1）：过度盈利区间（可能引发产能过度扩张）
- 当前猪粮比数值在图表右侧以大字体标注

**下方说明文字**：
- 当猪粮比 < 6:1 时，显示红色提示："当前猪粮比低于盈亏平衡线，养殖企业面临亏损风险"
- 当猪粮比 > 12:1 时，显示橙色提示："当前猪粮比偏高，需关注产能扩张过快风险"

---

#### 卡片七：全国猪肉批发价格地图

**展示形式**：中国地图热力图

- 地图按省份着色，颜色深浅表示猪肉批发价格高低
- hover 某省显示：省份名称、当日猪肉批发均价、较上周涨跌
- 四川省以边框高亮突出显示
- 右侧图例展示价格色阶

---

#### 卡片八：价格对比分析

**展示形式**：多品种叠加折线图

**折线图**：
- 将生猪、玉米、豆粕、白条猪肉四个品种的价格变化率（以期初价格为基准的涨跌幅百分比）叠加在同一张图中
- X轴：时间
- Y轴：涨跌幅（%），基准线为0%
- 四条不同颜色的折线分别代表四个品种
- 用于观察各品种价格联动关系（如饲料价格上涨是否传导至生猪价格）

### 五、数据模型

#### 5.1 市场行情数据表（新建）

**市场行情日报表 `pig_market_price_daily`**：

| 字段名（中文） | 字段名（英文） | 类型 | 必填 | 说明 |
|--------------|--------------|------|------|------|
| 记录ID | id | bigint(20) | 是 | 主键，自增 |
| 品种编码 | product_code | varchar(20) | 是 | `pig_outer`（生猪外三元）、`corn`（玉米）、`soybean_meal`（豆粕）、`pork`（白条猪肉） |
| 价格区域 | price_region | varchar(20) | 是 | `national`（全国）、`sichuan`（四川省）、`local`（本县） |
| 价格日期 | price_date | date | 是 | 行情日期 |
| 价格 | price | decimal(10,2) | 是 | 价格数值 |
| 价格单位 | price_unit | varchar(20) | 是 | 如"元/公斤"、"元/吨" |
| 日涨跌 | daily_change | decimal(10,2) | 否 | 较前一日涨跌金额 |
| 周涨跌幅 | weekly_change_rate | decimal(5,2) | 否 | 较上周涨跌百分比 |
| 数据来源 | data_source | varchar(100) | 否 | 数据来源标识 |
| 创建时间 | create_time | datetime | 是 | 数据入库时间 |

- 联合唯一索引：`(product_code, price_region, price_date)`，防止同一品种同一区域同一天重复入库

**省份猪肉价格表 `pig_market_price_province`**：

| 字段名（中文） | 字段名（英文） | 类型 | 必填 | 说明 |
|--------------|--------------|------|------|------|
| 记录ID | id | bigint(20) | 是 | 主键，自增 |
| 省份编码 | province_code | varchar(10) | 是 | 行政区划编码 |
| 省份名称 | province_name | varchar(20) | 是 | - |
| 价格日期 | price_date | date | 是 | - |
| 猪肉批发均价 | pork_price | decimal(10,2) | 是 | 元/公斤 |
| 较上周涨跌 | weekly_change | decimal(10,2) | 否 | - |
| 创建时间 | create_time | datetime | 是 | - |

### 八、关键约束

1. **外部数据依赖**：本模块的核心数据（四个品种的全国/四川价格）依赖外部数据源接入，数据源不可用时页面需展示"数据更新异常"提示，并展示最后一次成功获取的数据
2. **数据更新时效**：外部行情数据由后端定时任务每日采集（建议每日上午9:00-10:00采集前一交易日数据），页面展示最近一次采集的时间戳
3. **本县数据可选**：生猪交易趋势图中"本县收购价"来源于企业端销售记录，如平台内无销售数据则不展示此条线，图表图例标注"本县数据暂未采集"
4. **猪粮比为派生指标**：猪粮比由生猪价格和玉米价格计算得出，两个品种的数据需时间对齐后才能计算
5. **价格地图按周更新**：全国各省猪肉价格数据获取频率通常为每周一次，地图数据可能有1-7天延迟
6. **不做价格预测**：本模块仅展示历史和当前价格数据，不做价格预测模型（价格预测属于AI服务范畴，可在第7阶段 Deepseek 服务中实现）
7. **图表组件**：统一使用 ECharts，中国地图使用 ECharts 地图组件

## 备注

- 外部数据源的具体选择和对接方案需在技术方案中确定，PRD 层面仅定义需要哪些数据和展示形式
- 如外部数据源为付费API，需评估采购成本；如采用爬取方式，需遵守目标网站的使用条款
