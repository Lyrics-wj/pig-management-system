# WEB监管端-检验检疫无害化分析

## 需求描述

检验检疫无害化分析模块为监管端决策分析板块的组成部分，通过采集四川省智慧监督管理平台的检验检疫数据，结合本县生猪保险和无害化处理等业务数据，对全县检验检疫和无害化处理情况进行多维度分析展示。该模块帮助监管部门掌握疫病防控态势、检疫合格率、病死猪处理情况等关键指标，为防疫决策提供数据依据。

与养殖分析和市场贸易分析的区别：养殖分析关注养殖生产效率指标，市场贸易分析关注外部市场价格行情，检验检疫无害化分析关注动物卫生防疫和无害化处理领域的专项分析。

技术参数 #4 定义：
汇总展示：采集四川省智慧监督管理平台相关数据，同时结合本县生猪保险、无害化处理等数据。展示本年度全县检验检疫总量、本年度检验检疫类目、本年度检验检疫合格率、本年度疫病数量及分布、本年度病死猪数量及分布、本年度病死猪处理情况相关信息。

**展示形式**：6个统计数字卡片（横向排列两行，每行3个）

| 指标 | 数据来源 | 展示方式 |
|------|---------|---------|
| 检验检疫总量（头次） | 省级平台产地检疫+屠宰检疫数据 | 数字 + 较去年同期变化（↑↓百分比） |
| 产地检疫数量（头次） | 省级平台产地检疫数据 | 数字 + 同比变化 |
| 屠宰检疫数量（头次） | 省级平台屠宰检疫数据 | 数字 + 同比变化 |
| 检验检疫合格率（%） | 合格数/检疫总量×100% | 百分比数字 + 颜色指示（≥99%绿色，95%-99%黄色，<95%红色） |

### 六、外部数据导入功能

由于省级平台和保险系统的对接可能无法在初期实现API自动对接，需提供**管理员手动导入**入口作为备选方案。

#### 6.1 检疫数据导入

- 入口：分析页面右上角「数据管理」→「导入检疫数据」
- 支持 Excel 文件导入
- 提供导入模板下载
- 导入字段：检疫类目、检疫日期、检疫数量、合格数量、检疫单位、养殖企业名称、所属乡镇、检出问题
- 导入后数据标记 `data_source = 'manual_import'`
- 仅县级管理员可操作

#### 6.2 保险数据导入

- 入口：分析页面右上角「数据管理」→「导入保险数据」
- 支持 Excel 文件导入或逐条录入
- 导入字段：统计年月、所属乡镇、投保数量、理赔数量、理赔金额
- 仅县级管理员可操作

### 九、关键约束

1. **省级平台对接待确认**：四川省智慧监督管理平台的数据对接方式（API/数据推送/手动导入）需在技术方案中确认，PRD 层面同时设计了自动对接和手动导入两种路径
2. **手动导入为过渡方案**：如果省级平台API短期内无法对接，管理员可通过 Excel 导入方式录入检疫数据，保证分析功能可用
3. **本县数据权限过滤**：疫病分布、病死猪分布、免疫覆盖等基于本县数据的分析，需按角色的 `data_scope` + 部门树过滤（县级看全县，乡镇看本乡镇）
4. **省级数据不过滤**：从省级平台获取的检疫汇总数据为全县级别，不做乡镇级过滤（省级数据可能无法精确到乡镇粒度）
5. **保险数据获取方式待确认**：生猪保险数据可能需与保险公司协调数据接口或采用定期手动录入方式
6. **预警阈值可配置**：病死率阈值、免疫覆盖率阈值等做成系统参数（存入 `sys_config`），便于管理员调整
7. **图表组件**：统一使用 ECharts，乡镇地图使用自定义蓬溪县行政区划 GeoJSON 数据
