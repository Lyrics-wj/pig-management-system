# WEB监管端-产业总览大屏

## 需求描述

产业总览大屏是监管端决策分析板块的最高层展示入口，以全屏可视化大屏的形式，将养殖分析、市场贸易分析、检验检疫无害化分析三个模块的核心指标集中呈现在一张屏幕上。面向县级领导和监管决策者，提供蓬溪县生猪产业全貌的一站式总览，适用于日常监管指挥、领导汇报展示、大屏投放等场景。

与各分析模块的区别：养殖分析、市场贸易分析、检验检疫无害化分析各自提供某个领域的深度分析（含筛选、下钻、详细表格），产业总览大屏则从三个模块中精选最核心的指标，以纯可视化方式呈现全局概貌，不提供详细数据表格和深度交互，强调"一屏总览"。

技术参数 #5 定义：
产业总览大屏展示生猪存出栏量、养殖企业数量、养殖结构分布、市场行情、检验检疫、预警事件等全县生猪产业关键指标的综合展示。

### 二、页面整体布局

#### 2.1 屏幕规格与适配

- **设计基准分辨率**：1920×1080（16:9），同时兼容 2K（2560×1440）和 4K（3840×2160）
- **显示模式**：支持浏览器 F11 全屏模式，菜单栏和侧边栏自动隐藏
- **入口方式**：
  - WEB端左侧菜单"决策分析 → 产业总览"点击进入
  - 进入后自动切换为深色全屏布局，不显示系统顶栏和侧栏
  - 页面右上角提供「退出大屏」按钮返回正常管理界面
- **深色主题**：大屏采用深蓝色/深灰色暗色背景，图表使用亮色系配色，适合投影和大屏显示器展示

#### 2.2 布局分区

大屏采用经典的**左-中-右三栏布局**：

#### 区域二：左侧栏（养殖产业）

左侧栏自上而下排列以下内容板块：

##### 板块 L1：核心指标卡片

**展示形式**：2×2 排列的指标卡片

| 指标 | 数值来源 | 展示 |
|------|---------|------|
| 养殖企业总数（家） | 养殖分析 → 养殖结构概览 | 数字 + 同比变化动画 |
| 生猪存栏总量（头） | 养殖分析 → 养殖结构概览 | 数字 + 同比变化动画 |
| 能繁母猪存栏（头） | 养殖分析 → 能繁母猪存栏占比 | 数字 + 占存栏比例 |
| 本年出栏总量（头） | 养殖分析 → 养殖结构概览 | 数字 + 同比变化动画 |

**视觉效果**：
- 数字使用科技感数字字体（Digital-7 或类似风格），带数字滚动动画
- 同比变化以红色上箭头（增长）或绿色下箭头（下降）标注
- 卡片边框带微光呼吸动效

##### 板块 L2：养殖结构分布

**展示形式**：环形图

- 按企业类型（规模养殖场/家庭农场/散养户/合作社）展示占比
- 环形图中心显示企业总数
- 各扇区带标签：类型名称 + 数量 + 占比
- 数据来源：养殖分析 → 养殖结构分布

##### 板块 L3：养殖规模 Top5

**展示形式**：横向动态柱状图（竞赛柱状图/动态排序效果）

| 排名 | 企业名称 | 存栏量（头） |
|------|---------|------------|
| 1 | XX养殖场 | XXXX |
| ... | ... | ... |

- 展示当前存栏量 Top5 企业
- 柱状图带动态排序动画
- 数据来源：养殖分析 → 养殖规模排行榜

#### 区域三：中央主区域

中央区域分为上下两部分：

##### 板块 C1：蓬溪县养殖分布地图（上半部分，约 60% 高度）

**展示形式**：蓬溪县行政区划地图（GeoJSON）

**地图功能**：
- 按乡镇着色，颜色深浅表示该乡镇养殖企业数量（热力渐变）
- 地图上以图标标注各乡镇的关键信息：
  - 养殖企业图标（猪场图标），hover 显示企业数量和存栏总量
  - 视频监控图标（摄像头图标），在线为绿色、离线为灰色
  - 预警图标（红色闪烁三角），有未处理预警的乡镇标注
- hover 某乡镇气泡弹窗显示：
  - 乡镇名称
  - 养殖企业数
  - 生猪存栏量
  - 本月出栏量
  - 未处理预警数
- 地图可缩放和平移
- 地图外围可加科技感边框装饰

**数据来源**：
- 企业数量和存栏量：养殖分析接口按乡镇汇总
- 视频设备状态：视频监管模块设备在线状态
- 预警数据：养殖分析预警事件按乡镇统计

##### 板块 C2：生猪存栏出栏量趋势（下半部分，约 40% 高度）

**展示形式**：面积折线图

- X轴：近12个月
- Y轴：数量（头）
- 存栏量（蓝色渐变填充折线）
- 出栏量（绿色渐变填充折线）
- 数据点发光效果，hover 展示数值
- 数据来源：养殖分析 → 存栏出栏量趋势

### 四、数据刷新策略

| 数据类别 | 刷新频率 | 说明 |
|---------|---------|------|
| 核心指标（企业数、存栏、出栏） | 每 30 分钟 | 基于企业端入库数据汇总 |
| 市场行情价格 | 每日 1 次 | 跟随市场贸易分析的数据采集频率 |
| 检验检疫指标 | 每 30 分钟 | 与核心指标同步刷新 |
| 预警事件列表 | 每 5 分钟 | 近实时展示新增预警 |
| 视频设备在线状态 | 每 5 分钟 | 与视频监管模块同步 |
| 地图标注数据 | 每 30 分钟 | 乡镇汇总数据 |
| 底部滚动播报 | 每 10 分钟 | 从各模块的最新动态中提取 |

**前端实现**：使用定时器（`setInterval`）按各数据类别的频率轮询后端接口，接口返回数据后局部更新对应图表区域，无需整页刷新。

### 五、动效与交互设计

#### 5.1 进入动效

- 进入大屏页面时，各区域按顺序（左→中→右→底部）依次渐入显示，间隔 200ms
- 数字指标有从 0 到目标值的滚动递增动画（countUp 效果），持续约 1.5 秒
- 地图从缩小状态放大到正常比例，带渐入效果

#### 5.2 常驻动效

| 动效 | 说明 |
|------|------|
| 数字呼吸 | 核心指标数字卡片边框有微弱的呼吸灯效果（亮度周期性变化） |
| 地图光点 | 地图上有养殖企业的乡镇显示微弱的光点闪烁 |
| 预警闪烁 | 有未处理预警的乡镇，预警图标持续闪烁 |
| 滚动播报 | 底部文字从右到左匀速滚动 |
| 预警列表 | 右下角预警列表自动向上滚动 |

#### 5.3 交互操作

| 操作 | 效果 |
|------|------|
| hover 地图乡镇 | 弹出气泡窗口显示该乡镇详细数据 |
| hover 图表数据点 | tooltip 显示具体数值 |
| 点击地图乡镇 | 无下钻（大屏定位为总览，不做深度交互；深度分析到各子模块） |
| 按 F11 | 浏览器全屏 |
| 按 ESC 或点击退出 | 退出大屏，返回管理系统 |

### 九、关键约束

1. **纯展示，不做深度交互**：大屏定位为"一屏总览"，只做 hover tooltip 展示详情，不做点击下钻、筛选过滤等交互。用户需查看详细数据时退出大屏进入对应分析子模块
2. **数据复用，不重复计算**：所有指标数据从已有的养殖分析、市场贸易分析、检验检疫分析接口获取，大屏不做独立的数据聚合计算（仅地图数据和播报消息需要新增聚合接口）
3. **深色主题独立**：大屏使用独立的深色主题 CSS，不影响管理系统的正常浅色主题。进入大屏时切换主题，退出时恢复
4. **全屏适配**：大屏页面需适配 1920×1080 至 3840×2160 分辨率范围，使用 `rem` 或 `vw/vh` 做响应式布局，确保在不同尺寸的显示器和投影仪上正常展示
5. **性能优化**：
   - 地图渲染使用 ECharts 的 SVG 模式（降低 GPU 负载）
   - 定时刷新采用增量更新，仅更新变化的数据区域
   - 动效使用 CSS animation 优先，减少 JS 动画对主线程的占用
   - 长时间运行需防止内存泄漏（定时器清理、DOM 回收）
6. **无交互超时**：大屏页面不设自动退出超时，支持 7×24 小时持续展示（适用于指挥中心大屏场景）
7. **降级处理**：某个数据接口异常时，对应区域显示"数据加载中..."或上次成功获取的数据，不影响其他区域正常展示
8. **蓬溪县 GeoJSON**：地图使用自定义蓬溪县行政区划 GeoJSON 数据（与检验检疫分析的乡镇热力图共用同一份 GeoJSON），需单独制作或获取
9. **图表组件**：统一使用 ECharts（深色主题），与各分析模块保持技术栈一致

## 备注

- 蓬溪县行政区划 GeoJSON 地图数据需单独制作或获取，该地图资源与检验检疫分析中的乡镇热力图共用
- 大屏页面建议作为独立的前端路由页面（如 `/screen`），不嵌套在管理系统的 Layout 组件中，以避免系统布局对全屏展示的干扰
- 天气信息为可选增强功能，需对接第三方天气 API（如和风天气、心知天气等），如不实现则该区域空出或替换为其他装饰元素
- 大屏首次加载时间建议控制在 3 秒以内（含地图渲染），可通过预加载 GeoJSON、接口并行请求等方式优化
- 如需离线演示（无后端数据），大屏应支持加载本地 Mock 数据文件进行静态展示
- 底部滚动播报的动态消息由后端聚合各模块的最新操作日志、价格变动、预警事件等信息生成
