# WEB监管端-养殖分析

## 需求描述

养殖分析模块是监管端决策分析板块的核心组成部分，通过对全县养殖数据的多维度汇总分析，以可视化图表和数据报表形式呈现养殖产业的整体态势，辅助监管部门进行科学决策。该模块汇聚企业端填报的养殖数据（已入库状态）、视频监控数据以及平台运营数据，为各级监管人员提供养殖结构、养殖效率、养殖规模、预警事件等维度的分析视角。

技术参数 #2 定义：
数据汇总展示：平台获取展示蓬溪县规模猪场视频数据、养殖结构数据、生猪养殖总成本排行情况、PSY排行榜情况、养殖规模排行榜情况、养殖企业淘汰率、养殖预警事件统计、能繁母猪存栏占比、生猪存栏出栏量相关信息。

### 二、页面整体布局

养殖分析页面采用**仪表盘式布局**，由全局筛选区 + 多个分析卡片组成：

**全局筛选区**（页面顶部）：

| 筛选条件 | 控件类型 | 说明 |
|---------|---------|------|
| 时间范围 | 日期区间选择器 | 默认近一年；支持按月/季/年快捷切换 |
| 所属乡镇 | 下拉筛选 | 县级角色可选任意乡镇或"全县"；乡镇角色自动锁定本乡镇 |
| 企业类型 | 下拉筛选 | 规模养殖场/家庭农场/散养户/合作社/全部 |

全局筛选条件变更后，页面所有分析卡片同步刷新数据。

#### 卡片三：生猪存栏出栏量趋势

**展示形式**：双Y轴折线图

- 左Y轴：存栏量（头）—— 蓝色折线
- 右Y轴：出栏量（头）—— 绿色折线
- X轴：时间（按月/季/年，与全局筛选的时间粒度联动）
- 数据点 hover 展示具体数值

#### 卡片四：能繁母猪存栏占比

**展示形式**：环形图 + 指标说明

- 环形图展示：能繁母猪存栏量 / 生猪存栏总量 的占比
- 环形图中心显示占比百分比数字
- 下方说明文字：能繁母猪存栏量 X 头 / 生猪存栏总量 X 头
- 旁边展示同比变化趋势（较去年同期↑↓）

**行业参考线**：在占比旁标注行业合理区间参考值（如 4%-5%），辅助判断能繁母猪存栏是否处于合理区间。

#### 卡片八：养殖企业淘汰率

**展示形式**：数字指标 + 折线趋势图

**淘汰率定义**：在统计周期内，状态变为"停用"的企业数 / 期初正常企业总数 × 100%

**展示内容**：

- 淘汰企业数 / 期初企业数
- 近12个月淘汰率折线趋势图
- 下方附淘汰企业明细列表（可折叠）：企业名称、企业类型、所属乡镇、停用时间

**数据来源**：`pig_enterprise` 表的 `status` 字段变更记录。

### 八、关键约束

1. **仅统计已入库数据**：所有分析指标均基于 `status = '4'`（已入库）的业务数据，草稿和审批中的数据不纳入统计
2. **数据范围按权限过滤**：县级角色看全县数据，乡镇角色看本乡镇数据，所有接口均需按 `data_scope` + 部门树过滤
3. **预警规则可配置**：预警阈值（如病死率阈值、产能下降比例阈值）应做成系统参数配置（存入 `sys_config`），便于管理员调整而无需改代码
4. **PSY计算需数据充足**：PSY指标依赖完整的繁育和断奶数据，企业未填报这些数据时该企业不参与PSY排行，排行列表中标注"数据不足"
5. **成本排行为近似值**：当前平台仅有饲料和兽药的采购记录，缺少人工、水电等成本数据，成本排行应明确标注为"投入品成本"而非"养殖总成本"，避免误导
6. **图表组件**：统一使用 ECharts，与大屏及其他分析模块保持一致

## 备注

- 预警事件由后端定时任务（如每小时一次）扫描业务数据生成，不做实时触发（实时告警由视频监管模块负责）
- 部分分析指标（如PSY、成本排行）在平台初期企业填报数据不充分时可能无法展示完整排行，页面需做好"数据不足"的空状态处理
- 养殖分析页面的图表布局在编写 PRD 时需配合原型图进一步细化卡片排列和尺寸
- 导出的分析报告为 Excel 格式，包含所有卡片的数据表格（图表不导出，仅导出数据）
