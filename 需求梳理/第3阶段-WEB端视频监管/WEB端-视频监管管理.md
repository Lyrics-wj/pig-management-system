# WEB端-视频监管管理

## 需求描述

视频监管管理模块将全县生猪养殖场重点区域的视频监控接入平台，实现实时调看、历史回放、告警管理和云存储管理。该模块为监管端和企业端共用，不同角色按权限查看各自范围内的摄像头画面：监管端可查看辖区内多家企业的监控，企业端仅可查看本企业的监控。

技术参数 #13 定义：
1. 视频设备信息管理：对系统中使用的视频监管摄像头信息进行登记管理。包括摄像头编号、使用单位名称、IP地址等信息进行维护。
2. 视频监控实时查看：登录用户可浏览查看自己权限下摄像头的实时监控画面信息。
3. 视频监控告警管理：对于视频监控重点区域，当人员进入告警区域，立即进行喊话警告，并且平台生成并推送告警信息，便于使用单位及时发现处理隐患。
4. 视频监控历史管理：登录用户可浏览查看自己权限下摄像头的历史监控画面信息。可通过筛选条件进行筛选需要查看时间段的监控回放信息。将全县的生猪养殖厂重点区域进行监控存储上云，随时随地实时调看、调度、告警、取证、留存。
5. 云储存管理：针对于监控服务的前端设备进行存储服务，将监控视频上传至云端存储，满足140个摄像头30天内的视频全天回放。

## 功能要点

### 一、功能拆分

本模块包含 **5个功能**，按 PRD 独立编写：

| 功能编号 | 功能名称 | 说明 |
|---------|---------|------|
| 功能一 | 视频设备信息管理 | 摄像头设备信息的登记、维护、状态监控 |
| 功能二 | 视频监控实时查看 | 实时监控画面的多画面浏览查看 |
| 功能三 | 视频监控告警管理 | 重点区域入侵告警、告警记录管理、告警推送 |
| 功能四 | 视频监控历史回放 | 历史监控视频的按时间段回放查看 |
| 功能五 | 云存储管理 | 视频存储状态监控、存储策略配置、存储容量管理 |

- 提供导入模板下载
- 导入时校验设备编号唯一性，重复时提示冲突

**导出**：

### 三、功能二：视频监控实时查看

#### 3.1 目标用户与角色

| 用户角色 | 角色编码 | 可查看范围 |
|---------|---------|----------|
| 县级管理员 | `county_admin` | 全县所有摄像头 |
| 县级业务人员 | `county_staff` | 全县所有摄像头 |
| 乡镇政府业务人员 | `town_gov_staff` | 本乡镇下所有企业的摄像头 |
| 乡镇畜牧兽医站 | `town_vet_station` | 本乡镇下所有企业的摄像头 |
| 企业管理员 | `ent_admin` | 本企业的摄像头 |

#### 3.2 功能要点

**监控画面布局**：

- 页面左侧为设备树（按"乡镇→企业→摄像头"层级组织）
  - 监管端用户看到权限范围内的完整设备树
  - 企业端用户只看到本企业下的摄像头列表（无乡镇/企业层级）
  - 设备树节点前显示在线/离线状态图标（绿色圆点/灰色圆点）
  - 设备树支持关键字搜索过滤

- 页面右侧为监控画面区域，支持多种分屏模式：
  - 单画面（1×1）
  - 四画面（2×2）
  - 九画面（3×3）
  - 十六画面（4×4）
  - 默认四画面模式

- 操作方式：
  - 从设备树拖拽或双击某摄像头到某个画面窗口，开始播放该摄像头实时画面
  - 点击画面窗口可全屏查看
  - 每个画面窗口右上角提供操作按钮：截图（保存当前帧）、录制（录制片段下载）、关闭（关闭该窗口画面）
  - 画面右键菜单：全屏、截图、录制、关闭

**视频流技术要求**：

- 实时画面延迟不超过 3 秒
- 支持 H.264 / H.265 视频编码
- 前端播放推荐使用 WebRTC 或 HTTP-FLV 方式
- 视频流地址由后端根据设备的接入通道号从视频平台获取后返回给前端

**异常处理**：

- 摄像头离线时画面区域显示"设备离线"灰色占位图
- 视频流加载超时（超过 10 秒）时显示"视频加载失败，请检查设备状态"
- 网络断开时提示"网络连接异常"

#### 3.3 接口路径规划

| 接口名称 | HTTP方法 | 路径 | 说明 |
|----------|---------|------|------|
| 设备树（按权限） | GET | `/video/monitor/deviceTree` | 按乡镇→企业→摄像头层级返回，含在线状态 |
| 获取实时视频流地址 | GET | `/video/monitor/realtime/{deviceId}` | 返回该设备的实时视频流URL |
| 截图 | POST | `/video/monitor/snapshot/{deviceId}` | 服务端截取当前帧并返回图片URL |

#### 3.4 权限标识

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `video:monitor:realtime` | 实时监控查看 | county_admin、county_staff、town_gov_staff、town_vet_station、ent_admin |
| `video:monitor:snapshot` | 截图 | county_admin、county_staff、town_gov_staff、town_vet_station、ent_admin |

### 四、功能三：视频监控告警管理

#### 4.1 目标用户与角色

与功能二一致（监管端四个角色 + 企业管理员），数据范围按权限过滤。

#### 4.2 功能要点

**告警规则配置**（仅县级管理员）：

- 对标记为"告警区域"的摄像头配置告警规则
- 告警类型：人员入侵检测（当有人员进入指定区域时触发告警）
- 配置项：
  - 告警区域绘制：在摄像头画面上通过鼠标绘制多边形告警检测区域
  - 告警时段：设置告警生效的时间段（如夜间 20:00-06:00）
  - 告警灵敏度：低/中/高
  - 是否启用喊话警告：是/否（触发告警时自动通过摄像头喊话器播放预设警告语音）
  - 喊话内容：预设文本或选择录制的语音文件
  - 推送方式：平台消息 / 短信通知（可多选）
  - 通知人员：选择需要接收告警通知的用户（从设备所属企业及上级监管人员中选择）

**告警记录列表**：

- 分页展示历史告警记录
- 列表展示字段：

| 列名 | 说明 |
|-----|------|
| 告警时间 | 告警触发时间 |
| 设备名称 | 触发告警的摄像头名称 |
| 使用单位 | 所属企业名称 |
| 所属乡镇 | 企业所属行政区域 |
| 告警类型 | 人员入侵 |
| 告警截图 | 告警瞬间截图（缩略图，点击放大） |
| 处理状态 | 未处理/已处理/已忽略 |
| 处理人 | 处理该告警的人员 |
| 处理时间 | 处理操作时间 |
| 操作 | 查看详情、处理、查看回放 |

- 筛选条件：设备名称（模糊搜索）、使用单位（模糊搜索）、所属乡镇（下拉）、处理状态（下拉）、告警时间范围（日期区间）
- 列表默认按告警时间倒序排列
- 未处理告警行以浅红色背景高亮

**告警详情**：

- 展示告警完整信息：告警时间、设备名称、使用单位、告警类型、告警截图（原图）、告警时的10秒短视频（告警前5秒到告警后5秒）
- 提供"查看回放"按钮，跳转到历史回放页面并自动定位到告警时间点

**告警处理**：

- 对未处理的告警执行处理操作
- 处理弹窗字段：处理结果（下拉：已确认处理/误报忽略）、处理说明（文本域，必填，最少10字符）
- 提交后更新处理状态、处理人、处理时间

**告警推送**：

- 告警触发时实时生成告警消息
- 推送方式一：平台内消息推送（页面右上角铃铛图标显示未读告警数）
- 推送方式二：短信通知（调用短信服务向配置的通知人员发送告警信息）
- 告警消息内容模板：「[告警] {设备名称}（{使用单位}）于{告警时间}检测到人员入侵，请及时处理。」

| `video:alarm:handle` | 处理告警 | county_admin、county_staff、town_gov_staff、town_vet_station、ent_admin |

### 五、功能四：视频监控历史回放

#### 5.1 目标用户与角色

与功能二一致，可查看范围按数据权限过滤。

#### 5.2 功能要点

**回放页面布局**：

- 页面左侧为设备树（与实时监控共用同一设备树组件）
- 页面右侧为回放播放区域（单画面模式）
- 播放区域下方为时间轴控件

**回放操作**：

- 选择摄像头后，选择回放日期和时间段
- 时间选择方式：
  - 日期选择器选择日期
  - 时间段选择：开始时间 - 结束时间，或通过可视化时间轴拖拽选择
- 时间轴控件：
  - 24小时横向时间轴，有录像的时段以蓝色条标识，无录像时段为灰色
  - 告警时刻以红色三角标记在时间轴上
  - 拖拽时间轴可快速定位播放位置
  - 支持缩放时间轴（放大到分钟级、缩小到小时级）

**播放控制**：

- 播放/暂停
- 快进（2倍/4倍/8倍/16倍速）
- 慢放（0.5倍速）
- 逐帧前进/后退
- 截图（保存当前帧）
- 片段下载（选择起止时间，下载该时间段视频文件）

**回放约束**：

- 最长可回放最近30天内的录像（与云存储保留策略一致）
- 单次回放时间段不超过24小时
- 超过30天的录像显示"超出存储保留期，录像不可用"

#### 5.3 接口路径规划

| 接口名称 | HTTP方法 | 路径 | 说明 |
|----------|---------|------|------|
| 查询录像时段 | GET | `/video/playback/timeline/{deviceId}` | 查询某天有录像的时段信息 |
| 获取回放视频流地址 | GET | `/video/playback/stream/{deviceId}` | 参数含日期、开始/结束时间 |
| 截图 | POST | `/video/playback/snapshot/{deviceId}` | 保存当前帧 |
| 片段下载 | POST | `/video/playback/download/{deviceId}` | 下载指定时段视频文件 |

#### 5.4 权限标识

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `video:playback:view` | 历史回放查看 | county_admin、county_staff、town_gov_staff、town_vet_station、ent_admin |
| `video:playback:download` | 视频片段下载 | county_admin、county_staff |

> 注意：视频片段下载权限仅给县级角色，避免视频文件随意下载外传。

### 六、功能五：云存储管理

#### 6.1 目标用户与角色

| 用户角色 | 角色编码 | 主要操作 |

| 县级业务人员 | `county_staff` | 查看存储状态 |

> 此功能仅对县级角色开放，乡镇和企业角色无需关注云存储管理。

#### 6.2 功能要点

**存储状态总览**：

- 存储容量仪表盘：总容量、已用容量、剩余容量、使用率（百分比 + 进度条）
- 设备存储明细列表：

| 列名 | 说明 |
|-----|------|
| 设备编号 | 摄像头编号 |
| 设备名称 | 摄像头名称 |
| 使用单位 | 所属企业 |
| 今日录像时长 | 今日已录制时长（小时） |
| 存储占用 | 该设备累计存储占用量（GB） |
| 最早录像日期 | 该设备最早可回放的录像日期 |
| 最新录像时间 | 最后一次录像的时间 |
| 存储状态 | 正常/接近上限/存储满 |

- 存储使用趋势图：近30天每日新增存储量折线图

**存储策略配置**（仅县级管理员）：

| 配置项 | 说明 | 默认值 |
|-------|------|-------|
| 录像保留天数 | 超过此天数的录像自动清除 | 30天 |
| 存储告警阈值 | 存储使用率超过此值时告警 | 85% |
| 录像质量 | 标清/高清/超清 | 高清 |
| 录像模式 | 全天录像/仅告警时段录像 | 全天录像 |

**存储容量规格**：

- 满足 140 个摄像头 30 天全天回放的存储需求（技术参数要求）
- 存储使用率超过告警阈值时，在页面顶部显示橙色警告条，并推送通知给县级管理员

#### 6.3 接口路径规划

| 设备存储明细列表 | GET | `/video/storage/device/list` | 分页 |
| 存储使用趋势 | GET | `/video/storage/trend` | 近30天趋势 |

#### 6.4 权限标识

|---------|------|---------|

### 七、关键约束与技术说明

1. **视频平台对接**：本模块需要对接第三方视频监控平台（如海康/大华的视频综合管理平台、或云视频服务），后端作为中间层，封装视频平台API，向前端提供统一的视频流地址获取接口。具体对接的视频平台品牌和API需另行确认
2. **视频流协议**：实时视频推荐使用 WebRTC 或 HTTP-FLV 实现低延迟播放；历史回放可使用 HLS 或 HTTP-FLV。前端播放器推荐使用 jessibuca 或 flv.js
3. **设备状态同步**：设备在线/离线状态需通过定时轮询或视频平台回调机制保持实时同步
4. **数据权限**：设备数据通过 `enterprise_id` 关联企业，再通过企业的部门树归属实现数据权限过滤。县级看全部设备、乡镇看本乡镇企业的设备、企业看本企业设备
5. **140个摄像头**：技术参数要求满足140个摄像头的接入与存储，属于已知规模上限，性能设计需考虑此规模
6. **告警实时性**：告警检测由视频平台AI能力完成，检测结果通过回调推送到本平台，本平台负责告警记录存储、消息推送和处理流程
