# WEB监管端-养殖企业管理

## 需求描述

监管端养殖企业管理模块是监管人员对辖区内所有养殖企业进行信息监管的核心入口。该模块作为企业端数据的"消费方"，不负责数据的录入填报（由企业端完成），而是提供对养殖企业基础信息和养殖档案数据的**查看、监管、统计、导出**能力。

技术参数 #6 定义：

1. 养殖企业信息管理：实现蓬溪县所有养殖企业的基本信息情况监管，主要包括养殖户名称、养殖类型、所在地区、手机号、企业附件等信息。
2. 养殖档案监管：实现养殖企业的养殖档案信息的监管查看。养殖档案信息包含养殖企业猪只入栏记录、出栏记录、免疫记录、保险记录、投入品使用记录、消毒记录、无害化处理记录等关联信息。

## 功能要点

### 一、功能拆分

本模块包含 **2个功能**，按 PRD 独立编写：


| 功能编号 | 功能名称     | 说明                                      |
| ---- | -------- | --------------------------------------- |
| 功能一  | 养殖企业信息管理 | 监管端对辖区内所有养殖企业基础信息的查看、搜索、筛选、详情查看、状态管理、导出 |
| 功能二  | 养殖档案监管   | 监管端对养殖企业各类养殖档案记录的汇总查看、筛选、详情查看、审核操作      |

### 二、功能一：养殖企业信息管理

#### 2.1 目标用户与角色


| 用户角色     | 角色编码（role_key）     | 使用场景       | 主要操作                            |
| -------- | ------------------ | ---------- | ------------------------------- |
| 县级管理员    | `county_admin`     | 管理全县养殖企业信息 | 查看全部企业列表、详情查看、启用/停用企业、新增企业账号、导出 |
| 县级业务人员   | `county_staff`     | 日常监管查看     | 查看全部企业列表、详情查看、导出                |
| 乡镇政府业务人员 | `town_gov_staff`   | 辖区内企业监管    | 查看本乡镇企业列表、详情查看、导出               |
| 乡镇畜牧兽医站  | `town_vet_station` | 辖区内企业技术监管  | 查看本乡镇企业列表、详情查看、导出               |


> 角色编码引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1

#### 2.2 数据来源

- 企业基础信息来自 `pig_enterprise` 表（企业端功能一定义，见 `WEB企业端-企业信息管理-基础信息.prd.md`）
- 监管端**不新增企业信息表**，直接查询企业端已有的数据
- 数据范围按角色的部门树权限过滤（县级看全县、乡镇看本乡镇下的企业）

#### 2.3 功能要点

**企业列表页**：

- 分页列表展示辖区内所有养殖企业基本信息
- 搜索与筛选条件：
  - 企业名称（模糊搜索）
  - 企业类型（下拉筛选：规模养殖场/家庭农场/散养户/合作社）
  - 所属乡镇（下拉筛选，从部门树获取乡镇列表；县级可选任意乡镇，乡镇角色自动锁定本乡镇不显示）
  - 企业状态（下拉筛选：正常/停用）
  - 联系电话（模糊搜索）
- 列表展示字段：企业名称、统一社会信用代码、企业类型、法人代表、联系电话、详细地址、养殖规模（头）、所属乡镇、状态、创建时间
- 操作列：「查看详情」（所有角色）、「启用/停用」（仅县级管理员）
- 支持导出 Excel（导出当前筛选条件下的全部数据）
- 列表默认按创建时间倒序排列

**企业详情页**：

- 展示企业全部基础信息字段（与企业端基础信息一致，见 `pig_enterprise` 全字段）
- 营业执照照片支持点击放大预览
- 经纬度坐标展示（若已定位则展示地图标点，未定位显示"暂未定位"）
- 圈舍信息展示：关联展示该企业下所有圈舍列表（来自 `pig_pigsty` 表）
- 所有信息均为**只读展示**，监管端不可编辑企业基础信息

**企业状态管理**（仅县级管理员）：

- 在企业列表中，县级管理员可对企业执行"启用"或"停用"操作
- 操作前弹出二次确认弹窗
- 停用后企业端用户登录该企业账号时无法进入系统（或提示"企业已停用，请联系管理部门"）

**新增企业账号**（仅县级管理员）：

- 县级管理员可在监管端为新的养殖企业创建账号
- 新增时需填写：企业名称、统一社会信用代码、企业类型、法人代表、联系电话、详细地址、养殖规模、所属乡镇（从部门树选择）
- 新增企业的同时自动创建一个企业管理员账号（默认密码），关联到该企业对应的部门节点
- 新增后该企业出现在企业列表中

#### 2.4 接口路径规划


| 接口名称        | HTTP方法 | 路径                                 | 说明           |

| 所属乡镇下拉（部门树） | GET    | `/system/dept/treeselect`          | 复用现有接口       |

#### 3.3 功能要点

**档案监管首页**：

- 以Tab页签形式组织 18 个档案类别，每个Tab对应一类养殖档案记录
- Tab页签按业务逻辑分组展示（可横向滚动）：
  - 养殖管理：养殖信息、繁育信息、断奶信息、入栏信息、转栏信息、出栏信息
  - 防疫免疫：畜禽免疫记录、消毒记录、防疫监测记录
  - 投入品管理：兽药购进记录、兽药使用记录、饲料添加剂购进记录、配合饲料使用记录
  - 疾病与处理：畜禽疾病诊疗记录、病死畜禽无害化处理记录、粪便及污物无害化处理记录
  - 生产与销售：生产记录、畜禽及其产品销售记录

**每个Tab下的列表页**：

- 与企业端对应模块的列表页结构一致（复用相同的列表字段定义），但有以下监管端专属差异：
  - **额外展示企业名称列和所属乡镇列**（企业端列表不展示这两列，因为企业端只看本企业数据）
  - **额外筛选条件**：企业名称（模糊搜索）、所属乡镇（下拉筛选）
  - **数据范围**：县级看全县所有企业数据，乡镇角色看本乡镇下的企业数据
  - **操作列**：根据当前用户角色和数据状态显示对应的审批操作按钮（核实/审核/终审）

**审批操作**：

- 监管端的审批操作与企业端各模块已定义的四级审批流程一致
- 审批接口复用企业端各模块已定义的审批接口（核实通过/退回、审核通过/退回、终审通过/退回）
- 不同角色在监管端看到的操作按钮：
  - 乡镇畜牧兽医站：对"待核实"数据显示「核实通过」「核实退回」
  - 乡镇政府业务人员：对"待审核"数据显示「审核通过」「审核退回」
  - 县级业务人员：对"待终审"数据显示「终审通过」「终审退回」
  - 县级管理员：可查看所有数据，可编辑、删除

**详情查看**：

- 点击列表中某条记录，弹出详情弹窗
- 详情内容与企业端各模块的详情页一致（字段完全相同）
- 额外展示：企业名称、所属乡镇、审核进度步骤条
- 所有字段只读展示

**导出Excel**：

- 每个Tab下支持导出当前筛选结果
- 导出字段在企业端导出字段基础上，增加"企业名称"和"所属乡镇"列
- 导出文件名格式：`{档案类别名称}_监管导出_YYYYMMDD_HHmmss.xlsx`

#### 3.4 接口路径规划

监管端养殖档案监管的列表查询和审批操作，**直接复用企业端各模块已定义的接口**。企业端接口已实现数据权限过滤（按部门树 + data_scope），监管端用户调用同一接口时，后端自动按监管端角色的数据范围返回对应数据。


| 接口类型         | 说明                                        | 复用方式                    |
| ------------ | ----------------------------------------- | ----------------------- |
| 各档案类别的分页列表接口 | 如 `GET /farm/dead-animal-records/list`    | ✅ 直接复用企业端接口，后端按数据权限自动过滤 |
| 各档案类别的详情接口   | 如 `GET /farm/dead-animal-records/{id}`    | ✅ 直接复用                  |
| 各档案类别的审批接口   | 如 `PUT /farm/dead-animal-records/verify`  | ✅ 直接复用                  |
| 各档案类别的导出接口   | 如 `POST /farm/dead-animal-records/export` | ✅ 直接复用                  |


> 注意：企业端各模块的列表接口需在请求参数中支持 `enterpriseName`（企业名称筛选）和 `areaCode`（行政区划筛选），以满足监管端的跨企业查询需求。部分企业端 PRD 中已设计了这些参数（如病死畜禽无害化处理记录已支持），其余模块的列表接口需确认是否已支持这些参数，未支持的需在企业端 PRD 中补充。

#### 3.5 权限标识

监管端养殖档案监管的权限标识，复用企业端各模块已定义的权限标识体系。监管端角色通过菜单配置获得对企业端各模块接口的访问权限。

额外需要的监管端专属权限：


| 权限标识                     | 说明         | 拥有角色                                                      |
| ------------------------ | ---------- | --------------------------------------------------------- |
| `admin:archive:overview` | 养殖档案监管总览入口 | county_admin、county_staff、town_gov_staff、town_vet_station |


各档案类别的具体权限（查看、核实、审核、终审）沿用企业端各模块已定义的权限标识，在角色管理中按需分配给监管端角色即可。

### 四、关键约束

1. **监管端不重复建表**：所有数据来自企业端已定义的业务表，监管端不新建业务数据表
2. **接口尽量复用**：养殖档案的列表/详情/审批接口直接复用企业端接口，通过数据权限机制实现不同角色看到不同范围的数据
3. **企业信息管理接口独立**：监管端的企业列表/详情/新增/状态管理使用独立的 `/admin/enterprise/`* 接口前缀，与企业端的 `/farm/enterprise/*` 接口区分
4. **数据范围靠部门树**：县级角色看全县，乡镇角色看本乡镇下的企业，通过 `data_scope` + 部门树自动过滤
5. **监管端一般只读**：监管端对企业基础信息和养殖档案数据以查看为主，不做填报操作（县级管理员的新增/编辑/删除属于管理权限，非日常填报）
