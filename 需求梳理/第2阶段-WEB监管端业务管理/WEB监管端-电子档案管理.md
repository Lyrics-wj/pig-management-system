# WEB监管端-电子档案管理

## 需求描述

电子档案管理模块是对已入库的养殖档案数据进行**结构化归档、统计分析、分类检索、数据汇总**的管理工具。与"养殖企业管理-养殖档案监管"模块的区别在于：养殖档案监管侧重"在线逐条查看与审批流程操作"，电子档案管理侧重"已归档数据的全局视角统计、跨企业汇总分析、快速检索和台账管理"。

技术参数 #7 定义：
1. 生猪养殖档案管理：通过电子化手段，对生猪养殖过程中的各项数据进行记录和管理，支持拍照、录入、保存、分类、统计、检索等功能，包括生猪存出栏统计、产地检疫、屠宰检疫、免疫防疫等相关数据。
2. 统计与数据分析：通过对养殖、屠宰、销售等环节的数据进行挖掘和分析，为企业管理层提供全方位的综合业务查询统计业务，跨部门联合审核，实现企业内统一核算和查询平台。

## 功能要点

### 一、功能拆分

本模块包含 **3个功能**，按 PRD 独立编写：

| 功能编号 | 功能名称 | 说明 |
|---------|---------|------|
| 功能一 | 档案台账总览 | 以企业为维度的档案归档情况总览，包括各类档案的填报数量、入库数量、最近更新时间等汇总信息 |
| 功能二 | 档案分类检索 | 对已入库的各类养殖档案数据进行跨企业的统一检索与查看 |
| 功能三 | 档案统计分析 | 对已入库数据进行多维度统计分析，以图表和报表形式展示 |

---

### 二、功能一：档案台账总览

#### 2.1 目标用户与角色

| 用户角色 | 角色编码（role_key） | 使用场景 | 主要操作 |
|---------|---------------------|---------|---------|
| 县级管理员 | `county_admin` | 全县档案归档情况总览 | 查看全部企业台账、导出 |
| 县级业务人员 | `county_staff` | 日常检查企业档案完整性 | 查看全部企业台账、导出 |
| 乡镇政府业务人员 | `town_gov_staff` | 辖区内企业档案完整性检查 | 查看本乡镇企业台账、导出 |
| 乡镇畜牧兽医站 | `town_vet_station` | 辖区内企业档案技术性检查 | 查看本乡镇企业台账、导出 |

> 角色编码引用自 `需求梳理/第0阶段-多端权限架构/全局-角色与权限体系.md` §1.1

#### 2.2 功能要点

**台账总览列表**：

- 以企业为行维度，展示每家养殖企业各类档案的归档情况汇总
- 列表展示字段：

| 列名 | 说明 |
|-----|------|
| 企业名称 | 养殖企业名称 |
| 所属乡镇 | 企业所属行政区域 |
| 企业类型 | 规模养殖场/家庭农场/散养户/合作社 |
| 养殖规模（头） | 设计养殖规模 |
| 养殖信息 | 已入库记录数 |
| 繁育信息 | 已入库记录数 |
| 入栏记录 | 已入库记录数 |
| 出栏记录 | 已入库记录数 |
| 免疫记录 | 已入库记录数 |
| 消毒记录 | 已入库记录数 |
| 投入品使用 | 已入库记录数（含兽药使用+饲料使用） |
| 无害化处理 | 已入库记录数（含病死畜禽+粪便污物） |
| 销售记录 | 已入库记录数 |
| 最近更新 | 所有档案类别中最近一条已入库记录的创建时间 |
| 操作 | 「查看档案」 |

- 各档案类别列的数字显示已入库记录数（status=已入库），点击数字可快速跳转到该企业该类别的档案详细列表
- 数字为 0 时显示红色字体，提示该企业该类别无归档数据

**搜索与筛选**：

- 企业名称（模糊搜索）
- 所属乡镇（下拉筛选；乡镇角色自动锁定本乡镇）
- 企业类型（下拉筛选）
- 时间范围（按最近更新时间筛选）

**企业档案详情页**：

- 点击「查看档案」进入某一家企业的完整档案页面
- 页面顶部展示企业基本信息摘要（企业名称、企业类型、法人代表、联系电话、养殖规模）
- 下方以 Tab 页签展示该企业各类已入库的档案记录列表（Tab 结构与养殖档案监管一致，但**仅展示已入库状态的数据**，不展示草稿/审批中的数据）
- 每个 Tab 下的列表支持按时间范围筛选
- 所有数据只读展示

**导出**：

- 支持导出台账总览列表（Excel）
- 支持导出某企业某类档案的已入库数据列表（Excel）
- 导出文件名格式：`档案台账总览_YYYYMMDD_HHmmss.xlsx` 或 `{企业名称}_{档案类别}_YYYYMMDD_HHmmss.xlsx`

#### 2.3 数据来源

- 台账汇总数据通过对各业务表按 `enterprise_id` 分组统计 `status = '4'`（已入库）的记录数获得
- 不新建汇总表，实时查询统计（企业数量有限，性能可接受）
- 数据来源表同"养殖档案监管"模块（18张业务表）

#### 2.4 接口路径规划

| 接口名称 | HTTP方法 | 路径 | 说明 |
|----------|---------|------|------|
| 档案台账总览列表 | GET | `/admin/archive/overview/list` | 分页，按企业汇总各类档案已入库数 |
| 企业档案详情-各类别列表 | GET | `/admin/archive/overview/{enterpriseId}/{category}/list` | 某企业某类别的已入库档案列表 |
| 导出台账总览 | POST | `/admin/archive/overview/export` | 导出台账汇总表 |
| 导出企业档案 | POST | `/admin/archive/overview/{enterpriseId}/{category}/export` | 导出某企业某类别已入库数据 |

#### 2.5 权限标识

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `admin:archive:overview:list` | 台账总览列表 | county_admin、county_staff、town_gov_staff、town_vet_station |
| `admin:archive:overview:query` | 企业档案详情 | county_admin、county_staff、town_gov_staff、town_vet_station |
| `admin:archive:overview:export` | 导出 | county_admin、county_staff、town_gov_staff、town_vet_station |

### 三、功能二：档案分类检索

#### 3.1 目标用户与角色

与功能一一致（县级管理员、县级业务人员、乡镇政府业务人员、乡镇畜牧兽医站）。

#### 3.2 功能要点

**全局检索入口**：

- 提供统一的搜索框，支持跨档案类别的全文检索
- 搜索范围：已入库的所有档案记录
- 可搜索字段：企业名称、档案内容中的关键字段（如处理方法、死亡原因、疫苗名称、药品名称、饲料名称等）

**高级检索（筛选条件）**：

| 筛选条件 | 说明 |
|---------|------|
| 档案类别 | 下拉多选，18个类别可选，默认全部 |
| 企业名称 | 模糊搜索 |
| 所属乡镇 | 下拉筛选 |
| 时间范围 | 按创建时间区间筛选 |
| 填报人 | 模糊搜索 |

**检索结果展示**：

- 结果以列表形式分页展示
- 统一列表字段：序号、档案类别（Tag标签区分）、企业名称、所属乡镇、关键摘要（根据档案类别展示最关键的2-3个字段值的拼接摘要）、填报人、创建时间、操作（查看详情）
- 点击"查看详情"弹出对应档案类别的详情弹窗（复用各模块已定义的详情展示）
- 列表上方展示检索结果统计：共 X 条记录，涉及 X 个档案类别、X 家企业

**导出**：

- 支持导出当前检索结果（Excel）
- 导出字段根据实际数据的档案类别动态确定

#### 3.3 接口路径规划

| 接口名称 | HTTP方法 | 路径 | 说明 |
|----------|---------|------|------|
| 档案全局检索 | GET | `/admin/archive/search` | 分页，支持跨类别检索 |
| 导出检索结果 | POST | `/admin/archive/search/export` | 导出当前筛选结果 |

#### 3.4 权限标识

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `admin:archive:search` | 档案检索 | county_admin、county_staff、town_gov_staff、town_vet_station |
| `admin:archive:search:export` | 导出检索结果 | county_admin、county_staff、town_gov_staff、town_vet_station |

### 四、功能三：档案统计分析

#### 4.1 目标用户与角色

与功能一一致（县级管理员、县级业务人员、乡镇政府业务人员、乡镇畜牧兽医站）。

#### 4.2 功能要点

**统计维度**：

以下统计均基于**已入库**数据：

| 统计项 | 统计内容 | 图表类型 | 说明 |
|-------|---------|---------|------|
| 存出栏统计 | 各企业（或全县/各乡镇）的生猪存栏量、出栏量趋势 | 折线图 + 数据表格 | 支持按月/季/年切换时间粒度 |
| 免疫防疫统计 | 全县/各乡镇/各企业的免疫记录数量、免疫覆盖率 | 柱状图 + 数据表格 | 按疫苗类型分类统计 |
| 无害化处理统计 | 病死畜禽处理数量、处理方式分布 | 饼图 + 折线图 | 按处理方式分类统计 |
| 投入品使用统计 | 兽药/饲料使用量统计、采购量统计 | 柱状图 + 数据表格 | 按类别分类统计 |
| 疾病诊疗统计 | 疾病类型分布、发病趋势 | 饼图 + 折线图 | 按疾病名称分类统计 |
| 销售统计 | 销售数量、销售去向分布 | 柱状图 + 饼图 | 按时间趋势展示 |
| 档案填报情况统计 | 各企业各类档案的填报数量、填报及时性 | 热力表格 | 行=企业，列=档案类别，色深=填报数量 |

**页面交互**：

- 页面顶部提供全局筛选条件：
  - 时间范围（日期区间选择器，默认近一年）
  - 所属乡镇（下拉筛选；乡镇角色自动锁定）
  - 企业名称（模糊搜索，可选某一家企业或全部）
- 统计面板以卡片式布局，每个统计项占一个卡片
- 每个卡片包含：标题、图表区域、数据表格区域（可折叠）
- 图表支持数据点hover展示具体数值
- 每个统计卡片支持单独导出图表（PNG）和数据（Excel）

**导出**：

- 支持整页统计报告导出（Excel，包含所有统计项的数据表格）
- 支持单个统计项导出（Excel 或 PNG 图片）
- 导出文件名格式：`档案统计分析_{时间范围}_YYYYMMDD_HHmmss.xlsx`

#### 4.3 数据来源

- 统计数据均实时从各业务表聚合查询（`status = '4'` 已入库数据）
- 如数据量大导致统计查询性能不佳，可后续引入定时任务生成统计快照表（属于优化方案，初期不做）

#### 4.4 接口路径规划

| 接口名称 | HTTP方法 | 路径 | 说明 |
|----------|---------|------|------|
| 存出栏统计 | GET | `/admin/archive/stats/stock` | 按时间粒度返回存出栏数据 |
| 免疫防疫统计 | GET | `/admin/archive/stats/immunity` | 按疫苗类型分组统计 |
| 无害化处理统计 | GET | `/admin/archive/stats/disposal` | 按处理方式分组统计 |
| 投入品使用统计 | GET | `/admin/archive/stats/input` | 兽药+饲料使用/采购统计 |
| 疾病诊疗统计 | GET | `/admin/archive/stats/disease` | 按疾病类型分组统计 |
| 销售统计 | GET | `/admin/archive/stats/sales` | 销售数量与去向统计 |
| 档案填报情况统计 | GET | `/admin/archive/stats/filing` | 各企业各类别填报数量矩阵 |
| 导出统计报告 | POST | `/admin/archive/stats/export` | 导出完整统计报告 |

#### 4.5 权限标识

| 权限标识 | 说明 | 拥有角色 |
|---------|------|---------|
| `admin:archive:stats` | 档案统计分析查看 | county_admin、county_staff、town_gov_staff、town_vet_station |
| `admin:archive:stats:export` | 导出统计报告 | county_admin、county_staff |

> 注意：统计分析导出权限仅给县级角色，乡镇角色可查看但不可导出全局统计报告。

### 五、与"养殖企业管理-养殖档案监管"的定位区分

| 维度 | 养殖档案监管（养殖企业管理-功能二） | 电子档案管理（本模块） |
|-----|-------------------------------|-------------------|
| 数据状态范围 | 所有状态（草稿/审批中/已入库/退回） | 仅已入库数据 |
| 核心操作 | 逐条查看 + 审批流程操作（核实/审核/终审） | 统计分析 + 全局检索 + 台账管理 |
| 视角 | 按单条记录，关注审批进度和流转状态 | 按企业/区域/时间维度，关注数据完整性和趋势 |
| 展示形式 | 列表 + 详情弹窗 | 台账汇总表 + 图表 + 检索结果列表 |
| 适用场景 | 日常审批工作、逐条数据核查 | 定期汇报、数据分析、档案完整性检查、领导查阅 |

---

### 六、关键约束

1. **仅展示已入库数据**：档案台账总览和统计分析仅统计 `status = '4'`（已入库）的数据，草稿/审批中/退回状态不纳入统计
2. **不重复建业务表**：所有统计数据从企业端已有的18张业务表实时聚合，不另建汇总表（初期）
3. **数据范围靠部门树**：统计与检索的数据范围同样按角色的 `data_scope` + 部门树过滤
4. **与养殖档案监管互补不重叠**：两个模块在菜单中独立入口，各有侧重，不在功能上重复
5. **图表组件选型**：统计图表推荐使用 ECharts（与后续产业大屏保持技术栈统一）

## 相关模块

- WEB监管端 → 养殖企业管理 → 养殖档案监管（功能互补，审批流程操作在那边完成）
- WEB企业端 → 企业信息管理 → 养殖信息管理（18个子模块，为本模块的数据来源）
- WEB监管端 → 决策分析（第4阶段，更宏观的分析维度；本模块侧重档案层面的统计）
- 系统管理 → 部门管理（数据权限过滤）
- 需求梳理 → 第0阶段-多端权限架构 → 全局-角色与权限体系.md

## 备注

- 本模块与"决策分析"阶段（第4阶段）的养殖分析有部分数据重叠，但定位不同：电子档案管理侧重"档案管理视角的统计"（强调数据完整性、填报情况、归档台账），决策分析侧重"产业发展视角的分析"（强调PSY排行、养殖成本、预警趋势等）
- 统计分析的具体图表样式和交互细节在编写 PRD 时需进一步细化
- 全局检索功能如果后续数据量增长较大，可考虑引入 Elasticsearch 优化搜索性能，初期使用数据库 LIKE 查询即可
